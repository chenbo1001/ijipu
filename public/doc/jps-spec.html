.jps 脚本语法规范 V1.0

来源：原「番茄简谱」脚本说明手册（doc.lezhi99.com/zhipu）逐页逆向整理。
本项目兼容此规范 —— 原网站的 .jps 谱子可直接使用。
原始规范快照已清理（不随项目分发，开发参考材料不出现在仓库中）。

1. 文件结构

描述头（多行，每行一个字段）   ← 必须
--- 简谱主体 ---
Q 行 / C 行（可重复，词依附曲）
[fenye]                        ← 手动分页
# 注释行                       ← 任意位置

2. 描述头

字母说明示例必须
V版本号V: 1.0是
B标题（可多次；首个为主标题，其后为副标题）B: 排排坐是
Z作者（可多次，居右显示）Z: 佚名 词曲-
D调式（大写字母，后接 #/$ 表示升降；升降号也可写在字母前，adj174 预览时 ♯/♭ 角标显示在字母左上角）D: E / D: F# / D: $B是
P拍号（/ 分隔；可多个，辅助拍号加括号）P: 4/4 / P: 6/8 (2/4)是
J节拍（数字=每分钟拍数；或文字显示在拍号下）J: 96 / J: 欢快的-
Y乐器（可多次，渲染在副标题下方）Y: 笛子-
S说明文字（可多次，渲染在谱尾；支持 \n 手动换行）S: 第一段\n第二段-

3. 主体行

  • Q 行（曲）：Q: 音符序列，可带声部编号与名称：Q2"女声": ...
  • C 行（词）：C: 歌词，依附于上一个同声部 Q 行；一行曲可对多行词；标点自动识别

4. 音符与符号

符号含义
1-7音符
0休止符（可见）
8隐藏休止符（占空间不显示）
9节奏音符 X
'高音点（数字后，可多个）
,低音点（数字后，可多个）
# / $ / =升 / 降 / 还原（一律写在数字后方，如 1# 2$ 3=）
-增时线（每条 +1 拍；原站格式化会拆为 5 -，解析须归并）
/减时线（n 条 = 1/2^n 拍）
.附点（可两个：1.5 / 1.75 倍）
(1)虚音符：括号紧贴单个音符（块内无空格），弱奏装饰，是音符块的一部分
1[65]前倚音：[ 紧跟音符数字，括号内可含高低音点 ' ,、变音 # $ =、减时线 /，是音符块的一部分
1[h65]后倚音：[ 后加 h，其余同前倚音
&编码装饰符号（拼音首字母，如 &tr 颤音、&sbf 声部括弧位置）；力度/速度编码（&pp &p &mp &mf &f &ff &fff &sf &fp &sfp，&rit 渐慢）写在音符后，预览在音符上方以斜体显示编码
&zkh / &ykh左右括号标记（adj294）：独立标记符（不依附音符）——在源码哪个位置就插入一个括号符号并占宽，不对音符时值/位置施加影响。&zkh 左括号 (、&ykh 右括号 )；可写在音符前/后（如 &zkh 6、6 - - -&ykh、1&zkh 2-&ykh）
< / > / !渐强 / 渐弱 / 结束：</> 写在音符后表示从该音符正中开始渐强/渐弱，! 写在音符后表示结束于该音符；预览从起点音符正中到终点音符正中画一个开口的 </> 尖括号（hairpin，两条线从尖点向上下张开，高度与对音符间距类似连音线）。<+/>++ 的 + 数量逐级抬升 hairpin 位置（每级 2px，类似跳房子）
@乐器名乐器切换指令（adj301）：从该时点起当前及以后行切换到指定乐器；乐器名须与试听音色库名一致（钢琴/风琴/弦乐/长笛/铜管/八音盒），不匹配回退默认乐器；不占时值、不渲染
@@切回默认乐器（描述头第一个 Y: 指定的乐器；无 Y: 则音色库第一个——钢琴）
音符块：数字连同其全部修饰（高低音点、变音、时值线、附点、虚音符括号、倚音括号）构成一个音符块，块内不用空格分隔。
乐器指令（adj301/302）：@乐器名 / @@ 为独立指令块，与其他块之间同样单空格（如 1 2 @弦乐 3 4 @@ 5 6），不占时值、不渲染，仅播放时切换乐器。描述头 Y: 行指定乐器：一个 Y 行只保留一种乐器（多乐器写多行）；多声部按声部序号对应 Y 行顺序（Q1→第一个 Y、Q2→第二个 Y…），声部比 Y 行多时用默认乐器（第一个 Y 或音色库第一个——钢琴）。

5. 小节线与反复

符号含义
`\`单小节线
`\\`双小节线（终止）
`\: / :\ / :\:`反复开始 / 结束 / 包围
`\/`隐藏小节线1（不显示不占空间，行首跳房子用）
`\*`隐藏小节线2（不显示但占空间，单声部变多声部用）
`[\]`跳房子（adj26）：[ 起点、`\] 终点；必须写在小节线后（行首用 \/ [）；同一个小节线区域可连续多个：\["1." 4 4 5 \]["2." 5 4 3 \]`
[修饰跳房子修饰（[ 到第一个音符之间）："注释" 番号（如 ["1."）、+ 抬高线（可多个，如 [+"1."）、/ 右侧不封闭
`\]/`跳房子开口结束（终点不封闭）
"文字"小节线备注（引号，建议数字便于播放）
小节线附加内容可任意顺序：小节线后的引号备注（如 "p:2/4" 临时节拍 / "文字" 备注）、小节线修饰符（&hs/&ty/&dc/&ds/&fine）、跳房子标记（[/]/]/）之间顺序无关，格式正确即可正常显示（如 |"p:2/4"&hs、|&hs"p:2/4"、|]/&hs、|&ds]/&hs）。音符块的注释引号与修饰符（&）同理可任意顺序（如 1&tr"注释"、1"注释"&tr）。

6. 连音线与分句

  • ( ... )：连音线（可嵌套、跨小节、跨行；分页处需切分）。括号与音符之间有空格，与虚音符 (1)（无空格）区分
  • {n: ...}：三连音/多连音（TODO：确认细节后补全）
  • &sbf：自定义声部括弧位置

7. 块间空格规则

  • 音符块与音符块之间、音符块与小节线块之间恰好一个空格（多空格或缺失解析时给出警告）
  • 连音线 ( )、装饰符号、跳房子 [ ] 为独立块，与其他块之间同样单空格

7. 歌词规则

  • 汉字一字一音，自动对齐音符
  • @：跳过一个音符（不画字）
  • ~：连字（两个字对应一个音符）
  • 标点：自动识别，不占音符位
  • - 增时线位置无需 @ 跳过

8. 多声部

  • Q1: / C1: / Q2: / C2:：声部编号（Q 后数字）
  • Q1"女声":：声部名称（双引号）
  • 非首个声部的空白用 8（隐藏休止符）和 |*（隐藏小节线）填充
  • 单声部与多声部可混合

9. 待确认项（后续迭代）

  • 临时拍号（{...} 内）细节
  • 临时多声部细节

附：快速上手示例

把下面这段 .jps 脚本粘进（Obsidian 的 ```jps 代码块，或 iJipu 编辑器）即可渲染一首简谱并试听：

V: 1.0
B: 两只老虎
Z: 法国童谣 词曲
D: C
P: 4/4
J: 120
Q: 1 2 3 1 | 1 2 3 1 | 3 4 5 - | 3 4 5 - |
C: 两只老虎 两只老虎 跑得快 跑得快

要点速览：

  • 描述头（每行一个，字母: 开头，必须）：V 版本、B 标题、Z 作者、D 调式、P 拍号、J 节拍；可选 Y 乐器、S 说明。
  • 主体行：Q: 曲（音符序列）、C: 词（歌词，自动对齐上一 Q 行音符；汉字一字一音）。
  • 音符：1-7 数字音符、0 休止符、8 隐藏休止、9 节奏音符；' 高音点、, 低音点、- 增时线、/ 减时线、. 附点、#/$/= 升/降/还原（写在数字后）。
  • 小节线与反复：| 单线、|| 终止、|: :| :|: 反复、[ ] 跳房子、"注释" 小节线备注。
  • 连音线与装饰：( ... ) 连音线（与音符间有空格）；&tr 颤音、&mp 力度等装饰写在音符后；< > 渐强/渐弱。
  • 多声部：Q1: Q2: 加声部编号，Q1"女声": 加声部名。
  • 音符注释（1"文字"）排版行为
