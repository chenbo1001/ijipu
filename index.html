在应用里试听

高低音点 ' ,、时值线 - /、附点 .、 连音线 ( )——改一个音符，就是改一个字符。 每行以命令字开头：Q: 曲、C: 词、B: 标题、V: 版本…… 完整写法看脚本语法说明（那里每个示例也是这种可切换的块， 块上还能写 v=（视图：谱面 / 满宽 / 整页）与 z=（缩放））。 另外：网页端拿不到精确的字形度量，预览用的是估算宽度，可能与编辑器里差一两个像素。

Obsidian 插件

在笔记里直接写谱

装好插件后，在任意笔记里写一个 ```jps 代码块，它就会渲染成简谱——就是右边这样 （渲染区右上角还有 ▶ 试听）。几句谱直接写在笔记里，不必为它单独建一个文件。

  • 代码块即乐谱：```jps 渲染成 SVG，多页自动分页；语法错了只提示、不打断笔记正文
  • 也能管 .jps 文件：链接或内联嵌入进笔记，双击用插件打开
  • 桌面端带完整编辑器：点左侧栏图标打开内嵌的 iJipu（手机端用 Obsidian 自己的编辑器写源码 + 语法着色与错误提示，切回「阅读视图」即看谱）
  • 试听：Web Audio 现场合成，不需要任何音频文件
  • 排版能拖：显示辅助虚线后直接拖，松手写回该谱源码的 # jps-config（与应用的设置一脉相承）
  • 默认裁到墨迹：谱面视图只显示有内容的部分，整页白边不占地方；也可切「整页 / 满宽」
  • 电脑手机都支持：Windows / macOS / Linux / Android / iOS
在 Obsidian 里安装 看源码 / 手动安装

安装：Obsidian →「设置 → 第三方插件 → 浏览」→ 搜 iJipu → 安装并启用。 手动安装则把 main.js / manifest.json / styles.css 放进 <你的库>/.obsidian/plugins/ijipu/。

常见问题

要装软件吗？收费吗？

不用装。打开网页就能写（/app/），手机、平板、电脑通吃，完全免费、无需注册。想要双击 .jps 直接打开，可以再装 Windows 桌面版。

我的谱子存在哪里？会传到服务器吗？

存在你自己的设备上——浏览器本地存储，或你指定的文件夹（工作区）。这是个纯前端工具，谱子不上传、不经我们的服务器。

和「番茄简谱」是什么关系？

爱记谱沿用 .jps 后缀与脚本语法，高度兼容它的写法，原网站导出的谱子粘贴进来基本即可使用。

手机上能用吗？没网呢？

能。手机浏览器打开即可写谱，还可以"添加到主屏幕"当 App 用。网页版支持 PWA，打开过一次之后断网也能继续用。

桌面版和网页版有什么区别？

功能一致。桌面版多了系统集成：双击 .jps 文件直接打开、可以放进右键"打开方式"。网页版则免安装、跨平台。

Obsidian 插件怎么装？

在 Obsidian 的「设置 → 第三方插件 → 浏览」，搜索 iJipu 安装；或从 GitHub 仓库手动安装。装好后在笔记里写 ```jps 代码块就能渲染。
