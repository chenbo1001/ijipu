在应用里试听

高低音点 ' ,、时值线 - /、附点 .、 连音线 ( )：改一个音符，即改一个字符。 每行以命令字开头：Q: 曲、C: 词、B: 标题、V: 版本。 完整写法见脚本语法说明；那里的每个示例也是可切换的块， 块上可写 v=（视图：谱面 / 满宽 / 整页）与 z=（缩放）。 另：网页端无法取得精确的字形度量，预览使用估算宽度，可能与编辑器相差一两个像素。

以代码的方式写谱

三种视图随时切换：编码只专注谱面，拆分左右对照、改一处看一处 （默认左谱面、右代码，方向可对调），预览只看成品、专心打磨排版。

语法有错时，编辑器直接写明「哪里错 + 正确写法」，点击即可跳到出错位置。

复杂谱面的排版

多声部、临时伴奏、反复与跳房子、倚音与波音滑音等简谱中的难点，都有对应的写法； 排版自动计算，试听时音符与色块同步跟随。

排好即可导出：PDF（矢量打印 / 位图两路）、PNG、JPG、SVG 与 MIDI，适用于打印、分享与课件。

在笔记中编写简谱

安装插件后，在任意笔记中写入一个 ```jps 代码块即可渲染成简谱， 渲染区右上角提供试听。短小的谱面可直接写在笔记中，无需为它单独建立文件。

  • 代码块即乐谱：```jps 渲染成 SVG，多页自动分页；语法错误只提示、不打断笔记正文
  • 也可管理 .jps 文件：链接或内联嵌入笔记，双击用插件打开
  • 桌面端带完整编辑器：点击左侧栏图标打开内嵌的 iJipu（手机端用 Obsidian 自己的编辑器书写源码，带语法着色与错误提示，切回「阅读视图」即看谱）

  • 排版可拖动：显示辅助虚线后直接拖动，松手写回该谱源码的 # jps-config（与应用的设置同一口径）
  • 默认裁到墨迹：谱面视图只显示有内容的部分，整页白边不占地方；也可切换「整页 / 满宽」

常见问题

是否需要安装软件？是否收费？

无需安装。打开网页即可编写（/app/），手机、平板、电脑通用，完全免费、无需注册。如需双击 .jps 直接打开，可另行安装 Windows 桌面版。

谱面保存在哪里？会上传到服务器吗？

保存在你自己的设备上：浏览器本地存储，或你指定的文件夹（工作区）。这是纯前端工具，谱面不会上传，也不经过服务器。

与「番茄简谱」是什么关系？

爱记谱沿用 .jps 后缀与脚本语法，高度兼容其写法，原网站导出的谱面粘贴进来基本可直接使用。

是否支持手机？没有网络时能用吗？

支持。手机浏览器打开即可编写，也可"添加到主屏幕"作为应用使用。网页版支持 PWA，打开过一次之后离线也能继续使用。

桌面版与网页版有什么区别？

功能一致。桌面版增加了系统集成：双击 .jps 文件直接打开、可加入右键"打开方式"；命令行工具随桌面版发布，见命令行手册。网页版则免安装、跨平台。

如何安装 Obsidian 插件？

在 Obsidian 的「设置 → 第三方插件 → 浏览」中搜索 iJipu 安装；或从 GitHub 仓库手动安装。安装后在笔记中写入 ```jps 代码块即可渲染。
