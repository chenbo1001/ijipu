# 对齐调试：给用户截图用的示例谱（`adj905t` 取证）

> 用法：打开应用 → 设置 → **调试** → 勾选「预览可视调试：边界虚线」→ 把下面每个谱
> 依次粘进脚本框 → 截图。
>
> **看什么（每次只比这两条）**：
> - 🟢 **绿线 = `segment`（段层）** 的边界
> - 🔴 **红线 = `beat`（拍子）** 的边界
>
> **合格标准**：同一小节里，**绿线与红线逐拍重合**。
> 观察点：**从第几拍开始分开、到末拍差多少**（这就是"每拍基准占宽不同"的直接读数）。
>
> 建议每次截图都**保持同样的窗口宽度与缩放**，这样像素差可直接横向比较。

## 例 1（最小复现：段层 4 个音 vs 主旋律 1 音 + 3 增时线）

```
V: 1.0
B: 例1 段层4音 vs 增时线
D: C
P: 4/4
Q: {bz 1, 3, 5, 3,} 3 - - - ||
```

**要点**：两边都是 **4 拍**。段层是 4 个**真实数字**（本体宽），主旋律是 1 个数字 + **3 条横线**（本体窄）。
按"最大本体宽度为基准"，**基准应取段层**，即主旋律那 3 条增时线要**按段层的每拍宽摊开**。

**期望看到**：绿线与红线**逐拍重合**。若红线的第 2/3/4 拍**偏右**于绿线（且越偏越多），
就是当前缺陷的指纹。

---

## 例 2（对照组：两边都是"1 音 + 3 增时线"）

```
V: 1.0
B: 例2 两边同构（对照）
D: C
P: 4/4
Q: {bz 1 - - -, } 3 - - - ||
```

**要点**：两边**本体一样**（都是一条横线）⇒ 不该有任何"基准之争"。

**期望看到**：绿线与红线**完全重合**。
⇒ 若例 2 也不齐，说明问题**不在"基准选取"**，而在更底层的"每拍宽怎么算"，方向要改。

---

## 例 3（多声部版：验证"多个声部也取最大本体宽度"）

```
V: 1.0
B: 例3 多声部 Q1 vs Q2
D: C
P: 4/4
Q1: | 1 2 3 4 ||
Q2: | 1 - - - ||
```

**要点**：这里不是段层，是**两个声部**（`Q1`/`Q2`）。按你的口径，
**多声部时同样以"最大本体宽度"为基准** ⇒ `Q2` 的 3 条增时线应**按 `Q1` 的每拍宽**摊。

**期望看到**：上下两行**逐拍对齐**。

---

## 例 4（附点对照：验证"附点那一段"的口径）

```
V: 1.0
B: 例4 附点 vs 等分
D: C
P: 4/4
Q: {bz 1, 3, 5, 3,} 3. 5 1' 2' ||
```

**要点**：主旋律含**附点**（`3.` = 1.5 拍）。
用来确认"**附点元素那一段的 `x` 是它的墨迹盒、还是时值格**"—— 这决定
`adj905o`（时值格 ⊇ 墨迹）那 16 处到底该怎么修。

**期望看到**：蓝线（本体）落在紫线（音符时值）之内；🔴 红线与 🟢 绿线逐拍重合。

## 例 6（弱起 + 增时线，边界情形）

```
V: 1.0
B: 例6 弱起
D: C
P: 4/4
Q: {bz 5, | 1, 3, 5, 3,} 5 | 3 - - - ||
```

**要点**：主旋律**弱起 1 拍**（`5 |`），段层从第 2 拍起对齐。
用来确认"锚点"在**非整小节起点**时是否仍然对齐（这一带踩过 `adj433/adj629c` 的坑）。
