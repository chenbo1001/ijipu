## OI-001 跳房子终点线 / 跳过落点 / 反复起点（`adj1005`，用户 2026-10-20 定稿）

**目标**：修「带跳房子的多段反复」的播放顺序。真实谱 `D:\蜗居笔记\悟乐居杂记\2.曲谱集\乌兰巴托的夜\乌兰巴托的夜.jps`
（结构与用户验证过的最小示例相同，但多了 `|/` 隐藏线、`{tp}` 替谱段与 `:|]` 收尾）。

**用户口径（原文要点）**：

- 跳房子 1 的范围 = **第 24–33 小节**（第 33 小节就是带 `:|]` 的那一小节）；
- **进入**跳房子：23 → 24 … 33，在 33 的 `:|` 处**回跳最近的那个 `|:`**（= 第 10 小节）；
- **跳过**跳房子：只奏到 23，**直接落到 34**（33 那节不奏——它只有 `:|]` 线、没有音）；
- 反复段起点 = `|:` **之后的第一小节**（第 10 小节），**`|/` 这类不占小节的隐藏线不得让它多走一节**。

**正确顺序（按小节号，用户两次确认）**：

```
第 1 遍：1 → 32（33 只有 :| 线）       → 回跳 10
第 2 遍：10 → 23（跳过跳房子 1）→ 34 → 43 → 回跳 36
第 3 遍：36 → 40（跳过跳房子 2）→ 44 → 54 → 回跳 47
第 4 遍：47 → 51（跳过跳房子 3）→ 55 → 结束
```

**现状（实测，引擎当前行为）**：每一轮都**多奏了跳房子之后的那几小节**，回跳点与落点一起后移，越往后偏得越多
（第 1 遍实际奏到约 37 小节，而不是 32/33）。

**根因（三处，彼此连锁）**：

1. `voltaAfterRepeat / voltaAfterStrict / voltaAfterWithFine` 取"跳房子起点之后**最近**的 `:|`/`:|:`"，
   而这份谱里跳房子**自己的 `]`** 才是终点 ⇒ 范围被拉长到吞掉过门；
2. `trySkipVolta()` 的落点在"跳过"时没有精确停在 `:|]` 之后的第一小节；
3. `|:` 处 `repeatStart = i + 1`，遇到紧跟的 `|/` 隐藏线会多走一节（用户在 9/10 之间反复核过，正解是 10）。

**要改的文件**：`packages/ijipu-engine/src/engine/playback/sequence.ts`

- `voltaAfterRepeat` / `voltaAfterStrict` / `voltaAfterWithFine` 的建表：**优先取本跳房子自己的 `|]`/`:|]`**，
  只有写成不封闭的 `|]/` 时才退回"其后最近的 `:|`/`:|:`"；
- `trySkipVolta()`：跳过时落点 = **`:|]` 那根线之后的第一小节**；`|/` 不计；
- `|:` / `:|:` 的 `repeatStart`：跳过紧跟的 `|/`（不占小节的隐藏线）。

**验收**：

1. `npm run smoke` 新增断言（用真实文件）：按小节号断言四遍顺序为
   `1..32 → 10..23,34..43 → 36..40,44..54 → 47..51,55..end`；
2. **负对照**：跳房子写成封闭 `|]` 与不封闭 `|]/` 各一例，证明两种终点取法都按上面规则走；
3. **回归必绿**（都涉及倒序/跳房子）：`adj359`（六条）、`adj723x`、`adj723aa`、`adj987u`、`adj997`；
4. `npx tsc -b` 0 错；`npm run lint` **58 警告 0 错**（基线）。
