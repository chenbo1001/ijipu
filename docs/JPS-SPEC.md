# .jps 脚本语法规范 V1.0

> 来源：原「番茄简谱」脚本说明手册（doc.lezhi99.com/zhipu）逐页逆向整理。
> 本项目兼容此规范 —— 原网站的 .jps 谱子可直接使用。
> 原始文档快照：`D:\Coding\JPCoder\_site_probe\docs\`（仅供开发参考，不随项目分发）。

## 1. 文件结构

```
描述头（多行，每行一个字段）   ← 必须
--- 简谱主体 ---
Q 行 / C 行（可重复，词依附曲）
[fenye]                        ← 手动分页
# 注释行                       ← 任意位置
```

## 2. 描述头

| 字母 | 说明 | 示例 | 必须 |
|---|---|---|---|
| V | 版本号 | `V: 1.0` | 是 |
| B | 标题（可多次；首个为主标题，其后为副标题） | `B: 排排坐` | 是 |
| Z | 作者（可多次，居右显示） | `Z: 佚名 词曲` | - |
| D | 调式（大写字母，后接 #/$ 表示升降） | `D: E` / `D: #F` / `D: $B` | 是 |
| P | 拍号（`/` 分隔；可多个，辅助拍号加括号） | `P: 4/4` / `P: 6/8 (2/4)` | 是 |
| J | 节拍（数字=每分钟拍数；或文字显示在拍号下） | `J: 96` / `J: 欢快的` | - |
| Y | 乐器（可多次，渲染在副标题下方） | `Y: 笛子` | - |
| S | 说明文字（可多次，渲染在谱尾；支持 `\n` 手动换行） | `S: 第一段\n第二段` | - |

## 3. 主体行

- **Q 行**（曲）：`Q: 音符序列`，可带声部编号与名称：`Q2"女声": ...`
- **C 行**（词）：`C: 歌词`，依附于上一个同声部 Q 行；一行曲可对多行词；标点自动识别

## 4. 音符与符号

| 符号 | 含义 |
|---|---|
| `1`-`7` | 音符 |
| `0` | 休止符（可见） |
| `8` | 隐藏休止符（占空间不显示） |
| `9` | 节奏音符 X |
| `'` | 高音点（数字后，可多个） |
| `,` | 低音点（数字后，可多个） |
| `#` / `$` / `=` | 升 / 降 / 还原（一律写在数字后方，如 `1#` `2$` `3=`） |
| `-` | 增时线（每条 +1 拍；原站格式化会拆为 `5 -`，解析须归并） |
| `/` | 减时线（n 条 = 1/2^n 拍） |
| `.` | 附点（可两个：1.5 / 1.75 倍） |
| `(1)` | 虚音符：括号紧贴单个音符（块内无空格），弱奏装饰，是音符块的一部分 |
| `1[65]` | 前倚音：`[` 紧跟音符数字，括号内可含高低音点 `' ,`、变音 `# $ =`、减时线 `/`，是音符块的一部分 |
| `1[h65]` | 后倚音：`[` 后加 `h`，其余同前倚音 |
| `&编码` | 装饰符号（拼音首字母，如 `&tr` 颤音、`&mp` 力度、`&sbf` 声部括弧位置） |
| `<` / `>` / `!` | 渐强 / 渐弱 / 结束（`<+` 调高度） |

> **音符块**：数字连同其全部修饰（高低音点、变音、时值线、附点、虚音符括号、倚音括号）构成一个音符块，块内**不用空格**分隔。

## 5. 小节线与反复

| 符号 | 含义 |
|---|---|
| `\|` | 单小节线 |
| `\|\|` | 双小节线（终止） |
| `\|:` / `:\|` / `:\|:` | 反复开始 / 结束 / 包围 |
| `\|/` | 隐藏小节线1（不显示不占空间，行首跳房子用） |
| `\|*` | 隐藏小节线2（不显示但占空间，单声部变多声部用） |
| `[\|]` | 跳房子（adj26）：`[` 起点、`\|]` 终点；**必须写在小节线后**（行首用 `\|/ [`）；同一个小节线区域可连续多个：`\|["1." 4 4 5 \|]["2." 5 4 3 \|]` |
| `[修饰` | 跳房子修饰（`[` 到第一个音符之间）：`"注释"` 番号（如 `["1."`）、`+` 抬高线（可多个，如 `[+"1."`）、`/` 右侧不封闭 |
| `\|]/` | 跳房子开口结束（终点不封闭） |
| `"文字"` | 小节线备注（引号，建议数字便于播放） |

## 6. 连音线与分句

- `( ... )`：连音线（可嵌套、跨小节、跨行；分页处需切分）。括号与音符之间**有空格**，与虚音符 `(1)`（无空格）区分
- `{n: ...}`：三连音/多连音（TODO：确认细节后补全）
- `&sbf`：自定义声部括弧位置

## 7. 块间空格规则

- 音符块与音符块之间、音符块与小节线块之间**恰好一个空格**（多空格或缺失解析时给出警告）
- 连音线 `(` `)`、装饰符号、跳房子 `[` `]` 为独立块，与其他块之间同样单空格

## 7. 歌词规则

- 汉字一字一音，自动对齐音符
- `@`：跳过一个音符（不画字）
- `~`：连字（两个字对应一个音符）
- 标点：自动识别，不占音符位
- `-` 增时线位置无需 `@` 跳过

## 8. 多声部

- `Q1:` / `C1:` / `Q2:` / `C2:`：声部编号（Q 后数字）
- `Q1"女声":`：声部名称（双引号）
- 非首个声部的空白用 `8`（隐藏休止符）和 `|*`（隐藏小节线）填充
- 单声部与多声部可混合
