# .jps 脚本语法规范 V1.0

> 来源：原「番茄简谱」脚本说明手册（doc.lezhi99.com/zhipu）逐页逆向整理。
> 本项目兼容此规范 —— 原网站的 .jps 谱子可直接使用。

## 1. 文件结构

```
描述头（多行，每行一个字段）   ← 必须
--- 简谱主体 ---
Q 行 / C 行（可重复，词依附曲）
[fenye]                        ← 手动分页
# 注释行                       ← 任意位置
```

## 2. 描述头

| 字母 | 说明 | 示例 | 必须 |
|---|---|---|---|
| V | 版本号 | `V: 1.0` | 是 |
| B | 标题（可多次；首个为主标题，其后为副标题） | `B: 排排坐` | 是 |
| Z | 作者（可多次，居右显示） | `Z: 佚名 词曲` | - |
| D | 调式（大写字母，后接 #/$ 表示升降；升降号也可写在字母前，adj174 预览时 ♯/♭ 角标显示在字母左上角） | `D: E` / `D: F#` / `D: $B` | 是 |
| P | 拍号（`/` 分隔；可多个，辅助拍号加括号） | `P: 4/4` / `P: 6/8 (2/4)` | 是 |
| J | 节拍（数字=每分钟拍数；或文字显示在拍号下） | `J: 96` / `J: 欢快的` | - |
| Y | 乐器（可多次，渲染在副标题下方） | `Y: 笛子` | - |
| S | 说明文字（可多次，渲染在谱尾；支持 `\n` 手动换行） | `S: 第一段\n第二段` | - |

## 3. 主体行

- **Q 行**（曲）：`Q: 音符序列`，可带声部编号与名称：`Q2"女声": ...`
- **C 行**（词）：`C: 歌词`，依附于上一个同声部 Q 行；一行曲可对多行词；标点自动识别

## 4. 音符与符号

| 符号 | 含义 |
|---|---|
| `1`-`7` | 音符 |
| `0` | 休止符（可见） |
| `8` | 隐藏休止符（占空间不显示） |
| `9` | 节奏音符 X |
| `'` | 高音点（数字后，可多个） |
| `,` | 低音点（数字后，可多个） |
| `#` / `$` / `=` | 升 / 降 / 还原（一律写在数字后方，如 `1#` `2$` `3=`） |
| `-` | 增时线（每条 +1 拍；原站格式化会拆为 `5 -`，解析须归并） |
| `/` | 减时线（n 条 = 1/2^n 拍） |
| `.` | 附点（可两个：1.5 / 1.75 倍） |
| `(1)` | 虚音符：括号紧贴单个音符（块内无空格），弱奏装饰，是音符块的一部分 |
| `1[65]` | 前倚音：`[` 紧跟音符数字，括号内可含高低音点 `' ,`、变音 `# $ =`、减时线 `/`，是音符块的一部分 |
| `1[h65]` | 后倚音：`[` 后加 `h`，其余同前倚音 |
| **倚音时值**（adj396） | 倚音**占用主音符的时值**：单个倚音实际时值 = **1/2^(括号内减时线条数 + 1) 拍**（写 `2[3]` → 1/2 拍；写 `2[3/]` → **1/4 拍**＝实音符的 `3//`，即「再减一半」）。**前倚音**先奏（`3[2/]`：先 1/4 拍倚音 2，再 3/4 拍主音符 3，合计仍是 1 拍）；**后倚音**后奏（`3[h2/]`：先 3/4 拍主音符 3，最后 1/4 拍才奏倚音）；**多倚音**各占各自时值依次排列（`3[3/2/]` = 1/4 + 1/4，主音符余 1/2 拍）。主音符发声时值 = 总时值 − Σ倚音时值（**总时值不变**，不向相邻音符借时间）；Σ倚音时值超过主音符时值会给出告警 |
| **增时线/附点后的后倚音**（adj396） | 后倚音可写在**增时线/附点之后**：`3 -[h5/]`、`3-[h5/]`、`3.[h5/]`、`3 .[h5/]`。主音符总时值 2 拍（或附点后的 1.5 拍），主音符**先奏满增时线/附点**（奏到末尾前），最后 1/4 拍才奏后倚音；谱面上倚音画在**增时线/附点之后**（紧靠这些元素）；无增时线也无附点的后倚音仍紧贴数字右上角 |
| `&编码` | 装饰符号（拼音首字母，如 `&tr` 颤音、`&sbf` 声部括弧位置）；力度/速度编码（`&pp` `&p` `&mp` `&mf` `&f` `&ff` `&fff` `&sf` `&fp` `&sfp`，`&rit` 渐慢）写在音符后，预览在音符上方以**斜体**显示编码 |
| `&编码+` | **加长版编码**（adj109）：编码尾部可带一个 `+`，表示该记号的**加长形态**——`&sby+`/`&xby+` 为加长波音（三齿半、更宽）、`&cy+` 为长颤音。**`&编码` 没有 `-`**：`&sby- 2` 里的 `-` 是**音符的增时线**（编码仍是 `&sby`），不是"反向/缩短" |
| `&tu` / `&ku` / `&da` / `&die` | 音符上方**单字修饰符**（adj334，写在音符后）：吐音 `&tu` → 粗体 **T**、吐音 `&ku` → 粗体 **K**、打音 `&da` → 粗体 **扌**、叠音 `&die` → 粗体 **又**（叠音又横向缩 3/4，adj335），均**居中**显示在音符正上方 |
| `&zkh` / `&ykh` | 左右括号标记（adj294）：**独立标记符**（不依附音符）——在源码哪个位置就插入一个括号符号并占宽，不对音符时值/位置施加影响。`&zkh` 左括号 `(`、`&ykh` 右括号 `)`；可写在音符前/后（如 `&zkh 6`、`6 - - -&ykh`、`1&zkh 2-&ykh`） |
| `&hx` | **呼吸（换气）记号**（adj375）：同为**独立标记符**（不依附音符），画成音符右上方的 V 形记号，**占宽与 `&zkh`/`&ykh` 相同**（基本占宽，adj376）；可写在音符前或后（`6 &hx 5` / `&hx 6 5`），格式化后两侧各留一个空格。**演奏语义**：占用**前一个音符**的总时值（= 音符时值 + 同音连音 + 增时线 + 附点）的 **1/4**、且**最多 1/2 拍**，这部分**静音**（换气）——即该音符发声 = 总时值 − 换气量，槽位长度不变（少掉的是静音，乐曲总时长/后续位置不受影响）。记号写在本行最前（左侧没有音符）时，作用于其**右侧最近的音符** |
| `<` / `>` / `!` | 渐强 / 渐弱 / 结束：`<`/`>` 写在音符后表示从该音符**正中**开始渐强/渐弱，`!` 写在音符后表示结束于该音符；预览从起点音符正中到终点音符正中画一个开口的 `<`/`>` 尖括号（hairpin，两条线从尖点向上下张开，高度与对音符间距类似连音线）。`<+`/`>++` 的 `+` 数量逐级抬升 hairpin 位置（每级 2px，类似跳房子） |
| `<` / `>` 的 `+` **只有抬升，没有 `-`** | **渐强/渐弱不提供 `-` 降低**（adj394）：`-` 在本语法中**始终是增时线**（每条 +1 拍），因此 `3<- 4` 里的 `-` 是**音符 3 的增时线**（不是"把 hairpin 降低一级"）。要抬高 hairpin 只用 `+`（`<+`、`<++`、`>+` …）；要增时就把 `-` 写在相应音符旁（如 `1- 2`、`3<---!` 表示"音符 3 增时 3 拍、渐强收在其末增时线右缘"）。**注意**：`3<- 4`（想降低）与 `3<---!`（合法增时 + 渐强收尾）在源码上完全同形，无法区分意图，故解析器**不告警**，只在本文档与编辑器提示里写明 |
| `!` 写在 `-` / `.` 后 | **终点可落在任意「有时值的元素」之后**（adj394）：起点 `<`/`>` 仍按「紧邻其前的音符」取数字槽中心，而 `!` 除写在音符后（终点 = 该音符数字槽中心）外，还可写在该音符的**增时线 `-`** 或**附点 `.`** 之后 → 终点取**该元素的右缘**。例：`1 2 3 < 4 ! 5`（结束于 4 号音符）、`1 2 3 < 4- ! 5`（结束于 4 的增时线之后，即该音符右缘）、`1 2 3 < 4-- ! 5`（更靠右，按增时线数量延伸）、`1 2 3 < 4. ! 5`（结束于附点右缘）。**渐强/渐弱不跨行**：未写 `!` 时收尾于本行行末 |
| `@乐器名` | 乐器切换指令（adj301）：从该时点起当前及以后行切换到指定乐器；乐器名按试听音色名路由（adj344 固定 SpessaSynth 高保真 GM，如 钢琴/小提琴/长笛/铜管…），不匹配回退默认乐器；不占时值、不渲染 |
| `@@` | 切回默认乐器（描述头第一个 `Y:` 指定的乐器；无 `Y:` 则音色库第一个——钢琴） |
| `"注释"` | 音符注释（adj59）：写在音符块内即显示在该音符**正上方**（居中、字号 = 音符字号的一半、灰色），如 `1"渐强" 2'"渐强_稍快"`；注释内空格用 `_` 表示 |
| `"注释"+` / `"注释"-` | **注释抬升 / 降低**（adj392）：**紧接**注释引号后的 `+`/`-` 各算一级，每级 **2px**（`+` 向上抬升、`-` 向下降低，可多个，与跳房子 `[+`/`[-`、连音线 `(+`/`(-` 同一套记法与步长），如 `1"注释"+`、`1"注释"--`、`2"高音"++`。**注意**：注释引号后紧贴的 `-` 属于注释（降低），**不是**增时线——增时线请写在注释之前（`1-"注释"`）或与注释之间留空格（`1"注释" -`）。休止符/节奏符注释（`0"转调"+`、`9"节奏"--`）同样支持 |

> **音符块**：数字连同其全部修饰（高低音点、变音、时值线、附点、虚音符括号、倚音括号）构成一个音符块，块内**不用空格**分隔。
> **乐器指令**（adj301/302）：`@乐器名` / `@@` 为独立指令块，与其他块之间同样单空格（如 `1 2 @弦乐 3 4 @@ 5 6`），不占时值、不渲染，仅播放时切换乐器。描述头 `Y:` 行指定乐器：**一个 Y 行只保留一种乐器**（多乐器写多行）；**多声部按声部序号对应 Y 行顺序**（Q1→第一个 Y、Q2→第二个 Y…），声部比 Y 行多时用默认乐器（第一个 Y 或音色库第一个——钢琴）。

> **`@...@` 包裹语法**（adj337，安全）：
> - 乐器指定推荐用 **`@` 包裹**：`@库id:乐器名["显示名"]@`；无库 id 可写 `@乐器名["显示名"]@`。**`@...@` 之间的内容不做自动化格式化**（原样保留，可含 `()`、`.`、空格等），避免 `@电吉他(清音)@` 被拆成 `@电吉他 (清音)@`。
> - **音色库前缀**（adj334）：`库id:乐器名` 指定具体音色库（如 `generaluser_gs:小提琴`）；省略库 id 时按可用乐器列表查找，同名多库取第一个。
> - **显示名**（可选）：`"显示名"` 显示在预览区标题下；缺省用纯净「乐器名」（无 `@`、无库前缀）。
> - **兼容**：旧写法单 `@乐器名`（无尾 `@`）仍可解析，但会给出**告警**，提示改用 `@...@`。
> - `@@` 仍是空包裹＝切回默认乐器。

## 5. 小节线与反复

| 符号 | 含义 |
|---|---|
| `\|` | 单小节线 |
| `\|\|` | 双小节线（终止） |
| `\|:` / `:\|` / `:\|:` | 反复开始 / 结束 / 包围 |
| `\|/` | 隐藏小节线1（不显示不占空间，行首跳房子用） |
| `\|*` | 隐藏小节线2（不显示但占空间，单声部变多声部用） |
| `[\|]` | 跳房子（adj26）：`[` 起点、`\|]` 终点；**必须写在小节线后**（行首用 `\|/ [`）；同一个小节线区域可连续多个：`\|["1." 4 4 5 \|]["2." 5 4 3 \|]` |
| `[修饰` | 跳房子修饰（`[` 到第一个音符之间）：`"注释"` 标签（如 `["1."`）、`+` 抬高线（可多个，如 `[+"1."`，每级 +2px）、`-` 降低线（可多个，如 `[-"1."`，每级 -2px，与 `+` 方向相反）、`/` 右侧不封闭 |
| `["结束句"` | **末遍房子**（adj368）：标签里有数字（`["1."`/`["2."`）按**番号 = 该遍才奏**；标签是文字且无数字（如 `["结束句"`，也可写 `["结束"` 等任意文字）时，语义是**该段最后一遍才奏**——前面的遍次跳过其内容（含 D.S./D.C. 造成的额外遍次，`pass` 更大同样奏响）。无 `:\|`（只奏 1 遍）时照常奏响，不会丢音 |
| `\|]/` | 跳房子开口结束（终点不封闭） |
| `"文字"` | 小节线备注（引号，建议数字便于播放） |

> **小节线附加内容可任意顺序**：小节线后的**引号备注**（如 `"p:2/4"` 临时节拍 / `"文字"` 备注）、**小节线修饰符**（`&hs`/`&ty`/`&dc`/`&ds`/`&fine`）、**跳房子标记**（`[`/`]`/`]/`）之间顺序无关，格式正确即可正常显示（如 `|"p:2/4"&hs`、`|&hs"p:2/4"`、`|]/&hs`、`|&ds]/&hs`）。音符块的**注释引号**与**修饰符（`&`）**同理可任意顺序（如 `1&tr"注释"`、`1"注释"&tr`）。
>
> **注释后的 `+`/`-` 归注释**（adj392）：`+`/`-` 只在**紧接注释引号**时才算注释的升降级数（`1"注释"+`、`1"注释"--`）；中间一旦隔了别的修饰符或空格就按原语义解析——`1"注释"&tr-` 的 `-` 是增时线，`1"注释" -` 的 `-`（有空格）也是增时线。既要注释降低又要增时，写 `1-"注释"` 最稳。

## 6. 连音线与分句

- `( ... )`：连音线（可嵌套、跨小节、跨行；分页处需切分）。括号与音符之间**有空格**，与虚音符 `(1)`（无空格）区分。`(` 后可跟 `+`/`-` 调整线高：`(+`/`(++` 抬升（+ 数量，每级 2px）、`(-`/`(--` 降低（- 数量，每级 2px，与 `+` 方向相反），如 `( (+ 2 3 ) 4 )`
- **`(-` 的 `-` 是连音线降低级数，不是增时线**（adj394）：与渐强/渐弱不同，连音线**确有 `-` 降低**——因为 `-` 位于 `(` 之后、属于连音线记号区。因此 `1(- 2 3)` 里的 `-` 是**连音线的降低**，不会给音符 1 增时；要给音符增时请把 `-` 写在音符旁：`1- (- 2 3)`。`(` 与音符之间**应留一个空格**（与虚音符 `(1)` 区分），紧贴且带 `+`/`-` 的写法（`1(-`）会给出告警提醒
- **`(y ... )`：等时值连音组（平均连音）**（adj395）——`(` 后紧接 `y`（大小写不敏感，`(Y` 等效）：组内音符**平分该组占用的时值**。四条规则：
  1. **组总时值 = 小节名义拍数 − 组外音符实际时值**（就是"这一小节里剩下的那一截"）。例：2/4 的 `3./ 6,// (y3/ 2/ 1/) |` —— `3./`（0.75 拍）+ `6,//`（0.25 拍）已占 **1 拍**，所以组占**剩下的 1 拍**，组内 3 个音符**各 1/3 拍**（**演奏时值也是 1/3 拍/音**）。4/4 的 `(y1 2 3) 4 |` 里组外只有 `4`（1 拍）→ 组占 3 拍 → 每音 1 拍。
  2. **占宽同样按"剩余时值"分摊**：组内每个音符的占宽 = 组总占宽 ÷ 组内音符数（**不按各自书写的 `/` 时值**）——即 `3/ 2/ 1/` 各占 1/3 拍的宽度，整组合计正好是"1 拍"该有的宽度。
  3. **减时线连成一条**：组内音符的减时线是**一整条**（一个三连音/多连音就是一个连音组），**即使该组跨越拍边界也不断开**；同时组内音符仍**与同一拍内的组外音符相连**（adj397）——减时线终究按拍成组。例：4/4 的 `2/. 3// 5/ (y5// 6// 5//) …` 里 `5/`（拍 2 起点）与组内三音（组占小节剩余 0.5 拍 → 拍 2 内）**同处第 2 拍**，故第 1 条减时线从 `5/` 一直连到组末；第 2 条只覆盖带 `//` 的组内三音（`5/` 只有 1 条线）。
  4. 弧线上方居中标注**组内音符数**（如 `3`）；普通连音线 `( ... )` 不标数字（adj43）。
  书写：`(y` 后可接 `+`/`-` 调线高（`(y+`/`(y-`，同 `(+`/`(-`）；括号与音符之间留空格。组内音符少于 2 个时不生效（退化为普通连音线）。
- `{n: ...}`：三连音/多连音（TODO：确认细节后补全）
- `&sbf`：自定义声部括弧位置

## 7. 块间空格规则

- 音符块与音符块之间、音符块与小节线块之间**恰好一个空格**（多空格或缺失解析时给出警告）
- 连音线 `(` `)`、装饰符号、跳房子 `[` `]` 为独立块，与其他块之间同样单空格

## 7. 歌词规则

- 汉字一字一音，自动对齐音符
- `@`：跳过一个音符（不画字）
- `~`：连字（两个字对应一个音符）
- 标点：自动识别，不占音符位
- `-` 增时线位置无需 `@` 跳过

## 8. 多声部

- `Q1:` / `C1:` / `Q2:` / `C2:`：声部编号（Q 后数字）
- `Q1"女声":`：声部名称（双引号）
- 非首个声部的空白用 `8`（隐藏休止符）和 `|*`（隐藏小节线）填充
- 单声部与多声部可混合

- 临时多声部细节

## 附：快速上手示例

把下面这段 `.jps` 脚本粘进（Obsidian 的 ```jps 代码块，或 iJipu 编辑器）即可渲染一首简谱并试听：

```jps
V: 1.0
B: 两只老虎
Z: 法国童谣 词曲
D: C
P: 4/4
J: 120
Q: 1 2 3 1 | 1 2 3 1 | 3 4 5 - | 3 4 5 - |
C: 两只老虎 两只老虎 跑得快 跑得快
```

## 附录 A：最小可用谱

只有描述头 + 一行曲行也能成谱（`V`/`B`/`D`/`P`/`Q` 是最小集合；`Z`/`J`/`Y`/`S` 可选）：

```jps
V: 1.0
B: 最小示例
D: C
P: 4/4
Q: 1 2 3 4 ||
```

## 附录 B：一份完整的谱（多声部 + 反复跳房子 + 力度 + 分页 + 说明）

```jps
V: 1.0
B: 完整示例
Z: 佚名 词曲
D: C
P: 4/4
J: 96
Y: 钢琴
Y: 弦乐
S: 本谱用于演示完整写法\n第二行说明
# 第一段：单声部 + 反复 + 跳房子
Q1"主旋律": 1 2 3 4 | 5 6 7 1' |["1." 1 2 3 4 :|["2." 5 4 3 2 |] ||&fine
C1: 一 二 三 四 五 六 七 八 九 十 百 千 万 里 江 山
[fenye]
# 第二段：多声部（伴奏用 8 与 |* 填充）+ 临时拍号 + 力度 + 呼吸
Q1"主旋律": @弦乐@ 1' 7 6 5 | 4 - - - |"p:2/4" 3 2 | 1 - ||
C1: 九 十 百 千 万 里 江 山 如 画 中 国
Q2"伴奏": 8 8 8 8 |* 8 - - - |* 8 8 |* 8 - |*
```

要点速览：

- **描述头**（每行一个，`字母:` 开头，必须）：`V` 版本、`B` 标题、`Z` 作者、`D` 调式、`P` 拍号、`J` 节拍；可选 `Y` 乐器、`S` 说明。
- **主体行**：`Q:` 曲（音符序列）、`C:` 词（歌词，自动对齐上一 Q 行音符；汉字一字一音）。
- **音符**：`1`-`7` 数字音符、`0` 休止符、`8` 隐藏休止、`9` 节奏音符；`'` 高音点、`,` 低音点、`-` 增时线、`/` 减时线、`.` 附点、`#`/`$`/`=` 升/降/还原（写在数字后）。
- **倚音**：`1[65]` 前倚音、`1[h65]` 后倚音；倚音**占用主音符的时值**——实际时值 = 书写减时线条数再减一半（`3[2/]` = 1/4 拍倚音 + 3/4 拍主音符，合计 1 拍），前倚音先奏、后倚音末奏；后倚音可写在**增时线/附点之后**（`3 -[h5/]`：主音符先奏满 2 拍中的 1.75 拍，最后 1/4 拍才奏倚音，谱面上倚音画在 `-` 之后）。
- **小节线与反复**：`|` 单线、`||` 终止、`|:` `:|` `:|:` 反复、`[` `]` 跳房子、`"注释"` 小节线备注。
- **连音线与装饰**：`( ... )` 连音线（与音符间有空格）；`(y ... )` 等时值连音组（组内音符平分"小节剩下的那截时值"，占宽与减时线同样按此规则，减时线连成一条并标数字）；`&tr` 颤音、`&mp` 力度等装饰写在音符后；`<` `>` 渐强/渐弱。
- **`+` 抬升 / `-` 降低 与增时线的边界**（重要）：`-` **在音符处永远是增时线**，只有写在**记号自己的区域里**才是"降低"——连音线 `(- 2 3)`、跳房子 `|[-"1."`、音符注释 `1"注"-` 三处的 `-` 属于各自记号；而渐强/渐弱**没有 `-`**（`3<- 4` 的 `-` 是音符 3 的增时线），`&编码` 也**没有 `-`**（`&sby+` 是加长版，`&sby-` 的 `-` 是增时线）。
- **多声部**：`Q1:` `Q2:` 加声部编号，`Q1"女声":` 加声部名。
- **音符注释**：`1"文字"` 显示在音符正上方（灰色小字，空格用 `_`）；`1"文字"+` / `1"文字"-` 逐级抬升/降低注释文本（每级 2px，可多个），与跳房子 `[+`、连音线 `(+` 同一套记法。
- **渐强/渐弱**：`1 2 3 <+ 4 5 6 ! 7`（`<`/`>` 从所跟音符正中开始，`!` 结束；不写 `!` 则收到行末）。`!` 也可写在增时线/附点之后（`< 4- !`），终点取该元素右缘；**不能跨行**。
