# 音色库推荐

应用**不内置**音色库：首次打开时列表是空的，装一个基础库才能出声。
下面 5 款都是免费、仍在广泛使用的 General MIDI（GM）音色库，都含完整 128 种标准音色，
拿来试听简谱或 MIDI 都够用。按体积和听感挑一个即可。

## 一款一款看

### GeneralUser GS（约 30 MB，先装这个）

效率极高：各乐器的音量平衡与包络都精调过，复杂合奏里不浑浊。日常试听、小样首选。
许可：GeneralUser GS License v2.0（允许用在软件项目里）。
下载页：<https://www.schristiancollins.com/generaluser.php>

### FluidR3 GM（约 141 MB）

开源社区的老牌经典，许多 Linux 发行版把它当默认音源；钢琴温暖、弦乐丰满，整体均衡。
想要比 GeneralUser GS 更细腻一些的听感，可以选它。许可：MIT。
下载页：<https://sourceforge.net/projects/pianobooster/files/pianobooster/1.0.0/FluidR3_GM.sf2/download>

### Arachno SoundFont（约 148 MB）

以冲击力和现代感著称：鼓组、贝斯、合成器很有力，适合摇滚、电子、游戏配乐风格的曲子。
许可：免费（具体条款以作者页为准）。
下载页：<https://www.arachnosoft.com/main/download.php?category=soundfonts>

### Timbres of Heaven（约 399 MB）

细节最丰富的免费 GM 之一，带力度分层（轻按和重按触发不同采样），真实感强；
对内存和 CPU 的占用也相应更高，低配机器慎选。许可：免费（以作者页为准）。
下载页：<https://www.midkar.com/SoundFonts/coolsoft.html>

### SGM-V2.01（约 235 MB）

日本 MIDI 社区常用，声音明亮清脆，在快节奏曲目和日系 RPG 风格配乐里表现很好。
许可：免费（原作者站点已下线，条款以镜像页为准）。
下载页：<https://musical-artifacts.com/artifacts/5826>

## 怎么装进应用

1. 从上面各条的下载页拿到 `.sf2` 文件。
2. 打开应用 →「设置 → 音色库」→ 点「添加音色库…」选中它；
   或者把它放进「我的音色库目录」（点「打开音色库目录」能直接打开），再点「重新扫描」。
3. 在列表里点「使用」，再「指定音色…」挑这次要用的音色。
   GeneralUser GS 在桌面版也可以在空界面直接点「下载基础音色库」。

## 两点说明

- **本站只链原作者或项目方的页面**，不链未标注许可的第三方合集 —— 来源与授权不可核对，
  装进应用等于把风险转给用户。
- **民族乐器**（二胡、琵琶、古筝…）在 GM 里没有采样，应用会按「拟」映射到最接近的 GM 音色，
  只是"像"、不是真实采样；要真民乐请用外部音源（可以先导出 MIDI）。
  音色库只是声音，不影响谱面内容与排版。
