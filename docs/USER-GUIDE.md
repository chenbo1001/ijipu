# 操作手册（iJipu 码上简谱）

欢迎使用 iJipu——「码上简谱」，一种用 .jps 文本编写简谱的代码式简谱制谱引擎。本手册帮助您快速上手。

## 一、界面概览

- **菜单栏**：文件 / 编辑 / 视图 / 帮助，含快捷键提示。
- **工具栏**：视图切换（编码 / 拆分 / 预览）、排版辅助开关、试听、页面设置、导出、预览缩放。
- **主区域**：按视图显示编辑器与预览；
  - `编码`：纯代码编辑。
  - `拆分`：上预览下编辑器（可拖动分隔条调整上下高度）。
  - `预览`：纯谱面渲染。
- **状态栏**：光标位置、文件信息、错误提示等。

## 二、新建与文件

- `Ctrl+N` 新建；`Ctrl+O` 打开 .jps；`Ctrl+S` 保存。
- 打开/保存支持浏览器文件系统访问（本地 .jps 文件）。
- 关闭前未保存会有脏标记（文件名旁圆点）。

## 三、编写乐谱

在编辑器里按 .jps 语法输入乐谱（详见「脚本语法」帮助）。常用快捷键：

- **行首命令**：光标在行首按 `Q`/`C`/`B`/`Z`/`D`/`P`/`J`/`V`/`H` 插入对应描述头或曲行/歌词行头。
- **自动补全**：行首输入描述头前缀、`&` 编码、`[` 跳房子、曲行 `@` 乐器等会自动弹出候选列表，`↑↓` 选择、`Enter`/`Tab` 确认、`Esc` 关闭。
- **自动格式化**：光标离开某 Q 行时自动整理格式（数字前补空格等）。

## 四、预览

- 谱面实时渲染为多页 SVG（自动分页、自动换行）。
- `+/−` 或工具栏缩放调整预览倍率（50%~200%）。
- **排版辅助虚线**：工具栏开关，打开后显示边距/行距/描述头区域辅助线，可拖动直接调整间距（描述头高度、四边距、曲部/歌词行距等）。
- 点击谱面音符 → 编辑器光标跳转；双击（试听未开时）仅联动光标。

## 五、试听播放

- 工具栏「试听」或 `Ctrl+Q` 打开试听对话框。
- 速度：30~240 拍/分（默认取 `J:` 描述头）。
- **音色**：自动（按声部名/乐器指令路由）/ 钢琴 / 风琴 / 弦乐 / 长笛 / 铜管 / 八音盒 / 采样。
- **动态色块**：播放时预览区各声部有半透明色块（不同颜色）沿拍段滑动，指示当前演奏位置；增时线、附点、连音合并都逐拍跟进。
- 点击谱面音符可跳到该处重新播放；预览区可在对话框中正常滚动/点击。
- 反复记号、跳房子自动展开播放。

## 六、页面设置

「页面设置」或工具栏按钮打开：

- 纸张（A4/A5/横/纵）、四边距。
- 行间距：曲部与词部、词部与词部、曲部与曲部、声部间距、两端对齐最小小节数。
- 字体：描述头/标题/副标题/音符/歌词/说明的字体与字号。
- **乐器显示**：勾选后在 `@` 乐器切换处的下一个音符上方标注乐器名。
- 歌词压缩：勾选后歌词宽度不足时横向缩窄（否则允许重叠）。
- 设置可保存到谱面 `# jps-config`（每首谱独立）。

## 七、导出

「导出」对话框支持：

- SVG 矢量图、PNG/JPG 图片（可选清晰度 2x/4x/6x）、PDF（A4 打印）。
- 源文件 .jps。
- **MIDI**（多声部分轨，DAW 用）、**WAV**、**MP3**（合成渲染，任何播放器可播）。

## 八、示例谱

「文件 → 示例」内置多份示例（小星星、两只老虎、二声部、连音线装饰、语法全概等），便于快速学习。

## 九、快捷键速查

`Ctrl+Q` 试听 · `Ctrl+S` 保存 · `Ctrl+O` 打开 · `Ctrl+N` 新建 · `Ctrl+Z/Y` 撤销重做 · `Ctrl+~` 快捷键 · `Alt` 打开菜单。

详见「帮助 → 快捷键速查」。
