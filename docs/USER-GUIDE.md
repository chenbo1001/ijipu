# 操作手册（iJipu 爱记谱）

欢迎使用 iJipu——「爱记谱」，一种用 .jps 文本编写简谱的代码式简谱制谱引擎。本手册帮助您快速上手。

## 一、界面概览

- **菜单栏**：文件 / 编辑 / 视图 / 帮助，含快捷键提示。
- **工具栏**：视图切换（编码 / 拆分 / 预览）、排版辅助开关、试听、页面设置、导出、预览缩放。
- **主区域**：按视图显示编辑器与预览；
  - `编码`：纯代码编辑。
  - `拆分`：上预览下编辑器（可拖动分隔条调整上下高度）。
  - `预览`：纯谱面渲染。
- **状态栏**：光标位置、文件信息、错误提示等。

## 二、新建与文件

- `Ctrl+N` 新建；`Ctrl+O` 打开 .jps；`Ctrl+S` 保存。
- 打开/保存支持浏览器文件系统访问（本地 .jps 文件）。
- 关闭前未保存会有脏标记（文件名旁圆点）。

## 三、编写乐谱

在编辑器里按 .jps 语法输入乐谱（详见「脚本语法」帮助）。常用快捷键：

- **行首命令**：光标在行首按 `Q`/`C`/`B`/`Z`/`D`/`P`/`J`/`V`/`H` 插入对应描述头或曲行/歌词行头。
- **自动补全**：输入 `&` 编码、曲行 `@` 乐器等会自动弹出候选列表，`↑↓` 选择、`Enter`/`Tab` 确认、`Esc` 关闭（描述头、跳房子已由输入工具条整段覆盖，不再弹列表）。
- **自动格式化**：光标离开某 Q 行时自动整理格式（数字前补空格等）。

### 简谱输入工具条（移动端 / PAD）

编辑器底部常驻一条**嵌入式输入工具条**（顶栏「输入条」开关控制，移动端/PAD 默认开启、PC 默认关）。它让手机用户**无需在字母与符号键盘之间来回切换**即可快速输入简谱符号（除中文歌词外）。

- **单行、可横向滑动**：主键与二级键共用同一条工具条，放不下的按键左右滑动显示。
- **主键 → 二级 → 返回**：显示主键组（音符/时值/小节线/括号/装饰/跳房子/强弱变音/描述头/乐器），点主键展开其二级键（最左是「← 返回」），点二级键插入后自动回到主键。
- **软键盘开关**：最右「⌨」按钮显示/隐藏系统软键盘（普通符号键点击不抢走编辑器焦点）。
- **自动补全保留**：`&` 修饰符、`@` 乐器仍有候选列表（提供中文说明与上下文筛选），插不进去的用工具条；二者互补。

## 四、预览

- 谱面实时渲染为多页 SVG（自动分页、自动换行）。
- `+/−` 或工具栏缩放调整预览倍率（50%~200%）。
- **排版辅助虚线**：工具栏开关，打开后显示边距/行距/描述头区域辅助线，可拖动直接调整间距（描述头高度、四边距、曲部/歌词行距等）。
- 点击谱面音符 → 编辑器光标跳转；双击（试听未开时）仅联动光标。

## 五、试听播放

- 工具栏「试听」或 `Ctrl+Q` 打开试听对话框。
- 速度：30~240 拍/分（默认取 `J:` 描述头）。
- **音色**：自动（按声部名/乐器指令路由）/ 钢琴 / 风琴 / 弦乐 / 长笛 / 铜管 / 八音盒 / 采样。
- **动态色块**：播放时预览区各声部有半透明色块（不同颜色）沿拍段滑动，指示当前演奏位置；增时线、附点、连音合并都逐拍跟进。
- 点击谱面音符可跳到该处重新播放；预览区可在对话框中正常滚动/点击。
- 反复记号、跳房子自动展开播放：跳房子标签写数字（`["1."`）按**番号**演奏（第 N 遍才奏）；写文字（`["结束句"`）表示**该段最后一遍**才奏。
- **呼吸记号 `&hx`**（独立块，可写在音符前或后，如 `6 &hx 5`）：演奏时占用**前一个音符**总时值（含同音连音、增时线、附点）的 1/4、最多 1/2 拍，作**换气静音**——该音余下部分不出声，后面的音符仍在原位继续。

## 六、页面设置

「页面设置」或工具栏按钮打开：

- 纸张（A4/A5/横/纵）、四边距。
- 行间距：曲部与词部、词部与词部、曲部与曲部、声部间距、两端对齐最小小节数。
- 字体：描述头/标题/副标题/音符/歌词/说明的字体与字号。
- **乐器显示**：勾选后在 `@` 乐器切换处的下一个音符上方标注乐器名。
- 歌词压缩：勾选后歌词宽度不足时横向缩窄（否则允许重叠）。
- 设置可保存到谱面 `# jps-config`（每首谱独立）。保存采用**差量写入**——只记录与默认不同的项（全部为默认时该行会被删除）；要把"当前全部设置"完整写进谱面（便于分享、保证任何机器上一致），用页面设置里的「**固化全部到谱面**」。
- **字体**：候选项都是跨平台字体栈（末尾带兜底字体），换机器不会掉到不合适的默认字体；若谱面指定的字体你本机没装，可在「全局」标签勾选「**用我的字体覆盖谱面字体**」。
- **编辑器字体/字号**属本机偏好（不随谱保存——别人打开你的 .jps 不会被改）。

## 七、导出

「导出」对话框支持：

- SVG 矢量图、PNG/JPG 图片（可选清晰度 2x/4x/6x）、PDF（A4 打印）。
- 源文件 .jps。
- **MIDI**（多声部分轨，DAW 用）、**WAV**、**MP3**（合成渲染，任何播放器可播）。

## 八、快捷键速查

`Ctrl+Q` 试听 · `Ctrl+S` 保存 · `Ctrl+O` 打开 · `Ctrl+N` 新建 · `Ctrl+Z/Y` 撤销重做 · `Ctrl+~` 快捷键 · `Alt` 打开菜单。

详见「帮助 → 快捷键速查」。
