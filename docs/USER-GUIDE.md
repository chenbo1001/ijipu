# 操作手册（iJipu 爱记谱）

欢迎使用 iJipu——「爱记谱」，一种用 `.jps` 文本编写简谱的代码式简谱制谱引擎。

> **怎么读这本手册？**
> · **第一次用**：按「一 → 二」走一遍，五分钟就能出第一张谱（每一步都能照抄）。
> · **用熟了想查**：直接看目录跳章节；脚本怎么写看配套的「**脚本语法说明**」（帮助 → 脚本语法说明）。
> · **卡住了**：看「十一、常见问题」。

| 我想…… | 看这里 |
|---|---|
| 认识界面 / 写出第一张谱 | §一、§二 |
| 改音符、加歌词、写多声部 | 「脚本语法说明」（帮助菜单里） |
| 调间距、字体、页面、主题、音色 | §六 设置 |
| 导出图片 / PDF / 音频 | §七 导出 |
| 保存、打开、手机上传文件 | §八 文件与保存 |
| 记住快捷键 | §九 快捷键 |
| 手机上看不到文件、导出被拦等 | §十一 常见问题 |

## 一、界面概览

- **顶栏**：「菜单」（文件 / 视图 / 播放 / 帮助）、视图切换（**编码 / 左右拆分**）、排版辅助、试听、导出、全局、谱面、预览缩放、折行、输入条、编辑器字体与字号。
- **主区域**：按视图显示编辑器与预览。
  - `编码`：只看代码；`拆分`：一边代码一边谱面；`预览`：只看谱面。
  - 拆分方向可在「全局设置 → 版面 → 左右排列」里切换（左预览右编辑 / 左编辑右预览）。
- **状态栏**：光标行列、文件名、语法检查结果。
- **问题提示条**：语法有错时出现在编辑器内，写明「哪里错 + 正确写法」，点一下跳到出错位置。

## 二、五分钟上手（照抄即可）

1. **新建**：`Ctrl+N`（或菜单「文件 → 新建」）。编辑器里会出现一份带说明的模板。
2. **写音符**：把 `Q:` 行改成你的旋律，例如 `Q: 1 2 3 4 | 5 6 7 1' ||`，谱面立刻重排
   （默认左预览右编辑，方向可在「全局设置 → 版面 → 左右排列」对调）。
3. **加描述头**：在文件开头写上标题 / 调式 / 拍号（模板里已经有了）：
   ```jps
   V: 1.0
   B: 我的第一首谱
   Z: 你的名字
   D: C
   P: 4/4
   J: 96
   Q: 1 2 3 4 | 5 6 7 1' ||
   C: 一 二 三 四 五 六 七 八
   ```
4. **加歌词**：`C:` 行一个汉字对一个音符（`@` 表示这个音符不配字）。
5. **试听**：点顶栏「试听」→「播放」。桌面端首次会自动准备随包内置音源，Web 端首次需要联网下载一次。
6. **保存 / 导出**：`Ctrl+S` 存 `.jps` 源文件；点「导出」可出图片、PDF、音频（见 §七）。

> 手机端：顶栏会收起成图标（菜单 / 视图 / 试听 / 导出 / 全局 / 谱面 / 更多）；「输入条」默认打开，常用符号点一下就插进去；
> 打不开本地文件时看 §十一。

## 三、编写乐谱

详细语法见「帮助 → **脚本语法说明**」，这里只讲编辑器层面的事。

- **行首命令**：光标在行首时按字母即插入命令头（大小写都可以，插入的永远是大写命令头）：

  - `q` / `c` → `Q: ` 曲行 / `C: ` 词行
  - `b` / `z` → `B: ` 标题 / `Z: ` 作者
  - `d` / `p` / `j` → `D: ` 调式 / `P: ` 拍号 / `J: ` 节拍
  - `y` / `s` → `Y: ` 默认乐器 / `S: ` 说明文字
  - `v` → `V: ` 版本

- **自动补全**：输入 `&` 装饰编码、`@` 乐器等会弹出候选列表（带中文说明），`↑↓` 选择、`Enter`/`Tab` 确认、`Esc` 关闭。
- **自动格式化**：光标离开某条 `Q:` 行时自动整理块间空格（数字前补空格等），不用手抠空格，也不用找「格式化」命令。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（菜单里不再放这两项，快捷键一直可用）。
- **粘贴导入**：手机端看不到本地 `.jps` 时，用「文件 → **粘贴源码导入**」把源码贴进来即可（不经过系统文件选择器）。
- **查找替换**（`Ctrl+F`）：底栏会切到「查找替换」页签（在「导入」右边）——上有**查找**与**替换**两个输入框、
  命中统计（`第 n / 共 m 处`），以及「上一个 / 下一个 / 替换 / 全部替换」四个按钮。
  - `Ctrl+F` 只**聚焦查找框**（连按不会把底栏收起来）；编辑器里若已**选中一段文字**，按 `Ctrl+F` 会**预填**进查找框。
  - 查找框里按 `Enter` = 下一个、`Shift+Enter` = 上一个；命中的内容在编辑区与预览区**同时高亮**。
  - 替换框**留空 = 删除**匹配到的内容；「全部替换」一次替换所有命中（含跨行的普通文本，按**字面**匹配，
    `#`/`$`/`[`/`]` 这类语法字符不需要转义）。

### 简谱输入工具条（手机 / PAD）

编辑器底部常驻一条**输入工具条**（顶栏「输入条」开关控制，手机/PAD 默认开、PC 默认关），
让手机用户不必在字母键盘与符号键盘之间来回切换就能输入简谱符号。

- **单行、可横向滑动**：主键与二级键共用同一条工具条，放不下的按键左右滑动显示。
- **主键 → 二级**：主键是 描述 / 时值 / 小节 / 括倚 / 装饰 / 跳房子 / 变音 / 乐器；点一下展开二级键，选完自动收起（时值、括倚、跳房子、变音组会保持展开，方便连着点）。
- **插进去的是"骨架"**：菜单项**左侧**显示的是**实际会插入的文本**（如连音线 `(`、前倚音 `[]`、后倚音 `[h]`），**右侧**是用法说明（如「前倚音：写在主音符后，如 `1[65]`」）。倚音键插完**光标停在 `]` 之前**，接着输倚音数字就行。
- **软键盘开关**：最右「⌨」按钮显示/隐藏系统软键盘。

## 四、预览

- 谱面实时渲染为多页 SVG（自动分页、自动换行）。
- `−` / `+` 或工具栏缩放调整预览倍率（50%~200%）。
- **排版辅助虚线**：工具栏开关，打开后显示边距/行距/描述头区域的辅助线，**拖虚线即可调间距**（描述头高度、四边距、曲部/歌词行距等），改完自动写进这份谱。
- 点击谱面音符 → 编辑器光标跳到对应位置（落在该**音符块的末尾、空格之前**，接着敲 `&` 修饰符就行）；双击音符（试听未开时）同样只联动光标。
- 单行短曲的小节宽度由「谱面设置 → 布局 → 两端对齐最小小节数」决定（见 §六）。

## 五、试听播放

- 顶栏「试听」或 `Ctrl+Q` 打开试听对话框。
- **速度**：30~240 拍/分（默认取 `J:` 描述头）。
- **音色**：「自动（跟随谱面声部/乐器）」或指定一个 GM 音色；可选音色来自「全局设置 → 音色库」里勾选的收藏。
- **播放 / 暂停 / 停止**：播放键是开关——播放中按一下暂停（显示「继续」），再按从暂停处接着播；点击后焦点留在按钮上，**按空格**即可暂停/继续。
- **动态色块**：播放时各声部有半透明色块沿拍段滑动，指示当前演奏位置。
- 反复记号、跳房子自动展开播放（标签写数字按番号奏；写文字表示"最后一遍才奏"）。
- **标记段（练一小段）**：试听区下方那排就是「标记段」按钮组，用来把一小段标起来反复练。
  - **怎么标**：在谱面上点一个音符 → 按「**起始**」；再点另一个音符 → 按「**停止**」；两端都标好后按「**添加**」，
    生成「段 1」并自动选中。
  - **演奏怎么走**：选中某段后按播放 ⇒ **只播这一段**；下拉第一项「**无（演奏全曲）**」是默认值、**不可删除**。
  - **循环**：按「⟲」打开 ⇒ 这一遍奏完**静默 3 秒**再从头（用户口径：既分得清循环位置，也给练习留气口）；
    每遍开始前在**起始音左侧**显示 **3-2-1** 白底圆形倒数，倒数结束才出声；倒数途中按停止会立刻取消。
  - **谱面上怎么看**：这一段覆盖的音符下方画一条**青色细线**（每行一段，不铺底色以免抢播放色块）；
    两端各有一个小竖头；**循环开启时两端换成一个 ⟲**（代替竖头，更明确）；只在试听面板打开时显示。
  - **跨行与反复**：允许跨行、也允许"起始在停止之后"（`:|` 回跳 / 跳房子）——线按**演奏顺序**逐行画，
    跳过去**不演奏**的段落**不会**画线。
  - **遍次**：同一对起止在展开后对应多处时，按钮组会多出一个「**遍次**」下拉（第 N 遍 / 含跳越），
    你选的那一遍会被记住。
  - **停止音要奏完**：停止音自己的**附点 / 增时线**一定会完整奏完；
    想连到**连音线末尾**，请把「停止」标在那条线的**最后一个主音**上（连音线**不自动判断**）。
  - **保存位置**：标记段按**文档**记在本机缓存（工作区 / 本地文件 / 文件名三种键），**不写进 `.jps`**；
    换台机器打开同一份谱不会带过去。
  - 左上角的「▾」可**收起整组**（收起后展开按钮挪到**歌名前**，不额外占一行）。
- **音源**：桌面端随安装包内置（`<安装目录>\generaluser_gs.sf2`），装上就能听、不提示下载；Web 端首次联网下载一次后缓存在本机。

## 六、设置

顶栏的「**全局**」「**谱面**」两个按钮（或菜单「设置 → 全局设置… / 谱面设置…」）分别打开底栏的两个设置页签：

| 底栏页签 | 子页签 | 管什么 | 是否随谱保存 |
|---|---|---|---|
| **全局** | 版面 | 左右排列方向、输入条开关、自动折行、排版辅助虚线、编辑器字号/字体、字体覆盖 | 本机偏好，不随谱 |
| **全局** | 主题 | 浅色 / 深色 / 跟随系统 + 中国色主题配色 + **预览柔化（关 / 轻 / 中）** | 本机偏好，不随谱 |
| **全局** | 音色库 | 试听/导出用音源与 GM 音色勾选、导入导出音色文件与收藏 | 本机偏好，不随谱 |
| **谱面** | 布局 | 纸张与边距、间距（描述头高 / 首行至描述头 / 曲部与曲部 / 曲部与词部 / 词部与词部 / 曲部与上词部 / **声部间距**）、临时段（bz / dsb 段上下间距）、音符布局（空间优先/时值优先、连音线样式、**两端对齐最小小节数**） | **随谱保存**（写进 `# jps-config`） |
| **谱面** | 字体 | 描述头/标题/副标题/音符/歌词/说明的字体与字号、是否显示乐器名、歌词压缩 | **随谱保存** |

- **谱面设置**在面板里**即时预览**：调完点「**保存设置**」才写进谱面；直接关掉则恢复原样。
  「全局」那三个子页签是**本机偏好**，改一下即时生效，因此**没有**「保存设置」按钮。
- 「谱面」页签里，**与默认值不同**的设置项，标签后会有一个**红色 `*`**——「保存设置」会写哪些项，一眼就能看出来。
- **预览柔化（关 / 轻 / 中，默认「轻」）**：只降低预览的刺眼感，**不影响导出**。
  · **深色**：纸底由纯黑抬到中性深灰、墨色由纯白收到浅灰（黑底白字不再扎眼）；
  · **浅色**：只把**纸张色**从纯白换成米黄（轻 `#FDFBF5` / 中 `#F7EFDD`），字与线不动、不糊；
  · 页面有**背景图**时图在纸色之上；图只覆盖一部分时，露出来的边距就是这个纸色（不会出现白块）。
- 保存采用**差量写入**：只记录与默认值不同的项（全是默认时设置行会被删掉）。改动一项，`*` 立刻出现；改回默认值，`*` 立即消失。
- **谱面自包含（adj480）**：版面设置只有两层——**代码默认值 ← 谱面自带的 `# jps-config`**，程序**不再在本机另存一份"页面设置"**。
  因此"你看到的"只由「默认值 + 谱面」决定：把源码复制给别人（或在别的机器/浏览器打开）显示一致；
  唯一的例外是**字体**——字体**族**随谱走，但对方机器上未必装了这个字体，会按字体栈回退（详见下面「字体」那条）。
- 「**恢复默认**」把当前草稿改回默认值（仍需点「保存设置」才落盘）。
- **单行曲部的小节槽**：一段曲部只有一行时（新建文件、示例谱那种），若小节数少于「两端对齐最小小节数」（默认 4），整行按该值**预分小节槽**——每小节占一个槽、槽内音符自动摊开，行尾留白；某小节内容放不下则按自身自然宽度排开。这样 1~3 小节的短谱不会挤在左边一小块。
- 字体候选都是**完整字体栈**（末尾带兜底字体），换机器不会掉到不合适的默认字体；谱面字体本机没有时，可在「全局」勾选「用我的字体覆盖谱面字体」。
- **编辑器字体/字号**属本机偏好，不会被写进谱面。

## 七、导出

「导出」对话框支持：

- **SVG** 矢量图；**PNG / JPG** 图片（2x / 4x / 6x 清晰度）。
- **导出底色**（默认 **透明**）/ **带上背景图**（默认 **不带**）——两项**独立**：
  · 底色可选 **透明 / 白 / 纸色（跟随预览柔化的纸色档位）**；PNG 支持透明，**JPG / PDF 没有透明通道 ⇒ 透明档按白底导出**；
  · 关掉背景图时，页面边距露出来的是**纸色**（不是白块）；
  · 导出**永远按浅色纸面**输出——深色主题只是预览的显示效果，不会带进图片/PDF（打印同样）。
- **PDF 文档（打印·矢量）**：调起**系统打印对话框**，目标选「另存为 PDF」即可——**矢量输出、放大不糊**，
  且打印走**当前窗口**（不开新窗口 ⇒ 不会被"弹窗拦截"拦下）。**默认文件名 = 谱面第一个 `B:` 的值**（标题）。
- **PDF 图片（位图）**：一键直接下载 `.pdf`（不经对话框），清晰度跟随上面的档位——
  适合"不想过打印对话框"或需要固定分辨率的场合；文字不可选中、放大会糊。
- **源文件 `.jps`**：把当前源码导出到本机。
- **MIDI**（多声部分轨，给 DAW 用）、**WAV**、**MP3**（离线渲染，任何播放器可播）。
- **动态谱视频（桌面版专属）**：桌面端「导出 → 动态谱视频」或试听「标记段 → 导出这段动态谱」，
  在预览区打开相机位；支持 **9:16 / 1:1 / 16:9**、**3 分钟 / 整首**、**整曲 / 标记段**，生成带声音的 MP4；
  片头片尾卡片模板、自定义卡片与 zip 迁移见 **§13.2**。**网站与 Obsidian 插件不显示这个入口**。
- 导出音频需要音源：应用不再随包带音色库；先在「设置 → 音色库」下载/导入并「使用」一个库（见 §13.1）。

## 八、文件与保存

- `Ctrl+N` 新建、`Ctrl+O` 打开、`Ctrl+S` 保存、`Ctrl+Shift+S`（菜单「另存为」）另存。
  - **新建会先问一句**（`adj963`）：当前文档有未保存的修改时，会先弹确认条问"要不要丢弃"——
    新建只是换上一份空白模板，**磁盘上的原文件不受影响**。
- **打开示例**（菜单「文件 → 打开示例…」）：列出随应用提供的示例谱（如《茉莉花》《送别》），点一条即载入编辑器，可以直接改、也可以另存为自己的谱。
- **打开**支持 `.jps`，也支持把 `.md` / `.txt` 当文本读入（文件选择器里看不到 `.jps` 时可改扩展名，见 §十一）。
- **拖进来就能打开**（`adj968`，用户要求）：从文件管理器把 `.jps` **拖到窗口里**松手即可打开——
  - 窗口上方会先亮一层「松开即打开「xxx.jps」」的提示（拖的不是 `.jps` 就不会亮）；
  - **桌面端**：拿到的是真实路径，打开后**能写回原文件**（与双击打开同一条链）；
  - **网页版 / PWA（Chrome、Edge）**：拖放给的是可写句柄，同样**能写回**（首次可能问一次权限）；
  - **Firefox / Safari**：只能读入内容（保存请用「另存为」/导出，界面会提示）；
  - 一次拖多个只打开**第一个** `.jps`（其余会提示未打开）；当前文档有未保存改动时**先问一句**再替换。
- **保存**按**你在哪儿用**自动选路（`adj963` 把这条判定收在一处，菜单与 `Ctrl+S` 完全一致）：
  - **桌面端**：系统保存对话框（选定位置后写回；双击打开的 `.jps` 直接写回原文件）；
  - **网页版（桌面浏览器）**：同上，读写用浏览器的文件系统访问能力；
  - **网页版（手机 / 不支持的环境）**：打开**工作区底栏**，在面板里选位置、填名字保存；
  - **Obsidian 插件（嵌入版）**：打开**「保存到工作区」对话框** —— 填文件名（默认取描述头第一个 `B:`）+ 点选文库里的子目录。
- 未保存时文件名旁有圆点标记。
- **粘贴源码导入**（菜单「文件 → 粘贴源码导入」）：不依赖系统文件选择器，适合手机端从微信/网盘复制过来的源码。
- **PWA**：手机浏览器打开站点后「添加到主屏幕」即可当作 App 用；有新版本时页面顶部会提示「发现新版本，点击刷新」。

## 十、界面小技巧

- 顶栏按钮太多时，放不下的会收进「更多」下拉（窗口变宽会自动放回来）。

## 十一、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 手机「打开」里看不到 `.jps` | 文件还在网盘/微信里没落到本机，或系统按类型隐藏了未知扩展名。**处理**：① 先把文件保存/下载到本机；② 从「下载」目录找；③ 把扩展名改成 `.md`/`.txt` 也能按文本读入；④ 用「文件 → 粘贴源码导入」把源码贴进来 |
| 「打开」点了没反应（没弹选择器） | 个别手机浏览器/PWA 会静默失败。**处理**：改用浏览器打开本站，或用「粘贴源码导入」 |
| 已安装的 PWA 里键盘把编辑区盖住 | 更新到最新版（viewport 已适配软键盘）；仍不行时用浏览器打开 |
| 导出 PDF 被提示"拦截弹窗" | **不会**：`Ctrl+P` / 菜单「打印」/ 导出的「PDF 文档（打印）」都在**当前窗口**打印，不开新窗口；若在打印对话框里没看到"另存为 PDF"，装一个系统虚拟打印机（Windows 自带「Microsoft Print to PDF」）或改用「PDF 图片（位图）」一键下载 |
| 打印/另存的 PDF 文件名不对 | 默认名取**谱面第一个 `B:`（标题）**；没有 `B:` 时用当前文件名。想换名字就改 `B:` 那一行 |
| 试听没声音 | 应用不再随包带音色库：先到「全局设置 → 音色库」下载/导入一个库，点「使用」切为当前库，并确认勾了音色；官网 [音色库推荐](/soundfonts/) 有下载入口 |
| 谱面不跟着改 | 看编辑器的问题提示条：有语法错误时该处不会正常渲染 |
| 手机上界面挤 | 顶栏会自动收进「更多」；也可用横屏、或在「全局设置 → 版面」关掉输入条 |

## 十三、音色库、动态谱视频与卡片风格（v0.71.0）

### 13.1 音色库

- **首次为空**：应用不再随包带音色库；第一次打开「全局设置 → 音色库」时列表是空的，按提示下载或导入。
- **添加音色库**：
  - 桌面端可在「音色库 → 发现」扫描目录、读 SF2 头并导入到“我的音色库”；
  - 下载推荐库请看官网 **[音色库推荐](/soundfonts/)**（只链原作者页面），下载后在应用里「添加音色库…」；
  - 桌面端下载会走系统 curl，带进度，不受浏览器 CORS 限制。
- **资源安装包目录**：桌面端额外识别 `%LOCALAPPDATA%\iJipu\soundfonts`。以后发「资源包」时，把库放到这里即可，不必再逐个导入。
- **安装资源包**：在 GitHub 的**独立资源 Release**（`releases/tag/resources`）里按需下载**单个**资源安装包，
  例如 `iJipu-SoundFont-GeneralUserGS_1.471.0_x64-setup.exe`、
  `iJipu-SoundFont-FluidR3GM_1.0.0_x64-setup.exe`、
  `iJipu-Tool-FFmpeg_1.0.0_x64-setup.exe`。安装器会自动找主程序目录（校验 `ijipu.exe`），
  只装这一个资源文件；装完在「音色库」里点「使用」即可。**资源安装包不随应用版本升级**，
  只有资源本身更新时才发新版本。卸载主程序时会问 **完全卸载 / 保留音色库与资源包**
  （默认保留，下次安装直接复用）；每个资源也能在「应用和功能」里单独卸载。
  命名规则见 `docs/INSTALLER-NAMING.md`。
- **使用与收藏**：列表里点「使用」切换当前音色库；每个库有自己的一套收藏音色；换库会自动重建播放后端。
- **民族乐器**：显示带「（拟）」的拟声映射；在音色页勾选后才参与试听/导出。

### 13.2 动态谱视频（**仅桌面版**）

- **入口**：桌面端「导出 → 动态谱视频」或试听「标记段 → 导出这段动态谱」，会在**预览区**打开相机位；
  网站与 Obsidian 插件**不显示**入口和相机位（性能与浏览器限制，后续再评估）。
- **画面**：不重排你的谱面，按相机取景；支持 **9:16 / 1:1 / 16:9**，可选 **3 分钟 / 整首**、**整曲 / 标记段**。
- **片头/片尾**：「卡片」前面那个**复选框**（悬浮提示「带片头片尾」，默认勾选）控制成片要不要它们。
  勾着时是 3 秒自制标题卡（标题/作者/调号/拍号/速度）+ 0.7 秒推近到第一拍，片尾是品牌落版；
  **不勾就只导出动态谱**，画面直接从第一拍开始，预览也立刻按这个口径重画（`adj1113` / `adj1116`）。
  片尾网址按**完整地址**显示（含 `https://`），照抄即可打开。
- **封面**：成片自带封面 = 片头标题卡的**完整帧**（第 3 秒那一帧）；不带片头片尾时取**第一拍画面**。
  系统缩略图与播放器封面直接显示它，不再是一片空背景（`adj1111` / `adj1113`）。
- **跳跳球**：每拍落在当前拍色块上，落地压扁；跨行、反复、跳转按展开后的实际演奏顺序走。
- **生成视频**：`生成视频` 用 WebCodecs 编码 MP4（含声音）；桌面壳 WebView 需要支持 WebCodecs，
  不支持时会禁用并提示。
- **导出位置**：生成完成后按系统保存对话框选择目录和文件名。

### 13.3 卡片模板与自定义

- 相机位「卡片」下拉提供 4 个预设：**深空蓝 / 纸面 / 水墨 / 极简**；选择保存在本机（L1），不写进 `.jps`。
- 点「自定义…」可编辑：
  - 标题字体（跟谱面/衬线/无衬线）、背景三段色、强调色、标题渐变、各文字颜色；
  - 水印字符/颜色/透明度/大小、粒子/扫光/动效、五线谱透明度、暗角、朱砂印章；
  - **背景图片**（≤2.5MB，自动压一层主题色保证标题可读）。
- **模板迁移**：「导出模板 zip」把当前设计 + 背景图打成一个 zip（默认 `ijipu-card.zip`，可选保存位置）；
  「导入模板 zip」先回填到对话框，检查效果后再点「保存并应用」。
- 片尾品牌（爱记谱 iJipu + 标语 + 网址）在所有模板里都会保留。
