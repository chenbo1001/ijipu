+ 之前两条：「默认为按正常 **100%** 的缩放比率来显示」✓、「```jps z=100 … **z=\*** 以实现目前的**自适应笔记宽度**」✓。

⇒ 三者合起来就是**一套几何 + 一个显示倍率** ✓（不存在两套口径 ✗）：

| 概念 | 语义 | 备注 |
|---|---|---|
| **墨迹盒** | 谱面内容（音符/歌词/线）的**墨迹**包围盒 ✓ | 唯一的几何来源 ✓；**退化盒（<40px）视为量取不可靠 ⇒ 退回按边距裁剪** ✓（`MIN_INK` 闸 ✓） |
| **谱面视图的 viewBox** | **墨迹盒 + 每边 2px** ⇒ `(w+4) × (h+4)` ✓ | **= 「导出谱面」的同一份几何** ✓（一处口径，两处消费 ✓） |
| **页面视图的 viewBox** | 整页（A4 等 ✓） | 不变 ✓ |
| **显示倍率 `z`**（代码块 info string ✓） | `z=100`（**缺省**）⇒ 1 viewBox 单位 = **1 CSS px**（自然尺寸 ✓，**不放大** ✗）；`z=n` ⇒ n%；**`z=*`** ⇒ **铺满容器宽度**（上线前的行为 ✓） | 只影响**屏幕显示** ✓ |
| **导出谱面** | 墨迹 + 每边 2px ✓（画布 = `(w+4)×(h+4)` ✓） | **不受 `z` 影响** ✓（导出与显示分离 ✓） |
| **导出页面** | 整页 + 留白 ✓ | 同上 ✓ |

**据此要改的三处**（下一轮实施 ✓）：
1. **`z` 应用层**：把 `JpsBlockRange.zoom`（已解析 ✓）从代码块渲染处传进面板 ✓，
   并把 SVG 的**渲染宽度**设为 `viewBox宽 × z/100` px ✓（`z=*` ⇒ `width: 100%` ✓）；
2. **谱面视图**：确保 viewBox = 墨迹 + 每边 2px ✓（即"只显示墨迹 ✓"，不显示整页高度 ✓）——
   若当前某个块显示整页高度 ✗，优先查"该块的视图模式是否被记成了页面/整页"✓ 与"墨迹盒是否触发了退化闸"✓；
3. **作用域**：`z` **先只对"笔记里的代码块"生效** ✓（`.jps` 文件视图/嵌入块暂保持现状 ✓，
   否则全屏文件视图会突然缩到 595px 宽 ✗）；若要一并支持，用设置项控制 ✓（待用户定 ✓）。

**验收** ✓：`z=100`（缺省）时单行曲部**不再被放大** ✓、谱面视图**只有墨迹 + 2px** ✓；
`z=50` 变一半 ✓；`z=*` 铺满栏宽 ✓；导出谱面仍 = 墨迹 + 2px ✓（与屏显无关 ✓）。
