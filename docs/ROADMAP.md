## M1 排版渲染引擎 —— 谱子可见 ★核心

> 目标：`.jps → 解析 → 排版 → SVG`，三视图预览显示真实乐谱。
> 拆为三步，每步独立可验收。

### M1a 单行音符渲染（音符能画出来）

- **内容**：
  - render：SVG 页面骨架（A4 白纸、边距、标题/作者/调号/拍号/节拍元数据）
  - 数字字形 1 套（样式 b 起步，SVG path 自绘或字体方案）
  - 音符绘制：高低音点、变音符号（#/$/=）、增时线、减时线、附点、休止符 0、节奏符 9
  - 小节线绘制：`|` `||` `|:` `:|` `:|:`
  - layout：单行音符横向排列（按 token 宽度累积 x 坐标），忽略换行/分页
- **验收**：`Q: 1'- 2,,$ 3// 4. | 0 8 9 ||` 一行渲染正确；每个音符带稳定 `data-notepos` 属性
- **工作量**：M ｜ **风险**：字形绘制质量

### M1b 换行与分页（一页谱能排出来）

- **内容**：
  - 行内自动换行（按页面可用宽度断行）
  - 手动分页 `[fenye]` → 多页渲染
  - 多行谱面纵向排布（行距来自页面配置默认值）
- **验收**：小星星（3 曲行）渲染为一页完整谱；插入 `[fenye]` 后变两页
- **工作量**：M ｜ **风险**：断行边界（连音线跨行留待 M7）

### M1c 歌词对齐与元数据（完整的一页谱）

- **内容**：
  - 歌词逐字对齐音符（一字一音、@ 跳过、~ 连字、标点自动跳过）
  - 一行曲多行词（C 行多行堆叠）
  - 标题居中、副标题、作者居右、调号/拍号/节拍绘制
  - PreviewPane 接入真实渲染，实时刷新（拆分视图）
- **验收**：小星星歌词逐字对位；修改代码预览即时更新
- **工作量**：M ｜ **风险**：歌词对齐精度

**M1 里程碑验收**：三视图可用；排排坐/小星星/两只老虎渲染正确；`npm run smoke` 全绿；git tag `m1`

## M2 编辑器 IDE 化

- **内容**：
  - 行号栏；错误行标记 + 悬停错误提示（行/列定位）
  - 行首命令快捷键（Q/C/B/Z/D/P/J/V/H 在行首插入）
  - 自动格式化完善（光标位置保持、格式化预览 diff 高亮，可选）
  - 高亮完善：`&` 装饰编码、渐强渐弱、多声部编号着色
- **验收**：输入体验接近 VS Code；错误即时可见可定位
- **工作量**：M ｜ 依赖：M0

## M3 光标双向联动

- **内容**：
  - 编辑器光标移动 → 谱面对应音符高亮光标块 + 自动滚动（依赖 M1a 的 data-notepos）
  - 点击谱面音符 → 编辑器光标跳转对应位置
  - 播放联动基础（光标跟随播放，为 M4 铺垫）
- **验收**：任意位置双向互跳，误差 ≤1 音符
- **工作量**：M ｜ 依赖：M1a

## M4 试听播放

- **内容**：
  - 合成音色后端（Web Audio 振荡器+包络，零依赖）
  - 播放队列：音符序列 + 时值（已有 duration.ts）→ 定时播放
  - 反复记号：`|:` `:|` 反复展开、跳房子第一遍/第二遍
  - 播放控制：速度 30~200 拍/分（默认取 J 描述头）、暂停/停止、自动滚屏、音符高亮
  - 采样音源后端（钢琴采样，按需加载，可切换）
- **验收**：两只老虎按反复记号正确播放；切换音色正常
- **工作量**：L ｜ 依赖：M1a、M3（高亮）

## M5 页面设置生效

- **内容**：
  - 纸张（A4/A5/横版）与四边距接入渲染
  - 标题/副标题/歌词字体字号；音符字形 a/b/c 三套
  - 行距（曲上/曲下/词下/声部）接入；按页覆盖（heights）
  - 连音线样式（自动/圆弧/平顶，绘制于 M7 同步实现）
- **验收**：修改设置即重排；设置随谱子持久化（localStorage）
- **工作量**：M ｜ 依赖：M1b

## M6 导出能力

- **内容**：
  - SVG：多页分别下载
  - PNG / JPG：SVG → canvas（白底、指定分辨率）→ 下载
  - PDF：浏览器打印（A4 页面化）或 jsPDF 合成多页
- **验收**：多页谱三种格式导出内容与预览一致
- **工作量**：M ｜ 依赖：M1b

## M7 多声部与复杂符号（专业制谱）

- **内容**：
  - 多声部渲染：Q1/Q2 纵向堆叠、声部括弧、声部名称、`&sbf` 括弧位置
  - 跳房子渲染：`[ ]` 起点/终点/跨行、`[/` 不封闭、`[+` 高度调整
  - 连音线绘制：圆弧/平顶、嵌套、跨小节（跨行/跨页切分）
  - 装饰符号库：`&tr` 颤音、`&mp` 力度、渐强渐弱 `< > !` 等
- **验收**：多声部示例谱渲染正确；跳房子/连音线样式符合简谱规范
- **工作量**：L ｜ 依赖：M1c

## 实施顺序建议

```
M1a → M1b → M1c →（M2 ‖ M3 ‖ M4 可并行策划，串行实施）→ M5 → M6 → M7
                                                   ↘ M8 → M9 → B1-B3 → T1/F1
```

- **M1a→M1c** 必须连续完成（核心引擎）。
- **M2/M3/M4** 三者在 M1 之后可按价值排序：M2（体验）→ M3（联动）→ M4（试听）。
- **M8/M9** 可穿插于任何空档，不阻塞主线。
- 每期结束：`npm run build` + `npm run lint` + `npm run smoke` 全绿，git 里程碑提交。
