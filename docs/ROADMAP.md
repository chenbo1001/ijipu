## M1 排版渲染引擎 —— 谱子可见 ★核心

> 目标：`.jps → 解析 → 排版 → SVG`，三视图预览显示真实乐谱。
> 拆为三步，每步独立可验收。

### M1a 单行音符渲染（音符能画出来） ✅

- **交付**：SVG 页面骨架（A4 白纸、边距、标题/作者/调号/拍号/节拍元数据）；数字字形（衬线粗体）；音符绘制（高低音点/变音/增时线/减时线/附点/休止符/节奏符）；小节线（`|` `||` `|:` `:|` `:|:`）；layout 单行横向排布；`data-notepos` 契约；音高映射（调式→audioPitch）。
- **git tag**：`m1a`

### M1b 换行与分页（一页谱能排出来） ✅

- **交付**：行内自动换行（按页面可用宽度断行）；`[fenye]` 手动分页 → 多页渲染；多行谱面纵向排布（行距）。
- **git tag**：`m1b`

### M1c 歌词对齐与元数据（完整的一页谱） ✅

- **交付**：歌词逐字对齐音符（一字一音、@ 跳过、~ 连字、标点自动跳过）；一行曲多行词堆叠；`data-cipos` 契约；PreviewPane 实时刷新。
- **git tag**：`m1`

**M1 里程碑验收**：三视图可用；排排坐/小星星/两只老虎渲染正确；`npm run smoke` 全绿 ✅

## M2 编辑器 IDE 化 ✅

- **交付**：行号栏（滚动同步、错误行红标 + 悬停错误消息）；行首命令快捷键（Q/C/B/Z/D/P/J/V/H，仅行首触发）；自动格式化（防抖 + 光标公共前缀保持）；语法高亮完善（`&` 装饰、渐强渐弱、多声部编号、错误行红底）。
- **git tag**：`m2`

## M3 光标双向联动 ✅

- **交付**：`engine/cursorMap.ts` 双向映射纯函数（光标位置↔音符 id，含分页/多声部/全局计数语义）；编辑器光标移动 → 谱面音符红标高亮 + 平滑滚动；点击谱面音符/歌词 → 编辑器光标跳转 + 滚动定位。
- **git tag**：`m3`

## M4 试听播放 ✅

- **交付**：`sequence.ts` 播放序列构建（`|:` `:|` 两遍反复、`:|:` 包围反复、跳房子 `[ ]` 第一遍/第二遍、`||` 终止、隐藏休止占时不发声、bpm 推断）；`synth.ts` Web Audio 合成音色（振荡器+泛音+指数包络，零依赖）；`sampler.ts` 采样后端（外部 soundfont，可切换、失败回退合成）；PlaybackDialog（速度 40~200、音色切换、播放/停止、播放高亮+自动滚屏复用 M3 联动）。
- **git tag**：`m4`

## M5 页面设置生效 ✅

- **交付**：纸张（A4/A5/横版，PAPER_SIZE 全接入）与四边距；标题/副标题/歌词字体字号；**三套音符字形**（a 衬线/宋体、b 黑体默认、c 楷体，字体方案替代原站 SVG path）；行距（曲上/曲下/词下）接入 layout 与歌词定位；**按页覆盖行距**（config.heights['a'+page]）；pageConfig 持久化（localStorage）。
- **git tag**：`m5`

## M6 导出能力 ✅

- **交付**：`export/export.ts` 纯前端导出（零第三方依赖）：SVG 逐页下载；PNG/JPG（SVG→canvas 白底 2x 高清，多页逐页）；PDF（A4 页面化新窗口 + 浏览器打印另存）；语法错误拦截；.jps 源文件下载。
- **git tag**：`m6`

## M7 多声部与复杂符号（专业制谱） ✅

- **交付**（4 子项，tags `m7a`~`m7`）：
  - **M7a 多声部**：声部块识别（连续不同声部组）、按小节宽度取 max 对齐堆叠、块级小节线跨声部、声部括弧（大括号）+ 声部名称（`Q1"男声"` 或默认"声部N"）、多声部+单声部混合排版
  - **M7b 跳房子**：`[ ]` 起点竖线+水平线+终点折线、`[/` 未封闭向右延伸、`[+` 高度调整、番号（小节线引号备注）显示在线起点上方、独立 `[` 继承番号
  - **M7c 连音线**：`()` 栈匹配、二次贝塞尔圆弧 / 平顶（`lianyinxian_type`）、嵌套深度错开、跨行/跨页跳过（第一版限制）
  - **M7d 装饰符号**：`&tr` 颤音（tr+波浪线）、`&mp` 等力度文本、渐强渐弱 `< > !` 楔形（含行尾未闭合）
- **git tag**：`m7a` `m7b` `m7c` `m7`

## 实施顺序建议

```
M1 ✅ → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9 → T1（桌面）→ B1-B3（云端）
```

- **M 系列**：本地核心功能，按 M2（体验）→ M3（联动）→ M4（试听）→ M5 → M6 → M7 推进；M8/M9 可穿插。
- **T1 桌面打包**：M 系列完成后实施（本地优先原则）；Rust 工具链安装与沙箱实测为其第一步。
- **B1-B3 云端**：最后实施（用户明确：先实现本地化功能，再考虑上网服务）。
- 每期结束：`npm run build` + `npm run lint` + `npm run smoke` 全绿，git 里程碑提交。
- **每次出错**：30 分钟内记录到 docs/ERRORS-LOG.md（现象/根因/解决/预防），并复核其预防清单。
