# 音色库与乐器指定语法规格（adj33x / adj344）

> 本文档定义「音色库 + 乐器」的指定语法与语义。属于 `.jps` 语法规范的一部分，
> 改动解析器后需同步 `docs/SYNTAX.md`（《脚本语法说明》）并在 `scripts/smoke.mts` 补断言。
>
> **adj344（试听简化）**：试听**固定 SpessaSynth 高保真**音源——不再提供「合成（快速）/
> midi-js 采样（高质量）」切换；「音色库」下拉移除（固定默认内置库）；导出音频同样改为
> SpessaSynth 高保真离线渲染。合成/midi-js 后端在 engine 中保留为兼容代码（标注废弃），
> 但不再作为试听用途。

## 1. 乐器引用（`@` 包裹，格式化安全）
为防自动格式化破坏乐器名（如 `@电吉他(清音)` 被拆成 `@电吉他 (清音)`），乐器指定改为 **`@` 包裹**：
- `@库id:乐器名["显示名"]@`
- 无库 id：`@乐器名["显示名"]@`
- 无显示名：`@库id:乐器名@` / `@乐器名@`

**规则**：`@...@` 之间的内容**不做自动化格式化**（原样保留，可含 `()`、`.`, 空格等），确保乐器引用安全。
- `@@`（空包裹）＝ 切回默认乐器（沿用）。
- 示例：`@电吉他(清音)@`、`@generaluser_gs:小提琴"领奏"@`、`@小提琴@`。

**兼容**：单 `@乐器名`（无尾 `@`）的旧写法**继续能解析**（按 `@` 到空白/`@` 结束），但会对**旧写法产生告警**，提示改用新语法 `@乐器名@`（含特殊字符的乐器名必须用 `@...@` 才能安全）——告警在 parser 错误/警告列表与编辑器浮层中展示。

## 2. 乐器显示名（可选）
在引用后可用引号携带显示名：
- `@乐器名"显示名"`、`@音色库id:乐器名"显示名"`。
- `"显示名"` **非必需**。
- **显示规则**（描述头标题下）：
  1. 有显示名 → 显示 `显示名`；
  2. 无显示名 → 显示**纯净的「乐器名」**（去掉 `@` 与音色库前缀，仅乐器名本身）。

## 3. Y 行（默认乐器）
`Y: <乐器引用>["显示名"]` —— 描述头默认乐器。示例：
- `Y: @小提琴"领奏"`（省略库 id + 显示名）
- `Y: @generaluser_gs:小提琴`（指定库，无显示名 → 显示“小提琴”）

## 4. 重名与省略规则
- 省略音色库（`@乐器名`）时，按 **可用乐器列表** 查找该乐器。
- **同名多库**：取可用列表中的**第一个**同名乐器，保证可正常播放。
- 需要精确指定某一库时用 `@音色库id:乐器名`。
- 「重名」的判断基准 = 所有**已可用乐器**列表（含收藏的高保真 GM 音色与 midi 库乐器）中的同名字段。

## 5. 可用乐器列表（adj344：试听固定 SpessaSynth 高保真）

运行时按用户配置动态汇聚——**试听固定高保真**，可用乐器即高保真 GM 库中用户**收藏**的音色：
- 高保真 GM 库：用户**收藏**的音色（`playbackHqEnabledByLib`，**每库一套**），库 id = 该音源库 id，乐器名 = GM 音色名。
- 合成 6 种 / midi 标准库不再作为**试听**可选项（engine 语法兼容保留，但试听后端固定高保真）。
列表顺序即「取第一个同类名」的先后依据。

### 5.1 民族乐器（**拟声**，adj1019）

GM 的 128 个 program 里**没有**二胡、琵琶、古筝、唢呐这些乐器。于是内置一张拟声表
（`engine/playback/ethnicVoices.ts`）：谱面写 `Y: 二胡` / `@琵琶@` 时，按最接近的 GM 音色演奏。

- 常用对应（`program` 按 MIDI 标准，显示名取 `GM_VOICES`）：
  二胡/高胡/中胡/板胡/京胡/马头琴→110；琵琶/柳琴/月琴/阮→105；三弦→106；古筝/古琴→107；
  箜篌→46；扬琴→15；笛子/竹笛/曲笛→73；梆笛→72；箫/洞箫/尺八→77；唢呐/管子→111；
  笙/芦笙/葫芦丝→20；埙/陶笛→79；排箫→75；堂鼓/大鼓/排鼓→116；木鱼/梆子→115；
  编钟/编磬→14；锣→118；镲/钹→119。
- **「拟」标在页签上、不标在名字上**（adj1029，用户 2026-10-21）：名字是给用户写进
  `@二胡@` 的，带后缀就写不进去 ⇒ `ethnicLabel()` 返回裸名；页签标题写「民族乐器（拟）」，
  行内再标出它落到哪个 GM 音色（`二胡 → 110 民谣提琴`）。解析器**兼容**旧标签
  （`二胡（拟）` / `二胡(拟)` 也认），避免照着旧界面复制的人踩空。
- **勾选才生效**（adj1028，用户 2026-10-21）：「指定音色」里有两个页签——「音色清单」（原列表）
  和「民族乐器（拟）」。后者与前者一样是**可勾选**的一组名字（`二胡 → 110 民谣提琴`）；
  勾了才在脚本里可用，没勾的名字退回普通解析（乐器族兜底，不是拟声）。
  勾选存 `ijipu.ethnicVoices`（L1 本机偏好），由应用入口 `syncEthnicVoicesToEngine()` 交给引擎。
  试听底栏的「音色」下拉用 `playbackVoiceOptions()` 把两处勾选**按 program 合并**，
  民乐名会以 `二胡（拟 · 110 民谣提琴）` 的形式出现（adj1030：用户报"勾了却看不到"）。
- 真实民乐请用外部音源（Ample China / Kong Audio 等 VST）：应用里排谱 → 导出 MIDI → DAW 渲染。
- **优先级**：`GM_VOICES` 全表 → 民族拟声表 → 旧简称表 → 乐器族兜底。
  所以 `长笛`/`小提琴` 这些 GM 已有的名字**不会被拟声表抢走**（smoke 有负对照）。

### 5.2 音色名的历史更正（adj1022）

GM 的 128 个中文名曾与 MIDI 标准**成段错位**，已按标准更正：

| program 段 | 旧名（错） | 新名（标准） |
|---|---|---|
| 8 / 9 | 钟琴 / 钢片琴 | **钢片琴 / 钟琴**（对调） |
| 24–31 | 民谣吉他 / 电吉他(清音) / … | 尼龙弦吉他 / 钢弦吉他 / 爵士电吉他 / 清音电吉他 / 闷音电吉他 / 过载电吉他 / 失真电吉他 / 吉他泛音 |
| 36–39 | 击弦倍低音 / 闷音电贝斯 / 电贝斯1 / 电贝斯2 | 击弦贝斯1 / 击弦贝斯2 / 合成贝斯1 / 合成贝斯2 |
| 44–47 | 拨奏弦乐 / 竖琴 / 定音鼓 / 弦乐合奏 | 震音弦乐 / 拨奏弦乐 / 管弦竖琴 / 定音鼓 |
| 74–79 | 泛音笛 / 竖笛 / 巴乌笛 / 民族笛 / 哨笛 | 竖笛 / 排箫 / 吹瓶声 / 口哨 / 陶笛 |
| 80–87 | 排箫 / 吹瓶声 / 口哨 / … / 合成主音1-3 | 方波 / 锯齿波 / 汽笛风琴 / 气声 / 恰朗戈 / 人声 / 五度 / 贝斯 主音 |

## 7. 播放路由（adj344：固定 SpessaSynth 高保真）
- 试听后端固定 SpessaSynth（高保真 GM）：按解析出的 `{库id, 乐器名}` 经 `engine.instrumentToProgram`
  选 GM program（`@库id:乐器名` 库前缀解析仍兼容）。
- 合成 / midi-js 采样后端不再作为试听用途（engine 兼容代码保留，仅标注废弃）。

## 8. 编辑器行号诊断（@乐器名告警在行号栏）
- 解析对旧写法 `@乐器名` 生成 `warning` 诊断（含行+列）；语法错误为 `error`。
- **行号栏渲染**：有告警/错误的行号显示对应背景色（warning=黄，error=红）。
- **优先级**：**告警/错误背景 > 当前行高亮**——同行的行号若含告警/错误，显示告警/错误色；无告警才显示当前行高亮。当前行高亮不得覆盖告警/错误色。
- **点击跳转**：点击告警/错误行号 → 光标跳到该行**问题所在列**。

## 10. 音源文件的来源与分发（adj346 / adj416；**adj1020 起不再随包**）

> 这一节讲"音源本体从哪来"，与上面的语法无关；改打包方式或音源来源时同步本节与 `scripts/check-installer.mjs`。
>
> 多库架构见 `docs/SOUNDBANK-LIBRARY-PLAN.md`；页面与"扫描本机目录/推荐下载"见 `docs/SOUNDBANK-PAGE-PLAN.md`。

**adj1020（用户 2026-10-21 决定）：音色库不随安装包分发。**

- 安装包里**没有** `generaluser_gs.sf2`，也没有 `soundfonts/` 目录；
- 首次安装后「已安装的音色库」列表**是空的**，页面提示"基础音色库需要先下载，否则没有声音"；
- 三条获取路径：① 应用内「下载基础音色库」（只在"一个库都没有"时出现一个按钮）；② 资源安装包
  （**每个资源文件一个独立安装器**，如 `iJipu-SoundFont-GeneralUserGS_<版本>_x64-setup.exe`，
  装进同一个目录；命名规则见 `docs/INSTALLER-NAMING.md`）；③ 「添加音色库…」导入本地文件。
- **应用里不放推荐清单**（adj1023，用户口径「少即是多」）：介绍/评价在官网**独立页 `/soundfonts/`**
  （adj1026 从首页搬出：用户指出"窄屏显示表格效果不佳"，正文改成分块），应用只留一条外链；
  引擎的 `RECOMMENDED_BANKS` 供官网与文档取数，界面只用 `BASE_BANK`。
- **桌面端下载走系统 curl**（`sf_soundfont_download`，adj1021）：浏览器 `fetch` 会被 CORS 拦死，
  桌面壳里由 Rust 调 `curl.exe` 下到"我的音色库目录"（先写 `.part` 再改名，边下边发进度）；
  调不起 curl 或失败时，前端回退到浏览器下载，并提示"可点下载页手动下、再导入"。
- 反向闸门：`scripts/check-installer.mjs` 会**检查 `bundle.resources` 里不许再出现音色库**
  （`adj1020` 那段），smoke `[101]` 同样只做反向断言 —— 免得哪天"顺手加回来"让安装包悄悄变大 32 MB。

**来源优先级（`src/playback/spessaCache.ts` 的 `resolveHqBank`，试听/导出共用）**：
1. **宿主给的地址**（仅 Obsidian 嵌入版：插件目录里那份，随文库走）；
2. **IndexedDB 缓存**（`ijipu-soundfonts-hq`，键 = 库 id）——用户导入/下载的音色；
3. **安装目录 / 我的音色库目录里的文件**（`<id>.sf2`）——给"便携版手动放文件"和资源包留的口子；
4. **远端下载**——`HQ_LIBRARIES[].source`（GitHub raw），失败再试 `fallbackSource`；只有这一条的结果会写回缓存。

**桌面（Tauri）的文件位置**：
- **我的音色库目录**（可写、推荐）：`<app_data>\soundfonts\`，Windows 下即 `%APPDATA%\com.ijipu.app\soundfonts\`。
  应用内「打开音色库目录」按钮会建好并打开它；下载/导入都落这里。
- **资源安装包目录**（adj1025，用户 2026-10-21 给定）：`%LOCALAPPDATA%\iJipu\soundfonts\`。
  用户自备的资源安装包装到这里；界面单独报「资源包 N 个文件」，位置标签写「资源安装包」。
- **安装目录**（只读、可选）：`<安装目录>\<id>.sf2` 或 `<安装目录>\soundfonts\<id>.sf2`。
- 扫描四处：`sf_soundfont_scan`（安装目录根 / `soundfonts/` / 我的音色库目录 / 资源包目录），
  只读文件头尾各 64 KB；音色表在该库**首次被选中**时读一次全量并缓存（SF2 的 `pdta` 在文件尾部）。
  播放读取的候选顺序：安装目录根 → `soundfonts/` → 我的音色库目录 → 资源包目录。
- 校验：smoke `[101]`（不许随包 + 其余资源仍在 + 发现命令仍在）、`[204]`（命令与安全边界）、`[205]`（发现编排）。

**Web（PWA）**：没有"目录"，缓存即目录 —— 下载/导入一律进 IndexedDB，之后离线可用。
