# 上下对齐原则（用户口径，作为冒烟判定的依据）

> 用户在 2026-10-12「段层上下对不齐」这条线上逐条给出的口径。**这是判定的依据**：
> 写断言、改布局、判断"修好没有"都以本文件为准。
> 由 `ijipu/AGENTS.md` §五 引用（自动加载），避免只躺在文档里失效。

## 一、三层对齐原则（用户原话，有先后次序）

> 「多声部、临时多声部、临时伴奏的对齐其实也是这个原则，**首先要保证拍子起点和宽度对齐**，
> 再保存**同时值起点的左边界对齐**，后保存**同时值长度的右边界对齐**，这是上下对齐的主要原则」

| 层 | 内容 | 说明 |
|---|---|---|
| **① 基础** | **拍子起点 + 宽度对齐** | 每拍的**位置**与**宽**在上下两层一致。这一层不成立，后面两层无从谈起 |
| **②** | **同时值起点的左边界对齐** | **时值相同**的音，左边界必须落在同一列 |
| **③** | **同时值长度的右边界对齐** | **时值长度相同**的音，右边界必须落在同一列 |

⚠ 三层是**递进**的：① 做不到时，②③ 只能"事后兜底"，兜不出来就是 ① 的账
（本轮实测：段层每拍步进 `25.7` vs 主旋律时值格 `28.8` ⇒ ① 不成立）。

## 二、时值格与墨迹的关系（左缘定位点）

> 「拍子墨迹应该是要在**时值格**里的，所以墨迹左缘一定是在时值格内的，也就是左缘右侧，
> **时值格左缘 x ≤ 墨迹左缘 x**，同理 **时值格右缘 x ≥ 墨迹右缘 x**。
> 这个时值左缘可能是**拍子的左缘**，也可能是**音符块的左缘**，看它定的是谁的时值，
> **这也是色块的左缘定位点**。」

- **时值格**是权威几何；**墨迹必须落在格内**（不是"大约"）；
- **格左缘**按"它定的是谁的时值"取：可能是**拍子的左缘**，也可能是**音符块的左缘**；
- **色块左缘 = 时值格左缘**（同一个点，不许各算一套）。

## 三、时值格右边界的取法

> 「时值格的右边界按上面说的原则，如：**下一个时值格的左缘**，**避开无时值元素**等」

```
时值格右缘 = min( 下一个时值格的左缘 , 小节线左界 , 无时值元素（&zkh/&ykh/&hx 等括号/修饰符）左缘 )
```

另有两条补充（用户早前口径，已落地在 `adj374`/`adj905c`）：

- **末音**（没有"下一个时值"）取自己的**末格右缘**，含增时线/附点（`adj374` 要求色块盖住末格增时线）；
- 「**播放层不变，只是色块显示层有变化**」—— `playheadSegs` 是**色块专用**数据，
  调它的水平几何**只影响显示**，播放数据（`atMs`/`durationMs`/`pitch`/`instrument`）与布局层都不动。

## 四、间隙（`NOTE_GAP`）的归属与作用

> 「插间隙的**只针对多声部/伴奏**的情况，**单声部不在内**，因为多声部/伴奏本就考虑到
> 以**最小本体占宽**来计算可用留空（即间隙）了，这个间隙就是为了填充在音符块之间以
> **保证同时值点的音符块左边界对齐**，只是这一块内容之间没做到/做好」

- 间隙的**目的**：填在音符块之间，使**同时值点的块左边界对齐**（服务于 ① 与 ②）；
- **范围**：多声部 / 临时多声部 / 临时伴奏（段层）。**单声部不在内** —— 不要为此改单声部的 `n.width`；
- 常量一次定义：`layout/index.ts:213` 的 `NOTE_GAP = 4`，模型是「n 拍有 (n−1) 个间隙」（`:616`）。

## 五、段层末小节的对齐

> 「**段层末小节无小节线的末尾与主旋律的小节一对齐**，主旋律一定是要有的」

段层（`{bz}`/`{dsb}`/`{tp}`）末尾可能没有收尾小节线，但它的**内容右端必须与主旋律那一小节的
右端（小节线 / `rightX`）对齐** —— 主旋律那一侧一定有小节线可作锚点。

实测（首页「铃儿响叮当」末小节）：段层末音右缘 `533.7` == 主旋律 `rightX` `533.7` ✅ **已满足**。

## 六、明确**不采用**的方案（用户否掉）

> 「**不推荐 B**（按页面有效宽度定义每个时值的宽度），这就是**等时值**的布局方式，
> 这会导致**短时值音符之间很窄，而长时值音符之间又很松**」

⇒ **禁止**把"整小节均分成 N 格、每格等宽"当作通用布局口径。

### `adj905o` 的实测明细（待修）

「时值格 ⊇ 墨迹」在**全部示例**里实测 **16 处不合规**，其中较重的是
「茉莉花（完整）」bar2：

```
格[366.5, 423.5]  vs  墨迹[373.8, 426.7]     墨迹右缘越格 3.2px
格[305.6, 362.5]  vs  墨迹[312.9, 365.8]     墨迹右缘越格 3.3px
```

⚠ 我一度把它归因为"`perBeat` 一位小数取整"——**这个解释是错的**：
取整误差界是 `0.05 × beats ≤ 0.2px`，解释不了 3.2px。⇒ 属**真实的"墨迹越格"**。

**判定口径**（写断言时照此，别再犯我踩过的坑）：

- **墨迹左缘 = `note.x`**；
- **墨迹右缘 ≠ `rightX`**（`rightX` 是**步进/占位右端**，含音符间距）——
  无附点/增时线时取 `x + min(占宽, digitSlotW)`，**有**才延伸到块右端（`AGENTS.md` 五·9）。
  我第一版拿 `rightX` 当墨迹右缘，**误报 164 处**。


### 当前已知冲突（下一步必须先解决）

`beatToX` 里**两种口径混用**：

- **音符起点** → `return n.x`（**数字墨迹位**，`adj435` 为避开"11px 跳变"特意如此）；
- **音符内部** → **时值格列**（实测 `428.2 / 457.0 / 485.7 / 514.5`）。

⇒ 按原则二「**色块左缘 = 时值格左缘**」，锚点应统一到**格**。但一改就撞红
`AJ1`/`AJ2`/`AK3`（"段层内部按自己的时值比例"）与 `Y3`（占宽）。

**在动手前必须先有这个调试开关**（`docs/PREVIEW-DEBUG-BOUNDARIES.md`）：
把「段层边界 / 墨迹边界 / 时值边界」三套几何同时画出来，看清各自画在哪，再统一 ——
本轮我三次"先改再量"全部失败，教训已记在该文档第七节。

另注：还有一处**字形级**差异要一起处理（实测）：

- 主旋律数字**居中**在自己的元素里（格左缘 `428.2` → 数字 `434.6`，偏 +6.4，见 `layout/index.ts:2381`）；
