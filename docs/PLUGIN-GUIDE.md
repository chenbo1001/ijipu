## 一、它能做什么

- **代码块即乐谱**：笔记里写一个 ` ```jps ` 代码块就渲染成简谱（SVG，多页自动分页）。
  语法错了**只提示、不打断**笔记正文。
- **`.jps` 文件当文档管**：插件把 `.jps` 注册成简谱文件，双击即渲染；能在笔记里链接或内联嵌入。
- **桌面端带完整编辑器**：点左侧栏的 iJipu 图标，打开**嵌入版 iJipu**（与网页版同一套界面），
  可直接编辑某个 `.jps` 文件。
- **试听**：Web Audio 现场合成，**不需要任何音频文件**；导入音色库还能更好听。
- **排版能拖**：显示排版辅助虚线后直接拖，松手写回**这份谱自己的源码**。
- **默认裁到墨迹**：只显示有内容的部分，整页白边不占地方；也可切「满宽 / 整页」。
- **导出**：复制为图片（桌面）、导出 PNG / SVG / MIDI、复制 SVG 文本或谱面源码。
- **全平台**：Windows / macOS / Linux / Android / iOS。

## 二、安装与启用

**装（推荐）**：Obsidian →「设置 → 第三方插件 → 浏览」→ 搜 **iJipu** → 安装 → 启用。

**手动装**：把 `main.js`、`manifest.json`、`styles.css` 三个文件放进
`<你的库>/.obsidian/plugins/ijipu/`，再到「设置 → 第三方插件」里启用。
⚠ 仓库里**没有** `main.js`（它是构建产物、不入库）⇒ 请从 Release 下载这三个文件，
不要用「下载源码 zip」那种方式。

**更新**：社区市场里点更新；手动装的话，三个文件一起换。

## 三、两种编制方式：先分清「代码块」与「`.jps` 文件」

**这是两套不同的用法，不是"同一个东西的两种写法"** —— 谱面源码（`.jps` 文本）是一样的，
但**它放在哪儿、参数从哪儿来、在哪儿编辑**完全不同。先看清这张表再往下读：

| | **写法 A：` ```jps ` 代码块** | **写法 B：`.jps` 文件** |
|---|---|---|
| 谱面放在哪 | **笔记正文里**（围栏内） | 库里一个**独立文件** |
| 怎么开始 | 在笔记里敲 ` ```jps ` | 文件夹右键 →「新建 JPS 文件」；或点一个指向不存在文件的 `[[谱名.jps]]`（会自动建） |
| **视图 / 缩放参数** | **可以调**：语言名后面写 `v=` `z=`（见 §四） | **不适用**：文件与内嵌块不读信息行参数 ⇒ 默认「谱面」+ 按宽自适应（见 §五） |
| 谱面源码是同一份吗 | 是（围栏内的文本就是 `.jps` 源码） | 是（就是这个文件的内容） |
| 在哪儿编辑 | 「✎ 编辑」= 在**笔记源码**与该块预览之间切换 | 桌面端「✎ 编辑」= 用**嵌入版 iJipu** 打开这份 `.jps` 编辑 |
| 排版辅助线改动写回哪 | 写回**笔记正文里的这个代码块** | 写回**这个 `.jps` 文件** |
| 一处改、几处跟着变 | 只影响这一处 | 链接 / 内嵌 / 嵌入版看到的**都是同一份** |
| 适合 | 笔记里随手记一小段、讲义里嵌一段、演示 | 一份完整的谱；要反复编辑、多处引用、当文件管理 |

> 一句话：**短、就地、要参数** ⇒ 用**代码块**；**长、要反复改、要被多处引用** ⇒ 用 **`.jps` 文件**。

## 四、写法 A：在笔记里写「代码块」

**必须用围栏围起来**，语言名写 `jps`（不是 `jsp`）：

```jps
V: 1.0
B: 小星星（片段）
D: C
P: 4/4
Q: 1 1 5 5 | 6 6 5 - ||
```

几个要点：

- **围栏是语法的边界**：```` ```jps ```` 开头、```` ``` ```` 结尾，中间才是谱面源码；
  围栏外的文字和它互不影响。光标离开代码块（或在阅读视图里）就出谱。
- **`V: 1.0` 是语法版本**，照写即可；`B:` 标题、`D:` 调号、`P:` 拍号、`Q:` 是谱面主体。
- **哪一行错了会指出来**：提示挂在代码块里，写明「哪里错 + 正确写法」，点一下跳到出错位置。
- **多页自动分页**；谱面右键（桌面）或点 **⋯ 更多** 有全部出口。
- **「✎ 编辑」**：在这个块上就是**切回笔记源码**（桌面与手机一样）—— 改的仍是笔记正文。

### 代码块参数（`v=` 视图 / `z=` 缩放）

**只有代码块有参数**（写在语言名后面，空格分隔）：

```jps v=w z=150
V: 1.0
B: 参数示例
D: C
P: 4/4
Q: 5 5 6 6 | 5 - - - ||
```

| 参数 | 取值 | 含义 |
|---|---|---|
| `v=` | `s` / `w` / `p` | **视图**：`s` 谱面（裁到墨迹，**默认**）/ `w` 满宽 / `p` 整页 |
| `z=` | 数字 1–1000 / `*` | **缩放**：百分比；`z=*` = 自适应容器宽；不写 = 100（自然尺寸） |

约定：分隔符以空格为主（`,` `;` `|` 也认）、**顺序任意**、**大小写不敏感**；
**认不出的值一律忽略**（`v=x` 当没写）；`v=full` 因有歧义（"满宽"还是"整页"）**会被拒绝并明确提示**，
请写 `v=w` 或 `v=p`。完整取值表见「脚本语法说明」的「附：代码块参数」。

## 五、写法 B：`.jps` 文件（独立文件，用嵌入版 iJipu 编辑）

### 怎么建、怎么打开

- **新建**：文件列表里在某文件夹上**右键 →「新建 JPS 文件」**——在该目录建一份默认模板的 `.jps` 并打开。
- **顺手建**：笔记里写 `[[我的谱.jps]]` 指向一个**还不存在**的文件，点它就会**自动建好并打开**。
- **自己建**：在文件列表里新建文件、名字写 `我的谱.jps` 也行。
- **打开即渲染**：插件把 `.jps` 注册成简谱文件 ⇒ 双击（或点链接）直接看到谱面，不需要写代码块。

### 在笔记里引用它

| 写法 | 效果 |
|---|---|
| `[[我的谱.jps]]` | 一个**链接**，点开就是这份谱 |
| `![[我的谱.jps]]` | 把谱面**内联嵌进当前笔记**（阅读视图里直接显示） |

### 用嵌入版 iJipu 独立编辑（这是与代码块最大的不同）

桌面端，`.jps` 文件可以**用嵌入版 iJipu 打开来独立编辑**——那就是一个完整的编辑器：

- **怎么进**：点左侧栏的 **iJipu 图标**；或在谱面预览里点 **✎ 编辑**（桌面端优先走嵌入版）。
- **在哪儿打开**：「设置 → iJipu → **打开 `.jps` 的方式**」——右侧栏（默认）/ 新的页签 / 当前页签 /
  默认应用（仅桌面端，交给系统里关联 `.jps` 的程序）。
- **改动写回文件**：在嵌入版里编辑、保存 ⇒ 写回**这份 `.jps`**（与文件视图、内嵌块看到的是同一份内容）。
- **手机端没有嵌入版**：点 **✎ 编辑** 会用 Obsidian 自己的编辑器打开 `.jps` 源码（带语法着色与错误提示），
  点「看谱」回到预览。

### 视图与缩放：文件不读 `v=` / `z=`

`v=` / `z=` 是**代码块的信息行参数**，文件与内嵌块**没有信息行** ⇒ 它们不读这两个参数：

- **默认视图 = 谱面**（裁到墨迹）；
- **默认缩放 = 按宽自适应**（等价 `z=*`），不是 100。

要看整页 / 固定缩放，请进**嵌入版 iJipu**（或应用的页面设置）改**这份谱自己的**配置
（会写回源码里的 `# jps-config`，跟着文件走）。这也是"同一份源码、两种用法看着不一样"的原因。

## 六、谱面工具条：固定 5 位

谱面旁边有一条工具条（桌面：3 秒无操作自动收起，**点一下谱面**再出现；手机：常驻）：

| 按钮 | 作用 |
|---|---|
| **▶ 试听** | 播放 / 停止；播放时谱面上有色块跟着走 |
| **☰ 排版** | 排版辅助虚线开关（虚线可拖动改边距 / 行距，松手写回该谱源码） |
| **谱面·页面** | 显示模式：谱面（裁墨迹）/ 满宽 / 整页 |
| **✎ 编辑** | 按场景分派：**代码块** ⇒ 切笔记源码；**`.jps` 文件 / 内嵌块** ⇒ 桌面用嵌入版 iJipu 编辑、手机用 Obsidian 编辑器 |
| **⋯ 更多** | 低频入口都在这里（见下） |

## 七、菜单里有什么

桌面端点 **⋯ 更多**，或**在谱面上点右键**；手机端点 **⋯ 更多**（Obsidian 会把它显示成底部面板）：

| 分组 | 项目 |
|---|---|
| 设置 | 设置 / 页面设置、格式化源码 |
| 复制 | **复制为图片**（仅桌面，默认 2×）、复制 SVG 文本、复制谱面源码 |
| 导出 | **导出 PNG**（仅桌面）、导出 SVG、导出 MIDI |
| 范围 | 导出范围：跟随视图 / 页面 / 谱面（单选，打勾的是当前生效的那个） |
| 打开 | **在应用中打开**（仅桌面）、打开谱面文件 |

> **手机上为什么没有「复制为图片 / 导出 PNG」**：出图必须调用**嵌入版 iJipu 应用**，
> 而嵌入版只在桌面注册 ⇒ 手机上点它必然失败。所以这两项在手机端**根本不出现**
> （而不是让你点了才知道不行）。手机上要图，用 **导出 SVG**（矢量、放大不糊），
> 或把源码拿到桌面端导出。

## 八、试听

点 **▶ 试听** 即播：声音是 Web Audio **现场合成**的，不下载音频文件；播放时谱面上的色块跟着走。
想更好听，可在「设置 → iJipu → 音色库」导入音色库（采样音源，体积较大、按需下载）。

## 九、排版辅助虚线：拖一下就改好

点 **☰ 排版** 显示虚线（页边距、行距、临时段间距等）。**拖**虚线即改，松手就写回**这份谱的源码**：

- **代码块** ⇒ 写回**笔记正文里的那个代码块**；
- **`.jps` 文件 / 内嵌块** ⇒ 写回**那个 `.jps` 文件**。

也就是说，改的是**谱面自己的设置**（`# jps-config`）：把源码发给别人、换台机器打开，效果一样。

## 十、导出与复制

**先选范围，再选出口。**「导出范围」三种口径（菜单与设置页改的是同一个值）：

| 范围 | 含义 |
|---|---|
| **跟随视图**（默认） | 与你**当前看到的**一致（谱面视图 ⇒ 裁到墨迹） |
| 页面 | 整页 + 留白（A4 那种页面） |
| 谱面 | 墨迹 + 每边 2px |

| 出口 | 产物 | 平台 |
|---|---|---|
| 复制为图片 | 剪贴板里的 PNG（1× / 2× / 4×，默认 2×） | 桌面 |
| 导出 PNG | 写进库里的 PNG；文件头带 DPI（2× ⇒ 144 DPI），贴进 Word / 微信不会被放大成巨图 | 桌面 |
| 导出 SVG | 写进库里的矢量图（放大不糊、可再编辑） | 全平台 |
| 复制 SVG 文本 | 剪贴板里的 SVG 源码 | 全平台 |
| 导出 MIDI | 写进库里的 MIDI 文件（拿去别的软件继续编曲） | 桌面 |
| 复制谱面源码 | 剪贴板里的 `.jps` 文本 | 全平台 |

> 多页谱「复制为图片」只复制**第 1 页**，并会如实说明（剪贴板只能放一张图）。

## 十一、设置项（设置 → iJipu）

| 设置 | 作用 |
|---|---|
| 嵌入版通道（导出图片 / MIDI 需要） | 允许插件调用嵌入版应用的取图能力；默认关闭，打开后会**记住** |
| 使用嵌入版 iJipu（完整应用） | 桌面端点左侧栏图标打开的那个完整编辑器 |
| 工作区子目录 | 只扫描这个子目录里的谱（大库更快） |
| 打开 `.jps` 的方式 | 双击 `.jps` / 点「编辑」时在哪儿打开（右侧栏 / 新页签 / 当前页签 / 默认应用） |
| 跟随 Obsidian 主题 | 嵌入版 iJipu 的深浅色跟随 Obsidian（默认开） |
| 导出范围（导出 / 复制时的画布口径） | 见「十、导出与复制」 |
| 音色库（高保真试听的音源） | 导入音色库以改善试听音色 |
| 设置优先级（源内最高） | 谱面源码里的 `# jps-config` 优先于插件设置 |
| 截图/反馈时请附上构建信息 | 反馈问题时把构建信息一起附上（诊断报告里有） |

设置页底部还有「生成完整诊断报告」与「一键复制全部诊断」；「项目主页与仓库」里有源码与 Issue 入口。

## 十二、手机上有什么不同

| 维度 | 桌面 | 手机 |
|---|---|---|
| 工具条 | 3 秒自动收起，点一下再出现 | **常驻**，触控目标 ≥ 44px |
| 右键菜单 | 有 | 没有（长按被 Obsidian 占用）⇒ 用 **⋯ 更多** |
| **`.jps` 文件的完整编辑器（嵌入版）** | 有 ⇒ 独立编辑、保存写回文件 | 没有 ⇒ 用 Obsidian 编辑器（源码模式）+ 「看谱」 |
| 「在应用中打开」 | 有 | 菜单里不出现 |
| 图片出口（复制为图片 / 导出 PNG） | 有 | **不出现**（原因见「七、菜单里有什么」） |
| 代码块 | 一样（围栏 + 参数都可用） | 一样（围栏 + 参数都可用）；「✎ 编辑」切笔记源码 |

## 十三、常见问题

**Q：代码块和 `.jps` 文件，我该用哪种？**
A：笔记里**随手记一小段**、要就地调视图/缩放（`v=` `z=`）⇒ 用**代码块**；
**一份完整的谱**、要反复改、要能被多处引用、要当文件管 ⇒ 用 **`.jps` 文件**（见「三」的对照表）。

**Q：代码块里没出谱，只显示源码？**
A：先确认插件已启用；再看围栏的语言名是不是 `jps`（不是 `jsp`），并且**首尾围栏都写了**。
语法有问题时插件会给出提示行，按提示改。

**Q：同一个 `.jps`，为什么在代码块里和在文件里看起来不一样？**
A：**代码块能调参数、文件不能**：文件与内嵌块默认「谱面」视图 + 按宽自适应；代码块按你写的
`v=` / `z=` 来（不写则视图=谱面、缩放=100）。要让文件也用别的视图，就进嵌入版改这份谱自己的配置。

**Q：手机上为什么找不到「复制为图片」？**
A：出图要调用嵌入版应用，而嵌入版只在桌面注册（见「七」）。手机上用「导出 SVG」或复制源码。

**Q：手机上能像桌面那样"独立编辑"一份 `.jps` 吗？**
A：不能（嵌入版只在桌面）。手机端点 **✎ 编辑** 会打开 Obsidian 自己的编辑器写源码，
点「看谱」回预览。

**Q：`v=full` 为什么不生效？**
A：`full` 有歧义（"满宽"还是"整页"），插件**拒绝**它并明确提示 ⇒ 满宽写 `v=w`、整页写 `v=p`。

**Q：导入音色库很慢、很大？**
A：音色库是采样音源，体积本来就大；它只影响**试听音色**，不导入也能正常试听（内置合成）。

**Q：出问题了怎么反馈？**
A：「设置 → iJipu → 生成完整诊断报告」+「一键复制全部诊断」，连同截图一起发到插件仓库的 Issue。
