# 插件手册（iJipu for Obsidian）

把 `.jps` 简谱搬进 Obsidian 笔记：**代码块即乐谱**、能试听、排版可以拖、能导出成图。

> **本页只讲插件**。应用本身（网页版 / 桌面版）看「**操作手册**」，`.jps` 怎么写看「**脚本语法说明**」。
> 插件内部的实现口径（工具条槽位、移动分支策略等）以插件仓库的 `obsidian-ijipu/docs/TOOLBAR-AND-MENU.md` 为准；
> 本页只描述**使用者看得见的东西**。

## 一、它能做什么

- **代码块即乐谱**：笔记里写一个 ` ```jps ` 代码块就渲染成简谱（SVG，多页自动分页）。
  语法错了**只提示、不打断**笔记正文。
- **`.jps` 文件也能管**：链接或内联嵌入进笔记，双击用插件打开。
- **桌面端带完整编辑器**：点左侧栏的 iJipu 图标，打开内嵌的完整应用（与网页版同一套界面）。
- **试听**：Web Audio 现场合成，**不需要任何音频文件**；导入音色库还能更好听。
- **排版能拖**：显示排版辅助虚线后直接拖，松手写回这份谱的 `# jps-config`。
- **默认裁到墨迹**：只显示有内容的部分，整页白边不占地方；也可切「满宽 / 整页」。
- **导出**：复制为图片（桌面）、导出 PNG / SVG / MIDI、复制 SVG 文本或谱面源码。
- **全平台**：Windows / macOS / Linux / Android / iOS。

## 二、安装与启用

**装（推荐）**：Obsidian →「设置 → 第三方插件 → 浏览」→ 搜 **iJipu** → 安装 → 启用。

**手动装**：把 `main.js`、`manifest.json`、`styles.css` 三个文件放进
`<你的库>/.obsidian/plugins/ijipu/`，再到「设置 → 第三方插件」里启用。
⚠ 仓库里**没有** `main.js`（它是构建产物、不入库）⇒ 请从 Release 下载这三个文件，
不要用「下载源码 zip」那种方式。

**更新**：社区市场里点更新；手动装的话，三个文件一起换。

## 三、在笔记里写第一段谱

在任意笔记里写：

```jps
V: 1.0
B: 小星星（片段）
D: C
P: 4/4
Q: 1 1 5 5 | 6 6 5 - ||
```

光标离开代码块（或在阅读视图里）就出谱。几个要点：

- **`V: 1.0` 是语法版本**，照写即可；`B:` 标题、`D:` 调号、`P:` 拍号、`Q:` 是谱面主体。
- **哪一行错了会指出来**：提示挂在代码块里，写明「哪里错 + 正确写法」，点一下跳到出错位置。
- **两端同源**：插件里的渲染结果，与应用、官网示例**是同一个引擎**（`vendor/engine` 与主仓库逐字节同步）。

### 代码块参数（`v=` 视图 / `z=` 缩放）

参数写在语言名后面，空格分隔：

```jps v=w z=150
V: 1.0
B: 参数示例
D: C
P: 4/4
Q: 5 5 6 6 | 5 - - - ||
```

| 参数 | 取值 | 含义 |
|---|---|---|
| `v=` | `s` / `w` / `p` | **视图**：`s` 谱面（裁到墨迹，**默认**）/ `w` 满宽 / `p` 整页 |
| `z=` | 数字 1–1000 / `*` | **缩放**：百分比；`z=*` = 自适应容器宽；不写 = 100（自然尺寸） |

约定：分隔符以空格为主（`,` `;` `|` 也认）、**顺序任意**、**大小写不敏感**；
**认不出的值一律忽略**（`v=x` 当没写）；`v=full` 因有歧义（"满宽"还是"整页"）**会被拒绝并明确提示**，
请写 `v=w` 或 `v=p`。完整取值表见「脚本语法说明」的「附：代码块参数」。

## 四、`.jps` 文件：链接、嵌入、双击

- **链接**：写 `[[某谱.jps]]`，在笔记里可点。
- **内嵌**：写 `![[某谱.jps]]`，把谱面直接嵌进当前笔记（**默认视图 = 谱面**，即裁到墨迹）。
- **双击打开**：文件列表里双击 `.jps`，用「设置 → iJipu → 打开 `.jps` 的方式」指定的入口打开。
- **桌面端**：可点左侧栏图标打开**嵌入版完整编辑器**（编辑、试听、导出都在里面）。
- **手机端**：用 Obsidian 自己的编辑器写 `.jps`（带语法着色与错误提示），点「看谱」回到预览。

## 五、谱面工具条：固定 5 位

谱面旁边有一条工具条（桌面：3 秒无操作自动收起，**点一下谱面**再出现；手机：常驻）：

| 按钮 | 作用 |
|---|---|
| **▶ 试听** | 播放 / 停止；播放时谱面上有色块跟着走 |
| **☰ 排版** | 排版辅助虚线开关（虚线可拖动改边距 / 行距，松手写回 `# jps-config`） |
| **谱面·页面** | 显示模式：谱面（裁墨迹）/ 满宽 / 整页 |
| **✎ 编辑** | 按平台分派：笔记源码 / 宿主编辑器 / 嵌入版 iJipu |
| **⋯ 更多** | 低频入口都在这里（见下） |

## 六、菜单里有什么

桌面端点 **⋯ 更多**，或**在谱面上点右键**；手机端点 **⋯ 更多**（Obsidian 会把它显示成底部面板）：

| 分组 | 项目 |
|---|---|
| 设置 | 设置 / 页面设置、格式化源码 |
| 复制 | **复制为图片**（仅桌面，默认 2×）、复制 SVG 文本、复制谱面源码 |
| 导出 | **导出 PNG**（仅桌面）、导出 SVG、导出 MIDI |
| 范围 | 导出范围：跟随视图 / 页面 / 谱面（单选，打勾的是当前生效的那个） |
| 打开 | **在应用中打开**（仅桌面）、打开谱面文件 |

> **手机上为什么没有「复制为图片 / 导出 PNG」**：出图必须调用**嵌入版 iJipu 应用**，
> 而嵌入版只在桌面注册 ⇒ 手机上点它必然失败。所以这两项在手机端**根本不出现**
> （而不是让你点了才知道不行）。手机上要图，用 **导出 SVG**（矢量、放大不糊），
> 或把源码拿到桌面端导出。

## 七、试听

点 **▶ 试听** 即播：声音是 Web Audio **现场合成**的，不下载音频文件；播放时谱面上的色块跟着走。
想更好听，可在「设置 → iJipu → 音色库」导入音色库（采样音源，体积较大、按需下载）。

## 八、排版辅助虚线：拖一下就改好

点 **☰ 排版** 显示虚线（页边距、行距、临时段间距等）。**拖**虚线即改，松手就写回这份谱的
`# jps-config` —— 也就是说，改的是**谱面自己的设置**：把源码发给别人、换台机器打开，效果一样。

## 九、导出与复制

**先选范围，再选出口。**「导出范围」三种口径（菜单与设置页改的是同一个值）：

| 范围 | 含义 |
|---|---|
| **跟随视图**（默认） | 与你**当前看到的**一致（谱面视图 ⇒ 裁到墨迹） |
| 页面 | 整页 + 留白（A4 那种页面） |
| 谱面 | 墨迹 + 每边 2px |

| 出口 | 产物 | 平台 |
|---|---|---|
| 复制为图片 | 剪贴板里的 PNG（1× / 2× / 4×，默认 2×） | 桌面 |
| 导出 PNG | 写进库里的 PNG；文件头带 DPI（2× ⇒ 144 DPI），贴进 Word / 微信不会被放大成巨图 | 桌面 |
| 导出 SVG | 写进库里的矢量图（放大不糊、可再编辑） | 全平台 |
| 复制 SVG 文本 | 剪贴板里的 SVG 源码 | 全平台 |
| 导出 MIDI | 写进库里的 MIDI 文件（拿去别的软件继续编曲） | 桌面 |
| 复制谱面源码 | 剪贴板里的 `.jps` 文本 | 全平台 |

> 多页谱「复制为图片」只复制**第 1 页**，并会如实说明（剪贴板只能放一张图）。

## 十、设置项（设置 → iJipu）

| 设置 | 作用 |
|---|---|
| 嵌入版通道（导出图片 / MIDI 需要） | 允许插件调用嵌入版应用的取图能力；默认关闭，打开后会**记住** |
| 使用嵌入版 iJipu（完整应用） | 桌面端点左侧栏图标打开的那个完整编辑器 |
| 工作区子目录 | 只扫描这个子目录里的谱（大库更快） |
| 打开 `.jps` 的方式 | 双击 `.jps` 时用哪个入口打开 |
| 跟随 Obsidian 主题 | 嵌入版 iJipu 的深浅色跟随 Obsidian（默认开） |
| 导出范围（导出 / 复制时的画布口径） | 见「九、导出与复制」 |
| 音色库（高保真试听的音源） | 导入音色库以改善试听音色 |
| 设置优先级（源内最高） | 谱面源码里的 `# jps-config` 优先于插件设置 |
| 截图/反馈时请附上构建信息 | 反馈问题时把构建信息一起附上（诊断报告里有） |

设置页底部还有「生成完整诊断报告」与「一键复制全部诊断」；「项目主页与仓库」里有源码与 Issue 入口。

## 十一、手机上有什么不同

| 维度 | 桌面 | 手机 |
|---|---|---|
| 工具条 | 3 秒自动收起，点一下再出现 | **常驻**，触控目标 ≥ 44px |
| 右键菜单 | 有 | 没有（长按被 Obsidian 占用）⇒ 用 **⋯ 更多** |
| 完整编辑器（嵌入版） | 有 | 没有；用 Obsidian 编辑器 + 「看谱」 |
| 「在应用中打开」 | 有 | 菜单里不出现 |
| 图片出口（复制为图片 / 导出 PNG） | 有 | **不出现**（原因见「六、菜单里有什么」） |

## 十二、常见问题

**Q：代码块里没出谱，只显示源码？**
A：先确认插件已启用；再看代码块的语言名是不是 `jps`（不是 `jsp`）。语法有问题时插件会给出提示行，按提示改。

**Q：手机上为什么找不到「复制为图片」？**
A：出图要调用嵌入版应用，而嵌入版只在桌面注册（见「六」）。手机上用「导出 SVG」或复制源码。

**Q：内嵌的 `![[某谱.jps]]` 显示的不是整页？**
A：内嵌块与 `.jps` 文件视图**默认是「谱面」**（裁到墨迹）。要看整页，请用 ` ```jps v=p ` 代码块，
或在应用 / 嵌入版里改这份谱的页面设置（会写回 `# jps-config`，跟着谱走）。

**Q：`v=full` 为什么不生效？**
A：`full` 有歧义（"满宽"还是"整页"），插件**拒绝**它并明确提示 ⇒ 满宽写 `v=w`、整页写 `v=p`。

**Q：导入音色库很慢、很大？**
A：音色库是采样音源，体积本来就大；它只影响**试听音色**，不导入也能正常试听（内置合成）。

**Q：出问题了怎么反馈？**
A：「设置 → iJipu → 生成完整诊断报告」+「一键复制全部诊断」，连同截图一起发到插件仓库的 Issue。
