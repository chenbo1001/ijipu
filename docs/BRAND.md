## 品牌介绍（关于我们）

iJipu（中文名：爱记谱）—— 下一代代码式简谱制谱引擎。

我们致力于将编程语言的严谨逻辑，注入中国传统简谱的创作之中。通过一套极简的 .jps 标记语言，让音乐人像写代码一样编排音符，让程序员像调参一样调整音高。码即成，谱自现，让简谱创作从此进入"脚本时代"。

## 视觉规范

- 界面采用 **VS Code 风格深色主题**：深空蓝暗色系为底（`#0F1526` / `#161D3A`），霓虹青作强调（光标、行头命令、激活态）。
- 乐谱预览区保持**纸张白色**（`#FFFFFF`，墨色 `#1b1b1b`），还原真实乐谱阅读体验。
- 语法高亮色遵循代码语义：行头命令=霓虹青、音符=橙、小节线=灰蓝、歌词=绿、注释=暗蓝、分页符=粉。
