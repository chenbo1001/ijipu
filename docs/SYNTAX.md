# 脚本语法（.jps 简谱脚本参考）

iJipu 用 `.jps` 文本文本编写简谱。文件由「描述头」与「曲词主体」组成，兼容原站 V1.0 语法。

## 一、描述头（每行一个，`字母:` 开头）

```
V: 1.0        # 版本
B: 标题        # 标题（可多行，多个标题纵向排列）
Z: 作者 词曲    # 作者/署名
D: C          # 调号（C / D / F / bB 等）
P: 4/4        # 拍号
J: 80 欢快地    # 节拍速度（数字部分为拍/分，可带文字）
Y: 钢琴        # 乐器（一个 Y 行一种；多声部按行顺序对应各声部）
S: 说明文字     # 谱尾说明（可用 \n 换行）
```

注释：`#` 开头为注释行；`# jps-config:{...}` 为程序自动生成的页面设置行，请勿手改。

## 二、曲行与歌词

```
Q: 1 2 3 4 |   # 单声部曲行
C: 一 二 三 四  # 歌词（逐字对齐音符
Q1"高声部": ... # 多声部：Q 后带声部号（可带声部名），相同号对齐成多声部块
C1: ...        # 对应声部歌词
```

## 三、音符与时值

```
1 2 3 4        # 基本音符（1-7，对应 sol-la-si-do-re-mi-fa）
0              # 休止符（可见）；8 = 隐藏休止符（占空间不显示）；9 = 节奏符
'              # 高音点（数字后，可多个）；, = 低音点
# / $ / =      # 升 / 降 / 还原（写在数字后，如 1# 2$ 3=）
-              # 增时线（每条 +1 拍，如 1 - - - = 4 拍全音符）
/              # 减时线（n 条 = 1/2^n 拍，如 1/ 八分、1// 十六分）
.              # 附点（1.5 倍，可两个 = 1.75 倍）
(1)            # 虚音符（弱奏装饰，括号紧贴数字）
1[65]          # 前倚音；1[h65] = 后倚音
```

## 四、小节线与反复

```
|  ||  |/  |*  # 单/双小线、隐藏线1、隐藏线2
|:  :|  :|:    # 反复开始/结束/包围
"文字"          # 小节线备注（引号）
|["1." ... |]  # 跳房子（[ 起点、|] 终点；修饰："标签"、+ 抬高 / - 降低（每级 2px）、/ 不封闭）
               # 标签为数字 = 番号（第 N 遍才奏）；标签为文字 = 末遍房子（如 |["结束句" ... |]，最后一遍才奏）
|&fine 等      # 小节线修饰符：&fine 曲终 / &dc 从头反复 / &ds 大反复 / &ty 大跳跃 / &hs 花S
               #（可与跳房子共存，如 |]/&hs、|&ds]/）
```

## 五、连音线与装饰

```
( ... )        # 连音线（可嵌套/跨小节；括号与音符间有空格，与虚音符 (1) 区分；(+ / (- 抬高/降低线，每级 2px）
&tr 颤音  &mp 力度  &sbf 声部括弧位置   # & 开头装饰编码；力度编码（&pp &p &mp &mf &f &ff &fff &sf &fp &sfp，&rit 渐慢）在音符上方斜体显示
&tu 吐音  &ku 吐音  &da 打音  &die 叠音  # 音符上方单字修饰符（adj334）：吐音粗体 T / K、打音粗体 扌、叠音粗体 又（又横向缩 3/4），居中显示在音符正上方
<  >  !       # 渐强 / 渐弱 / 结束：< > 写在音符后从该音符正中开始，! 写在音符后结束于该音符；<+ / >++ 的 + 逐级抬升（每级 2px）
```

## 六、乐器指令（新增）

```
Y: 钢琴        # 默认乐器（多声部按行顺序对应）
@弦乐          # 曲行内从该时点起切换到弦乐（当前及以后行）
@@            # 切回默认乐器
```

乐器名须与试听音色库一致：钢琴 / 风琴 / 弦乐 / 长笛 / 铜管 / 八音盒；不匹配回退默认（第一个 Y 或钢琴）。`@`/`@@` 不占时值、不渲染；勾选「显示乐器名」后在切换处音符上方标注。

## 七、分页

```
[fenye]        # 强制换页
```

## 八、块间空格

音符块、小节线块、连音线/装饰/跳房子等独立块之间**恰好一个空格**。音符块内部（数字及其修饰）不用空格。

完整的语法细节与示例见项目 `docs/JPS-SPEC.md` 与内置示例谱。
