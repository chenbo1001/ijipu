# 第一部分 五分钟上手

## 1.1 什么是 .jps

`.jps` 是一份**纯文本**简谱：用几行"描述头"写标题/调式/拍号，再用 `Q:` 行写音符、`C:` 行写歌词。
一个文件就是一首谱，没有二进制、没有隐藏格式，用记事本也能改。

结构只有两段：

```
描述头（每行一个字段，字母 + 冒号）      ← 必须有
主体（Q: 曲行 / C: 词行，可写很多行）    ← 谱子的内容
```

## 1.2 最小可用谱

下面 6 行就是一首完整、能渲染也能试听的谱。**先整段选中复制**：

```jps
V: 1.0
B: 最小示例
D: C
P: 4/4
Q: 1 2 3 4 ||
```

- `V:` 版本（固定写 `1.0`，必须有）、`B:` 标题、`D:` 调式、`P:` 拍号（必须有）
- `Q:` 曲行：`1 2 3 4` 是四个音符（简谱数字），`||` 是终止小节线

## 1.3 在 iJipu 里跑起来

1. 打开 iJipu（网页版 / 桌面版 / 手机 App 都一样）→ 左侧是**编码区**，右侧是**预览区**。
2. 全选编码区内容（`Ctrl+A`），把上面那段粘进去（`Ctrl+V`）。
3. 右边立刻出谱。点顶部「**试听**」→「播放」就能听到声音。
4. 想改？直接改数字：`1` 换成 `5` 试试。

> 手机上如果看不到编码区，点顶栏的「编码 / 拆分 / 预览」切换，或把手机横过来。

## 1.4 在 Obsidian 笔记里用

在笔记里写一个 `jps` 代码块，装上 iJipu 插件后就会渲染成谱面：

    ```jps
    V: 1.0
    B: 小星星（片段）
    D: C
    P: 4/4
    Q: 1 1 5 5 | 6 6 5 - ||
    C: 一 闪 一 闪 亮 晶 晶
    ```

（插件安装与用法见插件仓库的说明；语法与这里完全一致。）

## 1.5 一步一步加东西

### 第 1 步：加歌词（`C:` 行）

歌词**一个汉字对一个音符**，自动对齐；中文标点不占音符位、跟在字后：

```jps
V: 1.0
B: 两只老虎（片段）
Z: 法国童谣 词曲
D: C
P: 4/4
J: 120
Q: 1 2 3 1 | 1 2 3 1 | 3 4 5 - | 3 4 5 - ||
C: 两 只 老 虎 两 只 老 虎 跑 得 快 跑 得 快
```

- `Z:` 作者、`J:` 速度（每分钟拍数）都是**可选**的。
- 一行曲可以配多行词（再写一条 `C:`）。某个音符不想配字就写 `@` 占位。

### 第 2 步：写时值（减时线、附点、增时线、休止）

```jps
V: 1.0
B: 时值练习
D: C
P: 4/4
J: 88
Q: 1 2 3 4 | 5/ 6/ 7 1' | 1. 2/ 3/ 4. | 0 5, 6, 7, - ||
```

| 写法 | 含义 | 拍数（以 4/4、1 拍为基准） |
|---|---|---|
| `1` | 基本音符 | 1 拍 |
| `1/` | 一条减时线（八分） | 1/2 拍 |
| `1//` | 两条减时线（十六分） | 1/4 拍 |
| `1.` | 附点 | ×1.5（`1.` = 1.5 拍） |
| `1/` 再加 `.` | `1/.` | 1.5 × 1/2 = 0.75 拍 |
| `1 -` | 增时线（每条 +1 拍） | 2 拍；`1 - - -` = 4 拍 |
| `1'` / `1,` | 高音点 / 低音点 | 不影响时值 |
| `0` | 休止符（可见） | 1 拍 |

### 第 3 步：加连音、倚音、装饰

```jps
V: 1.0
B: 连音与倚音
D: C
P: 4/4
J: 88
Q: 1[65] 2 ( 3 4 ) 5"渐强" 6&tr | 7 (y3/ 2/ 1/) 1' - - - ||
```

- `1[65]`：**前倚音**（先奏 6、5 两个小音符，再落到 1）；`1[h65]` 是**后倚音**。
- `( 3 4 )`：**连音线**（括号与音符之间要有空格）。
- `5"渐强"`：音符上方的**注释小字**；`6&tr`：**颤音**（`&` 开头的装饰编码）。
- `(y3/ 2/ 1/)`：**等时值连音组**（三个音平分"这一小节剩下的时值"，弧线上标数字）。

### 第 4 步：加反复与跳房子

```jps
V: 1.0
B: 反复与跳房子
D: C
P: 4/4
J: 100
Q: |: 1 2 3 4 | 5 6 7 1' |["1." 1 2 3 4 :|["2." 5 4 3 2 |] ||&fine
```

- `|:` `:|` 反复开始 / 结束；`["1." ...` 第一遍的房子、`["2." ...` 第二遍的房子，`|]` 收尾。
- `&fine` 画在终止线上（曲终记号）；同类还有 `&dc`（从头反复）/`&ds`（大反复）/`&hs`（花 S）。

### 第 5 步：多声部与乐器

```jps
V: 1.0
B: 多声部
D: C
P: 4/4
J: 96
Y: 钢琴
Y: 弦乐
Q1"主旋律": 1 2 3 4 | 5 6 7 1' | @弦乐@ 1' 7 6 5 | 4 - - - ||
C1: 一 二 三 四 五 六 七 八 九 十 百 千 万 里 江 山
Q2"伴奏": 8 8 8 8 |* 8 8 8 8 |* 8 8 8 8 |* 8 - - - |*
```

- `Q1:`/`Q2:` 是声部编号，`Q1"主旋律":` 给声部起名；`C1:` 对应该声部的歌词。
- `Y:` 每行一种乐器，**按行序对应声部**（第 1 个 `Y` 给 Q1）。
  乐器名可用「全局设置 → 音色库」里列出的任一音色名（`钢琴`、`长笛`、`弦乐合奏1`、`电钢琴`…），
  也可以直接写该音色的**编号**（`Y: 21` 即手风琴；编号就是音色库列表里名称前的数字）。
- `8` 是**隐藏休止符**、`|*` 是**隐藏小节线**——用来把短声部补齐对齐（上面伴奏声部就是靠它们占位）。
- `@弦乐@` 在曲行中途切换乐器，`@@` 切回默认乐器。

## 1.6 写错了怎么办

- 编辑器**行号栏**会变红/黄，光标所在行下方会出现「问题提示条」：写明**哪里错了**、**正确写法**，点一下能跳到出错位置。
- 最常见的三类错误（详见第四部分）：**块之间漏了空格**、**引号没闭合**、**用了不认识的符号**。
- **小节拍数与拍号不符**会给出**告警**（黄色，不是错误）：如 `P: 4/4` 下某小节只有 3.5 拍，会提示「第 N 小节共 3.5 拍，与拍号 4/4（每小节 4 拍）不符」，并给出补齐办法。告警**不影响预览与导出**。
- 改完不用手动刷新：预览区实时重排。

# 第二部分 语法参考

> 这一部分是**查阅用**的：符号表 + 字段表 + 边界说明。所有片段都可直接粘进 `Q:` 行试验。

## 2.1 文件结构

```
描述头（V/B/Z/D/P/J/Y/S，每行一个，至少 V/B/D/P）   ← 文件开头，必须
# 注释行（以 # 开头，整行忽略，可写在任意位置）
Q: 曲行（音符序列，可多行 / 多声部）
C: 词行（歌词，自动对齐上一行的 Q）
[fenye]                                              ← 手动换页
# jps-config:{...}                                   ← 程序写入的页面设置行（请勿手改，见 2.14）
S: 谱尾说明（可多行，支持 \n 换行）
```

## 2.2 描述头（每行一个字段）

| 字母 | 含义 | 示例 | 必须 |
|---|---|---|:--:|
| `V` | 版本号 | `V: 1.0` | ✅ |
| `B` | 标题（可多次：第一个是主标题，其余为副标题） | `B: 排排坐` | ✅ |
| `Z` | 作者（可多次，显示在描述头右侧） | `Z: 佚名 词曲` | |
| `D` | 调式（大写字母，可带 `#`/`$` 升降；升降号也可写在字母前） | `D: C` / `D: F#` / `D: $B` | ✅ |
| `P` | 拍号（`/` 分隔，可多个：辅助拍号加括号） | `P: 4/4` / `P: 6/8 (2/4)` | ✅ |
| `J` | 节拍（数字 = 每分钟拍数；也可写文字显示在拍号下） | `J: 96` / `J: 欢快地` | |
| `Y` | 默认乐器（**一个 Y 行一种**；多声部按行序对应声部） | `Y: 钢琴` | |
| `S` | 谱尾说明（可多次，渲染在谱末；支持 `\n` 手动换行） | `S: 第一段\n第二段` | |

- 编辑器里**在行首按字母**就能插入对应命令头：`v` `b` `z` `d` `p` `j` `y` `s`，以及 `q`（曲行）/`c`（词行）。
  字母大小写都可以，插入的永远是大写命令头（按 `q` 得到 `Q: `）。

## 2.3 曲行与歌词

| 写法 | 含义 |
|---|---|
| `Q: 1 2 3 4 \|` | 单声部曲行 |
| `C: 一 二 三 四` | 歌词行（对上一个同声部的 `Q:`；一行曲可写多条 `C:`） |
| `Q1:` / `Q2:` | 声部编号（相同编号的行组成多声部块） |
| `Q1"女声":` | 带声部名 |
| `C1:` / `C2:` | 对应声部的歌词 |

歌词规则：

| 写法 | 含义 |
|---|---|
| 汉字 / 字母 | 一个字对一个音符；`~` 把两个字压到一个音符上（如 `五~六`） |
| `@` | **跳过**一个音符（该处不写字） |
| `，。、！？` 等标点 | 自动识别，**不占音符位**，紧跟前面的字渲染 |
| `-`（增时线处） | 不必写 `@`，增时线本来就不配字 |

## 2.4 音符与符号

**音符块**：数字连同它后面的所有修饰（高低音点、变音、时值线、附点、倚音括号）算**一个块**，块内**不写空格**。

| 符号 | 含义 |
|---|---|
| `1`–`7` | 音符（do re mi fa sol la si） |
| `0` | 休止符（可见） |
| `8` | 隐藏休止符（占位但不显示；补多声部用） |
| `9` | 节奏符（X） |
| `'` | 高音点（可多个：`1''`） |
| `,` | 低音点（可多个：`1,,`） |
| `#` `$` `=` | 升 / 降 / 还原，**一律写在数字后**（`1#` `2$` `3=`） |
| `-` | 增时线，每条 +1 拍（`1 - - -` = 4 拍） |
| `/` | 减时线，n 条 = 1/2ⁿ 拍（`1/` 八分、`1//` 十六分） |
| `.` | 附点，×1.5；两个附点 = ×1.75（`1..`） |
| `(1)` | 虚音符：括号**紧贴**数字（不做弱奏标记时无需写；与连音线 `( 1` 的区别就看有没有空格） |

## 2.5 倚音

| 写法 | 含义 |
|---|---|
| `3[2/]` | **前倚音**：先奏倚音、再落主音符 |
| `3[h2/]` | **后倚音**：主音符先奏，最后才奏倚音 |
| `3 -[h5/]` / `3.[h5/]` | 后倚音写在**增时线/附点之后**（谱面上画在这些元素之后） |
| `3[3/2/]` | 多倚音：组内**均分**组时值 |

**时值规矩（adj489；adj505/adj507/adj623/adj624 按用户规范修订）**：

1. **短倚音**（括号内有减时线）：**组时值 = 主音符因子 × 倚音因子**（adj507），再取上限 `本体 ÷ 2`（adj624）
   ——倚音长短跟着主音符走（同样写 `[2/]`，主音符 1 拍还是 1/2 拍，听感完全不同）。
   - **主音符因子**：**本体 = 1 拍 → `1`**；**本体 < 1 拍 → `1/2`**。
     这里的"本体"**不含增时线和附点**（adj624 用户口径）：`3 -`（2 拍）、`3.`（1.5 拍）都按本体 1 拍算。
   - **倚音因子**：1 条减时线 → `1/4`；2 条 → `1/8`；**≥3 条 → `1/16`（封顶）**。
   - **上限（adj624）**：**主音符本体 < 1/2 拍时，倚音时值 = 本体的 1/2** ⇒ 倚音永远装得进本音符。
   - 组内所有倚音**均分**组时值（减时线数不一致时取最大值，保守）。
   - `3[2/]`（本体 1 拍）= **1/4 拍** → 主音符余 3/4 拍。
   - `3/[2/]`（本体 1/2 拍）= **1/8 拍** → 主音符余 3/8 拍（**是上一条的一半**）。
   - `3//[2/]`（本体 1/4 拍）= **1/8 拍**（= 本体的一半，上限开始生效）；`3///[2/]` = **1/16 拍**；
     `3////[2/]` = **1/32 拍**。
   - `3[2//]` = **1/8 拍**；`3/[2//]` = **1/16 拍**；`3[2///]` = **1/16 拍**（封顶）——倚音因子照旧相乘。
   - 上限与倚音因子并存：本体 1/8 拍时 1 条、2 条减时线的值与上限（1/16 拍）相同 ⇒ **都是 1/16 拍**，
     3 条才更短（**1/32 拍**）。
   - `3 -[2/]` / `3.[2/]`（增时线·附点**不计入本体**）= 仍按本体 1 拍 → **1/4 拍**。
   - `3[3/2/]` = 组时值 1/4 拍、两个各 1/8；`3[2/1/2/]` = 组时值 1/4 拍、三个各 1/12。
2. **长倚音**（括号内无减时线）：占**主音符本体**（数字 + 附点，**不含增时线**）的 ——
   **带附点 → 2/3、不带附点 → 1/2**；组内均分（多个长倚音**共享**这一整份）。
   - `3[2]`（1 拍）本体 1 拍 → 倚 1/2、主 1/2。
   - `3.[2]`（1.5 拍）本体 1.5 拍 → 倚 **2/3 × 1.5 = 1 拍**、主 1/2 拍。
   - `3 -[2]`（2 拍）本体 **1 拍**（增时线不计）→ 倚 1/2 拍、主 3/2 拍。
   - `3[32]` 两个倚音共享 1/2 拍（各 1/4）。
   > 只有带 `.` 才用 2/3；**增时线不计入本体**。引擎的时值口径是「附点作用在含增时线的整体上」
   > （`3. -` = 3 拍而非 2.5 拍），"本体"= 把增时线抹零后的引擎时值。
3. **时值来源（adj623，用户规范）**：倚音组的时值**只从本音符自己的时值里匀**——总时值守恒，
   小节总长与后续音符的起始点都不动（不向相邻音符借）。
   - **前倚音**（短/长**同一口径**）：占本音符的**开头**；主音符发声时值 = 本音符总时值 − 组时值。
   - **后倚音**：占本音符的**末尾**（写在 `-`/`.` 之后时，**位置**在那段之后，**时值仍按本体算**）。
   - 短、长倚音与**前、后倚音都是同一把尺子**（adj624）：时值只按本音符本体算，与"前/后"无关。
   - 按上面的时值规则，组时值**天然 ≤ 本音符时值**（短倚音 ≤ 本体的一半、长倚音 ≤ 本体）
     ⇒ **永远装得下**：既不向前/向后一个音符借，也不会撑长小节、更不会把主音符挤成 0 拍。
   - 旧口径（adj489/adj508）的"短前倚音向前一个音符借、抢在拍点之前"已**废弃**。
4. **摆放（adj623）**：
   - **前倚音 → 从本音符的拍点起奏**，主音符**顺延**到倚音之后（长、短倚音**同一口径**）。
     例：`1 3[2/] 1` ⇒ 前一个 1 奏满 1000ms、倚音 1000–1250、**主音符 3 顺延到 1250–2000**（合计仍 1 拍）；
     `1 3[2] 1` ⇒ 前一个 1 奏满 1000ms、倚音 1000–1500、主音 1500–2000。
   - **后倚音 → 依次奏于本音符末尾**（含增时线/附点）；`3 -[h5/]`：主音符先奏满 1.75 拍，最后 1/4 拍奏倚音。
5. **力度（adj505；adj623 后口径不变）**：**短倚音**取 **90%** 力度、稍弱起（旧理由是"不占强位"，
   现在短前倚音也从拍点起奏，但力度这条**不改**）；**长倚音**力度不变。前、后倚音同一把尺子。

（旧规则 `3[3/2/]` 是「1/4 + 1/4 倚音、主音符余 1/2 拍」——adj489 改为「**1/4 组时值均分**」→ 1/8 + 1/8、主音符余 3/4；既有 .jps 的播放时值会变，谱面布局不受影响。旧规则的「Σ > 主音符即报警」也已删除，改为从本音符自己的时值里匀。
adj505 又把**长倚音**从「主音符总时值 / 2」改成「本体 ×（附点 2/3 / 否则 1/2）」——所以 `3.[2]` 由「各 3/4 拍」变为「倚 1 拍、主 1/2 拍」，带增时线的 `3 -[2]` 由「各 1 拍」变为「倚 1/2 拍、主 3/2 拍」。
adj507 把**短倚音**改成「主音符因子 × 倚音因子」——所以 `3[2/]` 回到「倚 1/4、主 3/4」（与 adj489 同），而主音符**带减时线**时减半：`3/[2/]` = 「倚 1/8、主 3/8」。
adj623 把**前倚音**从「向前一个音符借、抢在拍点之前」改回「**占用本音符的时值**」——所以 `1 3[2/] 1` 由「前音 750ms、倚音 750–1000、主音 1000–2000」变为「**前音奏满 1000ms**、倚音 1000–1250、主音 1250–2000」；**长前倚音与后倚音行为不变**，只是与短前倚音归于同一口径。
adj624 又给**短倚音**补了一条上限「**本体 < 1/2 拍时倚音 = 本体的一半**」——所以 `3///[2/]` 由「倚 1/8 + 主 0（整个音符被吃光）」变为「倚 1/16 + 主 1/16」；`3//[2/]`、`3[2/]`、`3 -[2/]` 等**行为不变**，并把"本体不含增时线/附点"写死（`3 -[2/]` 仍按 1 拍本体算 = 1/4 拍）。）

**与连音的关系（adj504）**：倚音与后一个同音同连音时——
- **前倚音**（`(3/[3/5/] 3)`）：第二个 3 **延长**（不重新起奏）。合并只延长主音事件，倚音在开头不受影响。
- **后倚音**（`(3[h5/] 3)`）：**不合并**，第二个 3 照常起奏。后倚音占的是主音符**尾部**，延长主音会把它盖住、变得像"在长音里插一嘴"。

## 2.6 装饰与标记

**`&` 编码**（写在音符后，独立块）——与自动补全、输入条同源：

| 编码 | 含义 |
|---|---|
| `&tr` / `&cy` / `&cy+` | 颤音：`&tr` 带波浪线、`&cy` 只有 tr 文本、`&cy+` 加细密波浪线 |
| `&bc` | **保持音**（tenuto）：音符上方一条短横线（adj496 更正：此前误写作「波音（横线）」，它不是波音） |
| `&zy` / `&dy` / `&yc` | 颤音记号（三角+线）/ 顿音（实心三角）/ 跳音（圆点+圆弧） |
| `&sby` / `&sby+` | 上波音（2.5 齿 / 加长 3.5 齿） |
| `&xby` / `&xby+` | 下波音（带竖线 / 加长 3.5 齿） |
| `&shy` / `&xhy` | 上滑音 / 下滑音（弧线） |
| `&tu` / `&ku` | 吐音（音符上方粗体 **T** / **K**） |
| `&da` / `&die` | 打音（**扌**）/ 叠音（**又**） |
| `&pp` `&p` `&mp` `&mf` `&f` `&ff` `&fff` | 力度（很弱 → 最强），音符上方斜体显示 |
| `&sf` / `&fp` / `&sfp` | 突强 / 强后弱 / 突强后突弱 |
| `&rit` | 渐慢 |
| `&zkh` / `&ykh` | 左 / 右括号标记（**独立标记**，占宽、不依附音符，如 `&zkh 6 6-&ykh`） |
| `&hx` | **呼吸（换气）记号**：独立标记、占宽；演奏时把**前一个音符**总时值的 1/4（最多 1/2 拍）变成静音 |

> 小节线修饰符另有 `&fine`（曲终）/ `&dc`（从头反复）/ `&ds`（跳花 S）/ `&ty`（大跳跃）/ `&hs`（花 S）——见 2.8。
> `&编码` **没有** `-`：`&sby- 2` 里的 `-` 是**音符的增时线**（编码仍是 `&sby`），要加长写 `+`。
> `&编码` 写在音符块（数字 + 修饰 + 倚音括号）**之后**均可：`3&sby` 与 `3[2/]&sby` 等价。

### 波音的演奏时值（adj502，用户规范）

**波音时值与倚音同源：从主音符里"匀"出来，总时值守恒**。区别在起奏方向——
**波音从主音开始**（先弹主音再波动），倚音是**先弹装饰音再进主音**。

| 记号 | 演奏顺序 | 占用 | 每个短音 |
|---|---|---|---|
| `&sby` 单上波音 | 主 → 上邻 → 主 | ≈ P/4 | P/8 |
| `&xby` 单下波音 | 主 → 下邻 → 主 | ≈ P/4 | P/8 |
| `&sby+` 复上波音 | 主 → 上邻 → 主 → 上邻 → 主 | ≈ P/2 | P/8 |
| `&xby+` 复下波音 | 主 → 下邻 → 主 → 下邻 → 主 | ≈ P/2 | P/8 |

1. `P` = **主音符谱面时值**（含增时线/附点）；每个短音 = `P/8`，夹紧在 **45–110ms** 之间。
   于是单波音占 P/4、复波音占 P/2，而两者**波动速度一致**（复只是多波一下）。
2. **拍速越快越紧**（`P/8` 按拍算）；**长音符/附点音上短音不再变长**（上限 110ms）⇒ 占比自然更小（全音符上约 5%）。
3. **不抢太多**：装饰部分最多占 `P/2` ⇒ 主音至少保留一半、**重音仍在主音上**（与"占强拍的长倚音"相反）。
   极短音符上**复波音自动降级为单波音**。
4. **邻音取调内二度**（随调号走），**不继承主音的临时变音**：`#4&sby` 的上邻音是 `5` 而非 `#5`；
   `7` 的上邻音上翻八度（`1'`）、`1` 的下邻音下翻八度（`7,`）。要半音邻音就把实际音写出来。
5. 与**倚音**共存时：先奏倚音，再在主音开头波动（波音的预算在"扣掉倚音后的剩余时值"里匀）。
6. 与**连音**的关系（adj503，分两种情况）：
   - **带波音的音符自己不能并入前一个**——它必须重新起奏并波动（`(5 5/&sby)` 里第二个 5 要奏出来）；
   - **后一个同音可以并入带波音的音符**——并入的是"按住的主音"那一段，波动短音在开头不受影响。
     例：`(5/&sby 5)` 第二个 5 **延长**（不重新起奏），听感是"波动一次后一直按住"。
7. 现代记谱若把波音直接写成实际音符（如三十二分音符），则按谱面精确演奏——不写 `&sby` 就不触发。

**其他标记**：

| 写法 | 含义 |
|---|---|
| `1"文字"` | 音符注释：显示在音符**正上方**（灰色小字，空格用 `_` 表示） |
| `1"文字"+` / `1"文字"-` | 注释**抬升 / 降低**，每级 2px（可多个） |
| `<` / `>` | 渐强 / 渐弱起点（写在其后音符之后，从该音符正中开始） |
| `!` | 渐强/渐弱**结束**（写在音符后，或写在 `-` / `.` 之后 → 收在该元素右缘） |
| `<+` / `>++` | 抬高渐强/渐弱记号，每级 2px（**只有 `+`，没有 `-`**） |

> **`-` 到底属于谁？**（最容易踩的坑）
> `-` 在**音符处永远是增时线**；只有写在**记号自己的区域里**才是"降低"：
> 连音线 `(- 2 3)`、跳房子 `\|[-"1."`、音符注释 `1"注"-` 三处的 `-` 属于各自记号；
> 渐强/渐弱与 `&` 编码**都没有 `-`**——`3<- 4` 里是音符 3 的增时线。

## 2.7 连音线与连音组

| 写法 | 含义 |
|---|---|
| `( 1 2 3 )` | 连音线（可嵌套、跨小节、跨行；括号与音符之间**有空格**） |
| `( (+ 2 3 ) 4 )` | `(+` 抬升线高，每级 2px（可多个 `+`） |
| `( (- 2 3 ) 4 )` | `(-` 降低线高，每级 2px（**这里的 `-` 属于连音线**，不给前一个音符增时） |
| `(y3/ 2/ 1/)` | **等时值连音组**：组内音符**平分该组占用的时值**，弧线上标音符数 |

等时值连音组四条规则（记不住就先照抄示例）：

1. **组总时值 = 小节名义拍数 − 组外音符实际时值**。例：2/4 的 `3./ 6,// (y3/ 2/ 1/) |`——组外已占 1 拍，组占剩下的 1 拍，三个音各 1/3 拍（演奏时值同样 1/3 拍）。
2. **占宽同样按"剩余时值"分摊**：组内每个音符的宽度 = 组总占宽 ÷ 音符数（不按各自写的 `/`）。
3. **减时线连成一条**（跨拍也不断开），同时仍与**同一拍内的组外音符**相连。
4. 组内音符少于 2 个时不生效（退化成普通连音线）。

## 2.8 小节线与反复

| 写法 | 含义 |
|---|---|
| `\|` | 单小节线 |
| `\|\|` | 双小节线（终止） |
| `\|:` `:\|` `:\|:` | 反复开始 / 结束 / 包围 |
| `\|/` | 隐藏小节线 1（不显示**也不占空间**，行首跳房子用） |
| `\|*` | 隐藏小节线 2（不显示**但占空间**，单声部转多声部补位用） |
| `"文字"` | 小节线备注（如 `\|"p:2/4"` 临时拍号） |
| `&fine` `&dc` `&ds` `&hs` `&ty` | 小节线修饰符：曲终 / 从头反复 / 大反复 / 花 S / 大跳跃 |

**跳房子**（`[` 起点 + `|]` 终点，必须写在小节线后）：

| 写法 | 含义 |
|---|---|
| `\|["1." 1 2 3 4 :\|` | 标签为数字 = **番号**（第 N 遍才奏） |
| `\|["结束句" 3 - - - \|]` | 标签为文字（无数字）= **末遍房子**（该段最后一遍才奏） |
| `[+` / `[-` | 抬高 / 降低房子横线（每级 2px，可多个） |
| `\|]/` | 房子终点**不封闭** |
| `[\|]` 与 `\|[\|]` | 同一小节线区域可连续多个：`\|["1." 4 4 5 \|]["2." 5 4 3 \|]` |

> 小节线后的**备注引号**、**`&` 修饰符**、**跳房子标记**三者**顺序无关**（`\|"p:2/4"&hs`、`\|&ds]/&hs` 都行）。
> 音符后的**注释引号**与 `&` 编码同理（`1&tr"注释"` / `1"注释"&tr`），但注释**紧跟的 `+`/`-`** 算注释的升降级数。

**房子终点写 `|]/`（不封闭）时的范围**：这一段房子是"**演奏到下一处跳跃或结束**"，即**其后第一根**满足任一条的小节线：

- 反复线 `:|` / `:|:`（跳跃）
- 结束线 `||` / `||/`（结束）
- 带 `&ds`（跳花 S）、`&dc`（从头反复）、`&fine`（曲终）修饰的小节线

落到那根线时，**它自己的"跳跃 / 结束"照常生效**（例如落到 `|&fine` 就曲终、落到 `|&ds` 就跳花 S）。
也就是说：`|["1." … |]/` 后面的内容一直到那根线为止都属于第 1 遍房子，其它遍不演奏；
线**之后**的音乐照常演奏。已封闭的房子 `|]` 不受此影响（范围就是自己那根线之间）。

### 小节时值校验与临时拍号（adj594）

每个小节里**带时值元素**的时值之和应与当前拍号一致（`P: 4/4` → 每小节 4 拍；`P: 6/8` → 每小节 6 拍）。不一致时给**告警**（不阻断预览/导出）；**每个音轨的第 1 小节只查"整数拍"**（弱起可以不满拍号）：

```
P: 4/4
Q: 1 2 3 4 | 1 2 3 |
                ↑ 告警：第 2 小节共 3 拍，与拍号 4/4（每小节 4 拍）不符
```

- **临时拍号**：把 `|"p:2/4"` 写在小节线后，**从这一小节线之后的小节**（即下一小节）起按 2 拍计，一直延续到同一音轨的下一个临时拍号；不同音轨（`Q1:`/`Q2:`）**各算各的**。
  ```
  Q: 1 2 3 4 | 5 6 7 1' |"p:2/4" 1 2 | 3 - |      ← 后两小节按 2/4 校验，全部对齐
  ```
- **小节号按音轨累加**：同一旋律折成多行 `Q:` 时，第二行的小节接着数（不会又从"第 1 小节"开始）。
- **首小节（弱起）例外**：每个音轨的**第 1 小节只要求"整数拍"**——弱起可以短于拍号（`1 |` = 1 拍、`1 2 |` = 2 拍都合法），但 2.5 拍这种"半拍"仍告警。第 2 小节起必须等于拍号。
- **谁不参与合计**：记号/括号/渐强渐弱（`&hx`、`&zkh…&ykh`、`1<`）、乐器切换、临时段 `{bz … }`——倚音占用主音符的时值，也不额外计入。
- **空小节跳过**：一个小节里一个带时值元素都没有（多声部填充用）不报。
- 末尾**没写收尾 `|`** 的那一截也算一个小节（与排版口径一致）；没写 `P:` 时按 `4/4` 兜底检查。

## 2.9 乐器

| 写法 | 含义 |
|---|---|
| `Y: 钢琴`（描述头） | 默认乐器；多声部按行序对应（Q1→第 1 个 Y，Q2→第 2 个 Y） |
| `@弦乐@` | 曲行内从该时点起切换乐器（当前及以后行） |
| `@generaluser_gs:小提琴"领奏"@` | 带音色库前缀与显示名 |
| `@@` | 切回默认乐器 |

- 乐器名要与试听音色名对得上：钢琴 / 风琴 / 弦乐 / 长笛 / 铜管 / 八音盒（GM 音色名亦可）。对不上会回退默认乐器。
- 旧的裸写法 `@弦乐`（无尾 `@`）仍能解析，但会提示改用 `@弦乐@`；勾选「谱面设置 → 布局 → 显示乐器名」后会在切换处标出乐器名。
- **音色优先级（adj455 起）**：分两档，口径单一、可预期——
  - **「音色」选「自动」** → 全部跟随谱面，按 **曲内 `@乐器名@` > 描述头 `Y:`（按声部）> 「音色库」启用列表第一 > 音色库第一音色（大钢琴）** 路由；
  - **「音色」选定某个具体音色** → **全篇都用它**：主声部、`{bz}`/`{dsb}` 伴奏/第二声部、以及曲内 `@乐器名@` 切换**全部被覆盖**（试听界面会提示"谱面里有 N 处 `@` 已被统一覆盖"，避免误判"写了 `@` 却不生效"）。
  - 也就是说：**要看谱面本身的音色配置就选「自动」**；要"整首换一个音色听"就选具体音色。
  - **这条只作用于「试听」**：导出（MIDI / WAV / MP3）**始终按谱面音色**（`Y:` 行与曲内 `@乐器名@`）导出，
    不跟随试听对话框的音色选择（否则"先试听换个音色再导出"会静默改变导出结果）。
- **倚音跟随主音符音色（adj436）**：倚音（`3[5]` / `3[h5]`）是**独立发声**的，它继承所属主音符的
  音色与声部角色——`@手风琴@ 3/[3/5/]` 里两个倚音也是手风琴，不会中途切回默认音色。

## 2.11 多声部

- `Q1:` `Q2:` 编号 + `C1:` `C2:` 歌词；`Q1"女声":` 可加声部名。
- 短声部用 `8`（隐藏休止符）补音符、`|*`（隐藏小节线 2）补小节，做到各声部小节对齐。
- 声部数多于 `Y:` 行数时，多出的声部用默认乐器。

### 单声部行与多声部组混排（演奏顺序，adj595）

**连续写在一起**的曲行才算一组：同一组内**声部号不重复** ⇒ 同时演奏；一旦出现重复声部号就**另起一组**，
一组接一组**依次**往下演奏。单声部行（`Q:` = 声部 1）自成一组，单独用**第一音色**（`Y:` 第 1 条）演奏。

```
Q:  1 2 3 4 |      ← 单声部：单独奏（第一音色）
Q1: 5 5 5 5 |      ┐ 第一组多声部：两行**同时**奏（Q1 用第 1 条 Y、Q2 用第 2 条 Y）
Q2: 3 3 3 3 |      ┘
Q1: 6 6 6 6 |      ┐ 第二组多声部：接在第一组**之后**，不与它重叠
Q2: 2 2 2 2 |      ┘
Q:  7 7 7 7 |      ← 又回到单声部：接在第二组之后，仍用第一音色
```

即顺序为「单声部 → 第一组 → 第二组 → 单声部……」，与排版上下分块的外观一致（排版同样是"声部号重复即另起一块"）。

## 2.12 临时伴奏与临时多声部（`{bz … }` / `{dsb … }`）

一段旋律里，某几拍想**临时加一层伴奏**、或**临时分成两个声部**，用 `{bz … }` / `{dsb … }` 直接写在
曲行中间即可——不必把整首曲子都改成多声部（见 2.11）。

- **`{bz … }` 临时伴奏**：段内是伴奏声部，画在主旋律**上方**，与主旋律**同一拍位垂直对齐**。
- **`{dsb … }` 临时多声部**：段内是**上声部**；该段覆盖范围内的主旋律自动成为**下声部**，
  两层上下叠放、同一拍位对齐，并用一对大花括号 `{ }` 把两层括在一起。

**写法**：`{bz` / `{dsb` 之后留一个空格，段末用 `}` 收尾。段内可以正常写音符、时值、小节线：

```jps
V: 1.0
B: 临时伴奏示例
D: C
P: 4/4
Q: 3 4 | {bz 1 2 3 4 | 5 6 7 1'} 5 6 7 1' | 1' 7 6 5 | 5 5
```

```jps
V: 1.0
B: 临时多声部示例
D: C
P: 4/4
Q: 3 4 | {dsb 1 2 3 4 | 5 6 7 1'} 5 6 7 1' | 1' 7 6 5 | 5 5
```

括号有两种写法，**任选一种**（不要同时用，否则会出现两层括号）：

- **自动括号**：段内不写括号，程序自动给整段加一对圆括号 `( … )`。
- **显式括号**：在段内自己写 `&zkh` / `&ykh`（左/右括号），程序就按你写的位置画、并为其**预留占宽**：

```jps
V: 1.0
B: 显式括号的临时伴奏
D: C
P: 4/4
Q: 3 4 | {bz &zkh 1 2 3 4 | 5 6 7 1' &ykh } 5 6 7 1' | 1' 7 6 5 | 5 5
```

**对齐与宽度规则**（这是它"能对上"的关键）：

| 项 | 规则 |
|---|---|
| 段占不占拍？ | **不占**。段是叠加层：`{ … }` 前后主旋律的拍位连续不变 |
| 段有多宽？ | **包络** = `[段所在拍位, 段所在拍位 + 段自身总拍数)`，与主旋律同一拍位区间对应 |
| 段内音符怎么排？ | 按**拍位比例**映射到包络内（`1-` 占 2 拍，宽度就是 `1` 的两倍） |
| **每拍占宽？** | 段内外的**每拍占宽一致**（富余按拍数等比分配，段不会把相邻小节挤窄）。大括号/圆括号所需的间隙记在**边界小节线**上并计入非时值占位预算，只让所有拍**同比例**略窄，不破坏均匀性 |
| 段内小节线？ | 按**段内自身拍位**推进，再映射到**主旋律小节线**的位置——上下两条 `\|` 精确对齐 |
| 段右边界？ | 收在**主旋律小节线**处（不越过它），右括号落在该小节线**之前** |
| 段左边界？ | 段首音与主旋律同拍位音符对齐；左括号落在段首音**左侧**预留出的空位里 |
| 括号占宽？ | 段内 `&zkh`/`&ykh` 的占宽**计入行宽预算**（上下两层一起考虑占宽），不会被音符压住 |
| 括号位置/间距？ | 与全谱其它括号**同一套**：文本括号字形、**与数字同高**（字形中心 = 数字中心），左右各留 `0.5×字号` 间距 |
| 段层画在哪？ | bz：画在主旋律**上方**一层；dsb：上（段内容）+ 下（包络内主旋律）**两层整块下移**，使整块中线与主旋律其余部分**居中对齐** |
| **大括号在哪？** | dsb 的大括号是**无时值占宽元素**（同 `&zkh/&ykh` 只占宽、不占拍）：左 `{` 在起始小节线**右侧**、右 `}` 在结束小节线**左侧**，圆括号排在大括号内侧——好比把下一行两侧的小节线**向上延伸**，段内容全在这两条线**内部**排布（且与小节线留出净距，不贴线）。纵向**包住上下两层**——上端高过上一行音符的上沿、下端低过下一行音符的下沿；形状为自绘的**细条轮廓**（中段略粗、两端与中间尖角收拢），不依赖具体字体 |
| dsb 的下声部？ | 取包络范围内的主旋律音，与上声部同一拍位垂直对齐 |
| 上下层**间距可调**？ | 可以：在「谱面设置 → 布局 → 临时段」里分别设 `bz 段上下间距` / `dsb 段上下间距`（单位 px，10–80，默认 22 ≈ 1.7×字号）。bz 调间距只让段层上下移动、主旋律不动；dsb 调间距让两层**对称外扩**、整块中线仍对齐主旋律基线。这是**谱面级**设置，会写进 `# jps-config` |

**注意**：

- 段必须**成对闭合**（`{bz … }`）；缺少 `}` 会报「未找到结束 "}"」。
- 段**不支持嵌套**——段内再写 `{bz` / `{dsb` 会报「不能嵌套在已有段内」。
- 单独出现的 `}` 会报「多余的 "}"」。

**试听效果（声部与音色）**：

重叠区按**两个声部**演奏，各用不同音色、不同颜色的色块：

| 段型 | 上层（段内容） | 下层（包络内主旋律） |
|---|---|---|
| **`{bz … }`** | **伴奏声部**：用**第 2 可用音色**（脚本第 2 条 `Y:` 行；没有则「手风琴」），力度 **0.75** | **主声部**：沿用该曲行音色、力度不变 |
| **`{dsb … }`** | **主声部**：用该曲行音色、力度不变 | **第二声部**：用**第 2 可用音色**（同上），力度 **0.75** |

- 段层与主旋律**同一拍位同刻发声**（时间由排版坐标决定，反复/跳房子下也同步）。
- 重叠区按**多声部**呈现：**上下两层各有一个色块、同步移动**（上层 = 段内容，下层 = 包络内主旋律）。
- 段落在 `|: … :|` 里时，**每一遍都会演奏**。
- 色块**按音色着色**——不同音色不同颜色；播放中用 `@乐器名` 切换音色时，色块颜色随之变化。
- 伴奏 / 第二声部的音色**由本谱决定**（`Y:` 第 2 行，缺省「手风琴」）——**「音色」选「自动」时**不会被别处压成同一种音色；
  但**选定某个具体音色时全篇统一**，重叠区两个声部也会一起换成它（adj455，见 2.9 的音色优先级）。
- 第 1 可用音色即主声部音色（默认「大钢琴」，也就是「全局设置 → 音色库」启用列表的首位）。

**色块动态定界**（adj429）：多声部 Q1/Q2 的色块按声部中线**自动分块**（互不重叠）；临时叠加段的上下两层也按中线分块，且每块高度不小于 4 px（不到则隐藏）。色块不会侵入歌词区（默认 `+0.6×字号` 的下沿远小于歌词行 `quci=15`）。**adj429b（dsb 上下严格等高）**：dsb 上下两层色块**严格等高**（用户建议）——把"对称中线"从 row.y 上移 0.25×字号 = 3.25 px，让 upper 用 TOP_EXT(1.1ns) 覆盖减时线、lower 用 BOT_EXT(0.6ns) 不压歌词，两者通过中线偏移消化上下延伸量的天然不对称；整组随之轻微上移，但上行曲部底 − quci=15 ≫ 3.25，无侵入风险。

**色块颜色（adj432）**：段内声部角色决定色块颜色——`{bz … }` 上层（伴奏）= **蓝**、`{dsb … }` 上层（主声部）= **红**、`{dsb … }` 下层（第二声部）= **绿**；普通主旋律仍按音色着色（第 1 音色红、其它音色依次取调色板）。

**段层间距可拖动（adj432）**：预览区「排版辅助虚线」下，段层行虚线为**紫色**（与曲行绿、描述头橙、边距青区分），拖它调整：
- `{bz … }` 上层虚线 → `segmentRowGap.bz`（伴奏层与主旋律的间距；向上拖 = 增大）
- `{dsb … }` 上层虚线 → `segmentRowGap.dsb`（向上拖 = 增大间距，两层对称外扩）
- `{dsb … }` 下层虚线 → `segmentRowGap.dsb`（向下拖 = 增大间距，同一变量）

拖动即改设置面板「谱面设置 → 布局 → 临时段」的两个数值，并写进谱面 `# jps-config`（差量写入）——换机器/换人打开同一份 `.jps` 版面一致。

## 2.13 块间空格规则

**块与块之间恰好一个空格**：音符块、小节线块、连音线 `(` `)`、装饰 `&…`、跳房子 `[` `]`、乐器 `@…@` 各自是独立块。
音符**块内部**不写空格（`1'#`、`1/.`、`3[2/]` 都连写）。多写空格或漏写空格会被解析器提示。

## 2.14 页面设置行 `# jps-config`

- 程序把"这份谱的版面设置"写在这一行：`# jps-config:{"note_size":14,"margin_left":55}`。
- **差量写入**：只记录与默认值不同的项；全是默认时这一行会被自动删除（所以新文件里看到的是 `# jps-config:{}`）。
- **只写"你改过的项" + 谱面自包含**（adj480）：在「谱面设置」里点「保存设置」时，只有**这一次你真正改动**的字段会写进谱面。
  程序**不再在本机保存一份"页面设置"**（旧版本会，且会套用到未自带设置的谱面）——因此
  "你看到的"只由「**代码默认值 + 谱面这一行**」决定：复制源码给别人（或在别的机器/浏览器上打开），
  显示效果一致（唯一不确定的是字体：字体**族**随谱走，但对方机器上未必装了这个字体，会按字体栈回退）。
- 这一行请**不要手改**——要改去「谱面设置」，改完自动写回。
- 生效优先级：**源码（本行）> 代码默认值**。
  （宿主侧可能还有"宿主默认层"：例如 Obsidian 插件的插件设置与笔记 frontmatter——它们只对**本行没写**的项生效，
  且不随谱走；要把它们也带进谱面用插件里的「随谱固化」。）
- **写法要求**（不满足会给告警，不再是静默失效）：必须**顶格**（行首不能有空格/制表符）；
  值必须是 **JSON 对象**；键必须是可识别的设置项（拼错会告警）；值类型要对
  （数值项写数值、布尔项写 `true`/`false`、`page` 取 `A4`/`A5`/`A4_horizontal`/`A5_horizontal`、
  布局模式取 `space`/`duration`、连音线样式取 `0`/`1`/`2`）。不合法的那一项会被**忽略并告警**（问题条 + 状态栏橙点，带行号），
  JSON 整行坏掉则整行忽略、回退默认值，谱面照常渲染。

相关版面规则（在「谱面设置 → 布局」里调）：

| 项 | 说明 |
|---|---|
| 纸张 / 边距 | A4/A5/横版；四边距（默认上下 40、左右 50 px） |
| 两端对齐最小小节数 | 默认 4：一行的**小节数 ≥ 该值**才两端对齐撑满整行 |
| **单行曲部的小节槽** | 一段曲部**只有一行**且小节数少于上面那个值时（如新建文件只有 1 小节），整行按该值**预分小节槽**：每小节占一个槽、槽内音符自动摊开，行尾留白；某小节内容放不下就按自身自然宽度排开 |
| 布局模式 | 空间优先（默认，按本体宽+富余摊开）/ 时值优先（按时值比例） |

## 2.15 音符的"自动格式化"

编辑时不用手抠空格：光标离开某条 `Q:` 行时，编辑器会自动整理块间空格（数字前补空格等）。
格式化的对象是**块间空格**，块内写法（`1'#`、`3[2/]`）不会被拆开。

# 第四部分 报错与排查

编辑器在**行号栏**标色（红=错误、黄=告警），点问题提示条可跳到出错位置；每条报错都带「**正确写法**」。

| 报错 / 现象 | 常见原因 | 正确写法 |
|---|---|---|
| 块之间空了两个空格 | 块间**恰好一个空格** | `1 2 3`（不要 `1  2`） |
| 无法识别的符号 | 用了本语法没有的字符（如 `%`、全角空格） | 换成合法符号；不确定就看 2.4 的表 |
| 引号未闭合 | `1"注释` 少了右引号 | `1"注释"` |
| 多空格 / 缺空格导致 `@`、`&` 解析错 | 独立块没有单独占一格 | `1 &tr 2`、`1 @弦乐@ 2` |
| 跳房子位置不对 | `[` 没写在**小节线后** | 行首写 `\|/ ["1." …`，行中写 `\|["1." …` |
| `C:` 行"孤零零"（前面没有曲行） | 词行必须跟在**同声部的 Q 行**后面 | 先写 `Q:` 再写 `C:` |
| `@乐器名` 出现告警 | 旧写法 | 改用 `@乐器名@` |
| 连音线被当成虚音符 / 反之 | `(` 与音符之间少了空格 | 连音线写 `( 1 2 )`；虚音符写 `(1)` |
| 渐强/渐弱不显示 | 没写结束 `!`，或跨了行 | `<` 与 `!` 写在**同一行的音符后**；不写 `!` 则收到行末 |
| 增时线数量不对 / 音符被吃掉 | 把 `-` 当成"降低一级"写在了渐强/编码后面 | 渐强只有 `+`；`-` 一律是增时线 |
| 试听没声音 | 音色库未就绪 / 未勾选音色 | 桌面端首次打开会自动准备内置音源；Web 端首次需联网下载一次；勾选「全局设置 → 音色库」里的音色 |
