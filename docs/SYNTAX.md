# 第一部分 五分钟上手

## 1.1 什么是 .jps

`.jps` 是一份**纯文本**简谱：用几行"描述头"写标题/调式/拍号，再用 `Q:` 行写音符、`C:` 行写歌词。
一个文件就是一首谱，没有二进制、没有隐藏格式，用记事本也能改。

结构只有两段：

```
描述头（每行一个字段，字母 + 冒号）      ← 必须有
主体（Q: 曲行 / C: 词行，可写很多行）    ← 谱子的内容
```

## 1.2 最小可用谱

下面 6 行就是一首完整、能渲染也能试听的谱。**先整段选中复制**：

```jps
V: 1.0
B: 最小示例
D: C
P: 4/4
Q: 1 2 3 4 ||
```

- `V:` 版本（固定写 `1.0`，必须有）、`B:` 标题、`D:` 调式、`P:` 拍号（必须有）
- `Q:` 曲行：`1 2 3 4` 是四个音符（简谱数字），`||` 是终止小节线

## 1.3 在 iJipu 里跑起来

1. 打开 iJipu（网页版 / 桌面版 / 手机 App 都一样）→ **默认左边是预览区、右边是编码区**
   （两边想对调：「全局设置 → 版面 → 左右排列」）。
2. 全选编码区内容（`Ctrl+A`），把上面那段粘进去（`Ctrl+V`）。
3. 谱面立刻重排。点顶部「**试听**」→「播放」就能听到声音。
4. 想改？直接改数字：`1` 换成 `5` 试试。

> 手机上如果看不到编码区，点顶栏的「编码 / 拆分 / 预览」切换，或把手机横过来。

## 1.4 在 Obsidian 笔记里用

在笔记里写一个 `jps` 代码块，装上 iJipu 插件后就会渲染成谱面：

    ```jps
    V: 1.0
    B: 小星星（片段）
    D: C
    P: 4/4
    Q: 1 1 5 5 | 6 6 5 - ||
    C: 一 闪 一 闪 亮 晶 晶
    ```

（插件安装与用法见插件仓库的说明；语法与这里完全一致。）

## 1.5 一步一步加东西

### 第 1 步：加歌词（`C:` 行）

歌词**一个汉字对一个音符**，自动对齐；中文标点不占音符位、跟在字后：

```jps
V: 1.0
B: 两只老虎（片段）
Z: 法国童谣 词曲
D: C
P: 4/4
J: 120
Q: 1 2 3 1 | 1 2 3 1 | 3 4 5 - | 3 4 5 - ||
C: 两 只 老 虎 两 只 老 虎 跑 得 快 跑 得 快
```

- `Z:` 作者、`J:` 速度（每分钟拍数）都是**可选**的。
- 一行曲可以配多行词（再写一条 `C:`）。某个音符不想配字就写 `@` 占位。

### 第 2 步：写时值（减时线、附点、增时线、休止）

```jps
V: 1.0
B: 时值练习
D: C
P: 4/4
J: 88
Q: 1 2 3 4 | 5/ 6/ 7 1' - | 1. 2/ 3/ 4. | 0 5, 6, - ||
```

| 写法 | 含义 | 拍数（以 4/4、1 拍为基准） |
|---|---|---|
| `1` | 基本音符 | 1 拍 |
| `1/` | 一条减时线（八分） | 1/2 拍 |
| `1//` | 两条减时线（十六分） | 1/4 拍 |
| `1.` | 附点 | ×1.5（`1.` = 1.5 拍） |
| `1/` 再加 `.` | `1/.` | 1.5 × 1/2 = 0.75 拍 |
| `1 -` | 增时线（每条 +1 拍） | 2 拍；`1 - - -` = 4 拍 |
| `1'` / `1,` | 高音点 / 低音点 | 不影响时值 |
| `0` | 休止符（可见） | 1 拍 |

### 第 3 步：加连音、倚音、装饰

```jps
V: 1.0
B: 连音与倚音
D: C
P: 4/4
J: 88
Q: 1[65] ( 3 4 ) 5"渐强" | 6&tr 7 1' (y3/ 2/ 1/) ||
```

- `1[65]`：**前倚音**（先奏 6、5 两个小音符，再落到 1）；`1[h65]` 是**后倚音**。
- `( 3 4 )`：**连音线**（括号与音符之间要有空格）。
- `5"渐强"`：音符上方的**注释小字**；`6&tr`：**颤音**（`&` 开头的装饰编码）。
- `(y3/ 2/ 1/)`：**等时值连音组**（三个音平分"这一小节剩下的时值"，弧线上标数字）。

### 第 4 步：加反复与跳房子

```jps
V: 1.0
B: 反复与跳房子
D: C
P: 4/4
J: 100
Q: |: 1 2 3 4 | 5 6 7 1' |["1." 1 2 3 4 :|["2." 5 4 3 2 |] ||&fine
```

- `|:` `:|` 反复开始 / 结束；`["1." ...` 第一遍的房子、`["2." ...` 第二遍的房子，`|]` 收尾。
- `&fine` 画在终止线上（曲终记号）；同类还有 `&dc`（从头反复）/`&ds`（大反复）/`&hs`（花 S）。

### 第 5 步：多声部与乐器

```jps
V: 1.0
B: 多声部
D: C
P: 4/4
J: 96
Y: 钢琴
Y: 弦乐
Q1"主旋律": 1 2 3 4 | 5 6 7 1' | @弦乐@ 1' 7 6 5 | 4 - - - ||
C1: 一 二 三 四 五 六 七 八 九 十 百 千 万 里 江 山
Q2"伴奏": 8 8 8 8 |* 8 8 8 8 |* 8 8 8 8 |* 8 - - - |*
```

- `Q1:`/`Q2:` 是声部编号，`Q1"主旋律":` 给声部起名；`C1:` 对应该声部的歌词。
- `Y:` 每行一种乐器，**按行序对应声部**（第 1 个 `Y` 给 Q1）。
  乐器名可用「全局设置 → 音色库」里列出的任一音色名（`钢琴`、`长笛`、`弦乐合奏1`、`电钢琴`…），
  也可以直接写该音色的**编号**（`Y: 21` 即手风琴；编号就是音色库列表里名称前的数字）。
- `8` 是**隐藏休止符**、`|*` 是**隐藏小节线**——用来把短声部补齐对齐（上面伴奏声部就是靠它们占位）。
- `@弦乐@` 在曲行中途切换乐器，`@@` 切回默认乐器。

## 1.6 写错了怎么办

- 编辑器**行号栏**会变红/黄，光标所在行下方会出现「问题提示条」：写明**哪里错了**、**正确写法**，点一下能跳到出错位置。
- 最常见的三类错误（详见第四部分）：**块之间漏了空格**、**引号没闭合**、**用了不认识的符号**。
- **小节拍数与拍号不符**会给出**告警**（黄色，不是错误）：如 `P: 4/4` 下某小节只有 3.5 拍，会提示「第 N 小节共 3.5 拍，与拍号 4/4（每小节 4 拍）不符」，并给出补齐办法。告警**不影响预览与导出**。
- 改完不用手动刷新：预览区实时重排。

# 第二部分 语法参考

> 这一部分是**查阅用**的：符号表 + 字段表 + 边界说明。所有片段都可直接粘进 `Q:` 行试验。

## 2.1 文件结构

```
描述头（V/B/Z/D/P/J/Y/S，每行一个，至少 V/B/D/P）   ← 文件开头，必须
# 注释行（以 # 开头，整行忽略，可写在任意位置）
Q: 曲行（音符序列，可多行 / 多声部）
C: 词行（歌词，自动对齐上一行的 Q）
[fenye]                                              ← 手动换页
# jps-config:{...}                                   ← 程序写入的页面设置行（请勿手改，见 2.14）
S: 谱尾说明（可多行，支持 \n 换行）
```

## 2.2 描述头（每行一个字段）

| 字母 | 含义 | 示例 | 必须 |
|---|---|---|:--:|
| `V` | 版本号 | `V: 1.0` | ✅ |
| `B` | 标题（可多次：第一个是主标题，其余为副标题） | `B: 排排坐` | ✅ |
| `Z` | 作者（可多次，显示在描述头右侧） | `Z: 佚名 词曲` | |
| `D` | 调式（大写字母，可带 `#`/`$` 升降；升降号也可写在字母前） | `D: C` / `D: F#` / `D: $B` | ✅ |
| `P` | 拍号（`/` 分隔，可多个：辅助拍号加括号） | `P: 4/4` / `P: 6/8 (2/4)` | ✅ |
| `J` | 节拍（数字 = 每分钟拍数；也可写文字显示在拍号下） | `J: 96` / `J: 欢快地` | |
| `Y` | 默认乐器（**一个 Y 行一种**；多声部按行序对应声部） | `Y: 钢琴` | |
| `S` | 谱尾说明（可多次，渲染在**最后一页**正文下方；支持 `\n` 手动换行） | `S: 第一段\n第二段` | |

- 编辑器里**在行首按字母**就能插入对应命令头：`v` `b` `z` `d` `p` `j` `y` `s`，以及 `q`（曲行）/`c`（词行）。
  字母大小写都可以，插入的永远是大写命令头（按 `q` 得到 `Q: `）。
- 各行的**默认位置**（空设置下的排布）：`B:` 标题/副标题居中贴描述头上沿；`Z:` 作者靠**右下角**；
  `D:`+`P:`（调式与拍号，同一行）与 `J:`（节拍，在下一行）靠**左下角**；`Y:` 乐器接在标题下面居中。
  详见 §2.14「描述头默认排布」。
- `S:` 谱尾说明的**默认位置 = 紧靠边距内的右下角**（adj630/adj630b）：整体**右对齐**到右边距（多段、
  以及超宽自动换行的每个子行，右缘都贴同一条线），纵向**自下而上**——**末行紧靠下边距线**（字底距线 2px）、
  往上逐行（行距 = 说明字号 × 1.4）。**两条边距线一改，整块跟着走**（`margin_right` / `margin_bottom`）。
  在预览区拖过它（`metaPos` 里留下 `notes_i`）的谱面按你拖到的位置加偏移；「恢复默认」后回到右下角。

## 2.3 曲行与歌词

| 写法 | 含义 |
|---|---|
| `Q: 1 2 3 4 \|` | 单声部曲行 |
| `C: 一 二 三 四` | 歌词行（对上一个同声部的 `Q:`；一行曲可写多条 `C:`） |
| `Q1:` / `Q2:` | 声部编号（相同编号的行组成多声部块） |
| `Q1"女声":` | 带声部名 |
| `C1:` / `C2:` | 对应声部的歌词 |

歌词规则：

| 写法 | 含义 |
|---|---|
| 汉字 / 字母 | 一个字对一个音符；`~` 把两个字压到一个音符上（如 `五~六`） |
| `@` | **跳过**一个音符（该处不写字） |
| `，。、！？` 等标点 | 自动识别，**不占音符位**，紧跟前面的字渲染 |
| `-`（增时线处） | 不必写 `@`，增时线本来就不配字 |

## 2.4 音符与符号

**音符块**：数字连同它后面的所有修饰（高低音点、变音、时值线、附点、倚音括号）算**一个块**，块内**不写空格**。

| 符号 | 含义 |
|---|---|
| `1`–`7` | 音符（do re mi fa sol la si） |
| `0` | 休止符（可见） |
| `8` | 隐藏休止符（占位但不显示；补多声部用） |
| `9` | 节奏符（X） |
| `'` | 高音点（可多个：`1''`） |
| `,` | 低音点（可多个：`1,,`） |
| `#` `$` `=` | 升 / 降 / 还原，**一律写在数字后**（`1#` `2$` `3=`） |
| `-` | 增时线，每条 +1 拍（`1 - - -` = 4 拍） |
| `/` | 减时线，n 条 = 1/2ⁿ 拍（`1/` 八分、`1//` 十六分） |
| `.` | 附点，×1.5；两个附点 = ×1.75（`1..`） |
| `(1)` | **连音线的连接点**：单音符被 `(` 与 `)` **紧贴**包住 ⇒ 它**结束前一条连音线、同时起下一条连音线**（详见 2.7）。与连音线 `( 1 2 3 )` 的区别就看括号**紧不紧贴** |

## 2.5 倚音

| 写法 | 含义 |
|---|---|
| `3[2/]` | **前倚音**：先奏倚音、再落主音符 |
| `3[h2/]` | **后倚音**：主音符先奏，最后才奏倚音 |
| `3 -[h5/]` / `3.[h5/]` | 后倚音写在**增时线/附点之后**（谱面上画在这些元素之后） |
| `3[3/2/]` | 多倚音：组内**均分**组时值 |

**时值规矩（adj489；adj505/adj507/adj623/adj624 按用户规范修订）**：

1. **短倚音**（括号内有减时线）：**组时值 = 主音符因子 × 倚音因子**（adj507），再取上限 `本体 ÷ 2`（adj624）
   ——倚音长短跟着主音符走（同样写 `[2/]`，主音符 1 拍还是 1/2 拍，听感完全不同）。
   - **主音符因子**：**本体 = 1 拍 → `1`**；**本体 < 1 拍 → `1/2`**。
     这里的"本体"**不含增时线和附点**（adj624 用户口径）：`3 -`（2 拍）、`3.`（1.5 拍）都按本体 1 拍算。
   - **倚音因子**：1 条减时线 → `1/4`；2 条 → `1/8`；**≥3 条 → `1/16`（封顶）**。
   - **上限（adj624）**：**主音符本体 < 1/2 拍时，倚音时值 = 本体的 1/2** ⇒ 倚音永远装得进本音符。
   - 组内所有倚音**均分**组时值（减时线数不一致时取最大值，保守）。
   - `3[2/]`（本体 1 拍）= **1/4 拍** → 主音符余 3/4 拍。
   - `3/[2/]`（本体 1/2 拍）= **1/8 拍** → 主音符余 3/8 拍（**是上一条的一半**）。
   - `3//[2/]`（本体 1/4 拍）= **1/8 拍**（= 本体的一半，上限开始生效）；`3///[2/]` = **1/16 拍**；
     `3////[2/]` = **1/32 拍**。
   - `3[2//]` = **1/8 拍**；`3/[2//]` = **1/16 拍**；`3[2///]` = **1/16 拍**（封顶）——倚音因子照旧相乘。
   - 上限与倚音因子并存：本体 1/8 拍时 1 条、2 条减时线的值与上限（1/16 拍）相同 ⇒ **都是 1/16 拍**，
     3 条才更短（**1/32 拍**）。
   - `3 -[2/]` / `3.[2/]`（增时线·附点**不计入本体**）= 仍按本体 1 拍 → **1/4 拍**。
   - `3[3/2/]` = 组时值 1/4 拍、两个各 1/8；`3[2/1/2/]` = 组时值 1/4 拍、三个各 1/12。
2. **长倚音**（括号内无减时线）：占**主音符本体**（数字 + 附点，**不含增时线**）的 ——
   **带附点 → 2/3、不带附点 → 1/2**；组内均分（多个长倚音**共享**这一整份）。
   - `3[2]`（1 拍）本体 1 拍 → 倚 1/2、主 1/2。
   - `3.[2]`（1.5 拍）本体 1.5 拍 → 倚 **2/3 × 1.5 = 1 拍**、主 1/2 拍。
   - `3 -[2]`（2 拍）本体 **1 拍**（增时线不计）→ 倚 1/2 拍、主 3/2 拍。
   - `3[32]` 两个倚音共享 1/2 拍（各 1/4）。
   > 只有带 `.` 才用 2/3；**增时线不计入本体**。引擎的时值口径是「附点作用在含增时线的整体上」
   > （`3. -` = 3 拍而非 2.5 拍），"本体"= 把增时线抹零后的引擎时值。
3. **时值来源（adj623，用户规范）**：倚音组的时值**只从本音符自己的时值里匀**——总时值守恒，
   小节总长与后续音符的起始点都不动（不向相邻音符借）。
   - **前倚音**（短/长**同一口径**）：占本音符的**开头**；主音符发声时值 = 本音符总时值 − 组时值。
   - **后倚音**：占本音符的**末尾**（写在 `-`/`.` 之后时，**位置**在那段之后，**时值仍按本体算**）。
   - 短、长倚音与**前、后倚音都是同一把尺子**（adj624）：时值只按本音符本体算，与"前/后"无关。
   - 按上面的时值规则，组时值**天然 ≤ 本音符时值**（短倚音 ≤ 本体的一半、长倚音 ≤ 本体）
     ⇒ **永远装得下**：既不向前/向后一个音符借，也不会撑长小节、更不会把主音符挤成 0 拍。
   - 旧口径（adj489/adj508）的"短前倚音向前一个音符借、抢在拍点之前"已**废弃**。
4. **摆放（adj623）**：
   - **前倚音 → 从本音符的拍点起奏**，主音符**顺延**到倚音之后（长、短倚音**同一口径**）。
     例：`1 3[2/] 1` ⇒ 前一个 1 奏满 1000ms、倚音 1000–1250、**主音符 3 顺延到 1250–2000**（合计仍 1 拍）；
     `1 3[2] 1` ⇒ 前一个 1 奏满 1000ms、倚音 1000–1500、主音 1500–2000。
   - **后倚音 → 依次奏于本音符末尾**（含增时线/附点）；`3 -[h5/]`：主音符先奏满 1.75 拍，最后 1/4 拍奏倚音。
5. **力度（adj505；adj623 后口径不变）**：**短倚音**取 **90%** 力度、稍弱起（旧理由是"不占强位"，
   现在短前倚音也从拍点起奏，但力度这条**不改**）；**长倚音**力度不变。前、后倚音同一把尺子。

（旧规则 `3[3/2/]` 是「1/4 + 1/4 倚音、主音符余 1/2 拍」——adj489 改为「**1/4 组时值均分**」→ 1/8 + 1/8、主音符余 3/4；既有 .jps 的播放时值会变，谱面布局不受影响。旧规则的「Σ > 主音符即报警」也已删除，改为从本音符自己的时值里匀。
adj505 又把**长倚音**从「主音符总时值 / 2」改成「本体 ×（附点 2/3 / 否则 1/2）」——所以 `3.[2]` 由「各 3/4 拍」变为「倚 1 拍、主 1/2 拍」，带增时线的 `3 -[2]` 由「各 1 拍」变为「倚 1/2 拍、主 3/2 拍」。
adj507 把**短倚音**改成「主音符因子 × 倚音因子」——所以 `3[2/]` 回到「倚 1/4、主 3/4」（与 adj489 同），而主音符**带减时线**时减半：`3/[2/]` = 「倚 1/8、主 3/8」。
adj623 把**前倚音**从「向前一个音符借、抢在拍点之前」改回「**占用本音符的时值**」——所以 `1 3[2/] 1` 由「前音 750ms、倚音 750–1000、主音 1000–2000」变为「**前音奏满 1000ms**、倚音 1000–1250、主音 1250–2000」；**长前倚音与后倚音行为不变**，只是与短前倚音归于同一口径。
adj624 又给**短倚音**补了一条上限「**本体 < 1/2 拍时倚音 = 本体的一半**」——所以 `3///[2/]` 由「倚 1/8 + 主 0（整个音符被吃光）」变为「倚 1/16 + 主 1/16」；`3//[2/]`、`3[2/]`、`3 -[2/]` 等**行为不变**，并把"本体不含增时线/附点"写死（`3 -[2/]` 仍按 1 拍本体算 = 1/4 拍）。）

**与连音的关系（adj504）**：倚音与后一个同音同连音时——
- **前倚音**（`(3/[3/5/] 3)`）：第二个 3 **延长**（不重新起奏）。合并只延长主音事件，倚音在开头不受影响。
- **后倚音**（`(3[h5/] 3)`）：**不合并**，第二个 3 照常起奏。后倚音占的是主音符**尾部**，延长主音会把它盖住、变得像"在长音里插一嘴"。

### 2.5.1 倚音自身的修饰符（adj632 / adj633）

倚音括号内、**某个倚音数字之后**可以再挂一个修饰符——写法与主音符的 `&` 编码同源：

| 写法 | 含义 | 画在哪里 |
|---|---|---|
| `6/[5/&tu]` | 该倚音上加**吐音**（粗体 **T**） | 该倚音的**正上方** |
| `6/[5/&die]` | 该倚音上加**叠音**（粗体 **又**；演奏 = 上邻→主，见 2.6） | 该倚音的**正上方** |
| `6/[5/&da]` | 该倚音上加**打音**（粗体 **扌**；演奏 = 主→下邻→主，见 2.6） | 该倚音的**正上方** |
| `2[3/&sby]` | 该倚音上加**上波音**（2.5 齿） | 该倚音的**正上方** |
| `2[3/&xby]` | 该倚音上加**下波音**（带竖线） | 该倚音的**正上方** |
| `2[3/&sby+]` | 该倚音上加**长上波音**（复上波音，3.5 齿） | 该倚音的**正上方** |
| `2[3/&xby+]` | 该倚音上加**长下波音**（复下波音，3.5 齿） | 该倚音的**正上方** |
| `6/[5/&shy]` | 该倚音上加**上滑音**（弧线 + 箭头） | 该倚音的**左侧**（与主音符一致） |
| `6/[5/&xhy]` | 该倚音上加**下滑音**（弧线 + 箭头） | 该倚音的**左侧**（与主音符一致） |

1. **形状与主音符同名编码同款**；尺寸都**随倚音一起等比缩小**（adj632/adj632b/adj633，三处口径不同）：
   - **上方文字三个**（`&tu`/`&die`/`&da`）：字号 = **该倚音字号 × 10/18** —— 与主音符的记号**同一把尺子**
     （主音符记号的字号本来就是 `10/18 × 主音符字号`），所以记号跟着倚音一起变小、不会"比倚音还大"。
   - **上方波音四个**（`&sby`/`&xby`/`&sby+`/`&xby+`，adj633）：用与主音符**同一款矢量图形**，
     墨迹宽按「**波音 : 所属音符**」的**同一比率**算 —— 主音符 `9 × (字号/18)`、长波音 `13.5 × (字号/18)`，
     倚音把「字号」换成**倚音字号**即可 ⇒ 倚音上的波音正好是主音符上的一半大（与倚音字号同比例）。
   - **左侧两个**（`&shy`/`&xhy`）：图形**与倚音数字等高**、纵向与数字**齐平**（同顶同底）、右缘**紧贴**数字左侧
     （adj636c 用户要求"和主音符一样，滑音调整到左侧"——记号在音的左边才读得通"滑进本音"）。
2. **多倚音时挂在紧挨着它的那一个倚音上**：`6/[5/&shy2/]` 只有 5 带滑音。
   **上方**的记号会把**后一个倚音**、**左侧**的滑音会把**组左缘**（以及本音符的占位）一并推开，不会压到相邻数字或主音符。
3. **只支持上面这 9 个**。力度、颤音、独立标记 `&zkh`/`&ykh`/`&hx` 等**倚音不支持**
   （倚音只有主音符一半大小、又成组紧排，再堆这些记号必然与主音符自己的记号挤在一起）——
   写了会**告警**提示，不会静默丢弃。
4. 编码要紧跟在**该倚音数字之后**（`1[&tu2/]` 这种写在数字之前的写法会告警）。
5. **只影响谱面**的是 `&tu`/`&shy`/`&xhy` 这 3 个——它们不改变演奏时值；
   4 个**波音**（`&sby`/`&xby`/`&sby+`/`&xby+`）与**打音 `&da` / 叠音 `&die`** **会改变演奏**，
   口径见下面两条（倚音上的演奏型装饰一律"按主音符的同一套计划、时值按比率缩得更短"）。

**倚音上演奏型装饰的演奏（adj633 / adj635）**——用户口径：「**倚音的演奏参考主音符，只在时值按比率缩得更短**」：

1. 装饰的**计划本身按主音符算**：`P` 取主音符（扣掉倚音后的发声时值）、辅助音时长与「装饰最多占 P/2」
   的预算规则都与主音符上的同名记号**完全相同** ⇒ 奏法形状与主音符一致
   （波音 主→邻→主、打音 主→邻→主、叠音 邻→主）。
2. 再把这个计划里的**每一步时长整体乘一个比率** `k = 该倚音的发声时值 ÷ P`——只是按比率变快；
   各步之和正好等于该倚音的时值 ⇒ 倚音**不额外占拍**（时值仍从主音符里匀，见 2.5 的 1~4 条）。
3. 邻音取**该倚音音级**的调内二度（不继承临时变音，`7` 上翻八度、`1` 下翻八度）；
   力度沿用短倚音的 90%（长倚音不变），与主音符"用主音符自己的力度"同一口径。

```jps
V: 1.0
B: 倚音自身的修饰符（adj632 / adj633）
Z: 示例
D: C
P: 4/4
Q: 6/[5/&tu] 1/ 6/[5/&die] 2/ 6/[5/&shy] 3/ 6/[5/&xhy] 4/ |
Q: 2[3/&sby] 2[3/&xby] 2[3/&sby+] 2[3/&xby+] |
Q: 6/[5/&shy2/] 1/ 3[h5/&xhy] 2/ 3[2/&da] 1/ | 6/[5/&tu] 1/ 3[h5/&xhy] 2/ 3[2/&da] 1/ |
```

## 2.6 装饰与标记

**`&` 编码**（写在音符后，独立块）——与自动补全、输入条同源：

| 编码 | 含义 |
|---|---|
| `&tr` / `&cy` / `&cy+` | 颤音：`&tr` 带波浪线、`&cy` 只有 tr 文本、`&cy+` 加细密波浪线 |
| `&bc` | **保持音**（tenuto）：音符上方一条短横线（adj496 更正：此前误写作「波音（横线）」，它不是波音） |
| `&zy` / `&dy` / `&yc` | 颤音记号（三角+线）/ 顿音（实心三角）/ 跳音（圆点+圆弧） |
| `&sby` / `&sby+` | 上波音（2.5 齿 / 加长 3.5 齿） |
| `&xby` / `&xby+` | 下波音（带竖线 / 加长 3.5 齿） |
| `&shy` / `&xhy` | 上滑音 / 下滑音（弧线，**画在音符左侧**——滑进本音的记号写在音的左边） |
| `&tu` / `&ku` | 吐音（音符上方粗体 **T** / **K**） |
| `&da` / `&die` | 打音（**扌**）/ 叠音（**又**）——竹笛、葫芦丝的传统装饰音，**会改变演奏**，见 2.6「打音 / 叠音的演奏」 |
| `&pp` `&p` `&mp` `&mf` `&f` `&ff` `&fff` | 力度（很弱 → 最强），音符上方斜体显示 |
| `&sf` / `&fp` / `&sfp` | 突强 / 强后弱 / 突强后突弱 |
| `&rit` | 渐慢 |
| `&zkh` / `&ykh` | 左 / 右括号标记（**独立标记**，占宽、不依附音符，如 `&zkh 6 6-&ykh`） |
| `&hx` | **呼吸（换气）记号**：独立标记、占宽；演奏时把**前一个音符**总时值的 1/4（最多 1/2 拍）变成静音 |

> 小节线修饰符另有 `&fine`（曲终）/ `&dc`（从头反复）/ `&ds`（跳花 S）/ `&ty`（大跳跃）/ `&hs`（花 S）——见 2.8。
> `&编码` **没有** `-`：`&sby- 2` 里的 `-` 是**音符的增时线**（编码仍是 `&sby`），要加长写 `+`。
> `&编码` 写在音符块（数字 + 修饰 + 倚音括号）**之后**均可：`3&sby` 与 `3[2/]&sby` 等价。
> 其中 `&tu`/`&die`/`&da`/`&shy`/`&xhy` 与 4 个波音 `&sby`/`&xby`/`&sby+`/`&xby+`
> 还能写在**倚音括号内**（只作用在那一个倚音上，如 `6/[5/&tu]`、`2[3/&sby]`）——
> 位置与尺寸规则见 2.5.1。

### 波音的演奏时值（adj502，用户规范）

**波音时值与倚音同源：从主音符里"匀"出来，总时值守恒**。区别在起奏方向——
**波音从主音开始**（先弹主音再波动），倚音是**先弹装饰音再进主音**。

| 记号 | 演奏顺序 | 占用 | 每个短音 |
|---|---|---|---|
| `&sby` 单上波音 | 主 → 上邻 → 主 | ≈ P/4 | P/8 |
| `&xby` 单下波音 | 主 → 下邻 → 主 | ≈ P/4 | P/8 |
| `&sby+` 复上波音 | 主 → 上邻 → 主 → 上邻 → 主 | ≈ P/2 | P/8 |
| `&xby+` 复下波音 | 主 → 下邻 → 主 → 下邻 → 主 | ≈ P/2 | P/8 |

1. `P` = **主音符谱面时值**（含增时线/附点）；每个短音 = `P/8`，夹紧在 **45–110ms** 之间。
   于是单波音占 P/4、复波音占 P/2，而两者**波动速度一致**（复只是多波一下）。
2. **拍速越快越紧**（`P/8` 按拍算）；**长音符/附点音上短音不再变长**（上限 110ms）⇒ 占比自然更小（全音符上约 5%）。
3. **不抢太多**：装饰部分最多占 `P/2` ⇒ 主音至少保留一半、**重音仍在主音上**（与"占强拍的长倚音"相反）。
   极短音符上**复波音自动降级为单波音**。
4. **邻音取调内二度**（随调号走），**不继承主音的临时变音**：`#4&sby` 的上邻音是 `5` 而非 `#5`；
   `7` 的上邻音上翻八度（`1'`）、`1` 的下邻音下翻八度（`7,`）。要半音邻音就把实际音写出来。
5. 与**倚音**共存时：先奏倚音，再在主音开头波动（波音的预算在"扣掉倚音后的剩余时值"里匀）。
   波音也可以直接写在**倚音**上（`2[3/&sby]`）——那时它按主音符的同一套计划、只是时值按比率缩得更短，
   见 2.5.1「倚音上演奏型装饰的演奏」。
6. 与**连音**的关系（adj503，分两种情况）：
   - **带波音的音符自己不能并入前一个**——它必须重新起奏并波动（`(5 5/&sby)` 里第二个 5 要奏出来）；
   - **后一个同音可以并入带波音的音符**——并入的是"按住的主音"那一段，波动短音在开头不受影响。
     例：`(5/&sby 5)` 第二个 5 **延长**（不重新起奏），听感是"波动一次后一直按住"。
7. 现代记谱若把波音直接写成实际音符（如三十二分音符），则按谱面精确演奏——不写 `&sby` 就不触发。

### 打音 / 叠音的演奏（adj635，用户说明）

竹笛、葫芦丝的传统装饰音，**核心是用极短的辅助音来装饰主音**——`&da` 是打音（向下）、`&die` 是叠音（向上）：

| 记号 | 演奏顺序 | 占用 | 每个辅助音 | 记号的用途 |
|---|---|---|---|---|
| `&die` 叠音 | 上邻 → **主** | ≈ P/16 | `P/16` | 主音前"从上面压下来"，柔和的弹性 |
| `&da` 打音 | **主** → 下邻 → 主 | ≈ P/8（两个短音） | `P/16` | 把两个相同的音**断开**，"音断意连" |

1. 两种技法的**辅助音都"极小"**：`P/16`，夹紧在 **30–70ms** 之间 —— 取波音短音（`P/8`、45–110ms）的**一半量级**
   （用户原话："辅助音占的时值极小，否则听起来就会显得拖沓，变成普通的倚音了"）。
   `P` = 主音符**发声时值**（扣掉倚音后的剩余）。
2. **总时值守恒、最多占 `P/2`**（与波音同一套不变式）：辅助音 + 缩短的主音 = 原时值 ⇒ 不占拍、后续音符不动；
   极短音符上按比例压缩，"塞得进去"优先。
3. **叠音的上邻音占本音符开头**，主音顺延（与前倚音同一口径，**不向前一个音符借**）；
   **打音从主音短促起奏**（先"打"一下本音，再落辅助音），所以它的第一个短音就是主音本身。
4. **邻音取调内二度**（同波音第 4 条）：不继承主音的临时变音，`7` 上翻八度、`1` 下翻八度。
   例（C 调）：`1&die` ≈ 极快地 `2 → 1`；`1&da` ≈ `1 → 7 → 1`（中间那个 7 非常短促）。
5. **与连音的关系**：带打音/叠音的音符**自己不能并入前一个**同音——打音的用途正是"把两个相同的音断开"
   （`(1&da 1)` 里两个 1 都要奏出来）；后一个同音并入带装饰的音符时，并入的是"按住的主音"那一段。
6. **只认一个**：同一音符同时写了波音与打音/叠音时，按 **波音 → 打音 → 叠音** 取一个（不叠加）。
7. 也可以写在**倚音**上（`6/[5/&die]`、`3[2/&da]`）：按主音符的同一套计划、只是时值按比率缩得更短，
   与倚音上的波音同一条口径（见 2.5.1）。

```jps
V: 1.0
B: 打音与叠音（adj635）
Z: 示例
D: C
P: 4/4
Q: 1&die 2 3&da 3 | 5&die 5&da 6 7 |
```

### 滑音的演奏（adj636，用户说明）

滑音（`&shy` 上滑音 / `&xhy` 下滑音）与前两类最大的不同是**它是"线状"的**——用户说明：
"叠音、打音是'点状'的快速装饰，而滑音是'线状'的，依靠手指在音孔上逐渐滚动或抹动，
让音高平滑地过渡，中间没有断痕"。

**记号写在哪、滑到哪（用户口径）**：两种记号都当成"**从上／下一个音滑进本音**"——
`&shy` 一律**从下方**滑进被标记的这个音、`&xhy` 一律**从上方**滑进它；
**记号画在音符的左侧**（滑进本音的记号写在音的左边才读得通）。
起点取该音在滑动方向上的**调内二度**邻音（与波音/打音/叠音同一套邻音规则，含八度回卷）：

| 记号 | 演奏（C 调示例） | 听感 |
|---|---|---|
| `&shy` 上滑音 | `6&shy` = **5 → 5# → 6** | 从下方"爬"上来 |
| `&xhy` 下滑音 | `5&xhy` = **6 → 5# → 5** | 从上方"坠"下来 |

1. **逐半音的连续渐变**，不是直接跳到本音——用户举的正是"`5 → 5# → 6` 这样一个连续渐变的过程"。
2. **每格时长 = `clamp(P/8, 30, 60)ms`**，且整段滑行**最多占 `P/2`**（与装饰音同一预算不变式）
   ⇒ "逐渐、缓慢"但不拖，本音自己的音高至少按住一半。
3. **不改变任何音符的时值**：滑行只占本音符的**开头**，到达本音音高后一直按住到本音符结束
   ⇒ 后续音符的起点、整曲拍位都不动。
4. **邻音取调内二度**（同 2.6 波音第 4 条：不继承临时变音，`7` 上翻八度、`1` 下翻八度）；
   全谱第一个音也照样成立（起点只由"方向 + 调内二度"决定，不依赖前一个音）。
5. **与连音**：带滑音的音符**自己不能并入前一个**同音（并进去滑行就没了）。
6. **与点状装饰同时写时**：**点状装饰优先**（`3&da&shy` 奏打音、不叠加滑音）。
7. **也可以写在倚音上**（`6/[5/&shy]`）：按主音符的同一套计划、只是时值按比率缩得更短，
   与倚音上的波音/打音/叠音同一条口径（见 2.5.1）。

```jps
V: 1.0
B: 滑音（adj636）
Z: 示例
D: C
P: 4/4
Q: 5&shy 6 5&xhy 3 | 2&shy 3&xhy 1 2 |
```

**其他标记**：

| 写法 | 含义 |
|---|---|
| `1"文字"` | 音符注释：显示在音符**正上方**（灰色小字，空格用 `_` 表示） |
| `1"文字"+` / `1"文字"-` | 注释**抬升 / 降低**，每级 2px（可多个） |
| `<` / `>` | 渐强 / 渐弱起点（写在其后音符之后，从该音符正中开始） |
| `!` | 渐强/渐弱**结束**（写在音符后，或写在 `-` / `.` 之后 → 收在该元素右缘） |
| `<+` / `>++` | 抬高渐强/渐弱记号，每级 2px（**只有 `+`，没有 `-`**） |

> **`-` 到底属于谁？**（最容易踩的坑）
> `-` 在**音符处永远是增时线**；只有写在**记号自己的区域里**才是"降低"：
> 连音线 `(- 2 3)`、跳房子 `\|[-"1."`、音符注释 `1"注"-` 三处的 `-` 属于各自记号；
> 渐强/渐弱与 `&` 编码**都没有 `-`**——`3<- 4` 里是音符 3 的增时线。

## 2.7 连音线与连音组

| 写法 | 含义 |
|---|---|
| `( 1 2 3 )` | 连音线（可嵌套、跨小节、跨行；括号与音符之间**有空格**） |
| `( (+ 2 3 ) 4 )` | `(+` 抬升线高，每级 2px（可多个 `+`） |
| `( (- 2 3 ) 4 )` | `(-` 降低线高，每级 2px（**这里的 `-` 属于连音线**，不给前一个音符增时） |
| `(y3/ 2/ 1/)` | **等时值连音组**：组内音符**平分该组占用的时值**，弧线上标音符数 |

**连接点 `(X)`**（`adj321`；用户口径反复强调，**不是"虚音符"——那个说法已废弃**）：
当 `(` 与 `)` **紧贴**同一个音符（如 `(2)`）时，这个音是**两条连音线的连接点**：
它**结束前一条连音线**、同时**起下一条连音线**。

```text
Q: (1 - (2) - | 3) --- |      ← (2) 是连接点：1→2 一条、2→3 一条，共两条线
```

- **判据**是"外面还有没有未闭合的 `(`"：有 ⇒ 是连接点；没有（孤零零一个 `(2)`）⇒ **什么都不画**；
- **真嵌套**要写成内层 **≥ 2 个音符**：`(1(2 3))` ⇒ 外层 `1→3` + 内层 `2→3`（内层 2 音符，不触发连接点）；
- 连接点**不受**"连音线渲染层数上限"限制（`adj321b`）——它是**语义**，不是装饰，所以深嵌套里照样成立；
- **演奏**与普通连音线同一口径：连接点两侧**音高相同**才并成一个长音（只起奏一次、时值相加）。

**跨跳房子延续（`adj651`）**：一条连音线的**起点在跳房子起始小节线之前、终点是该房子的首音**时，
后面几个房子的首音只要写**孤立的 `)`**（前面没有未闭合的 `(`），就会**连回同一条连音线的起点**
（几个房子共用同一个起音，记谱上就是"这个音从前面的房子接过来"）：

```text
Q: 1 2 (5 |["1." 5) 6 |]["2." 5) 7 |]["结束句" 5) 1 ||      ← 三条线同一个起音（那个 5）
```

- 起点跨行时（上一个房子的连线在上一行），延续线画在**该房子的起始小节线**处（`|` / `:|` / `||/` 上的那一小段半弧），
  不从页面左边距拉长线；上半条由房子 1 的那条显式连线表达，**不再多画一截**。
- **隔多少行都接续**：起点与房子首音之间隔着整行音符（甚至好几行）也照样画——延续线的语义就是"从前面接过来"，
  不需要两行紧邻（`adj651b`）。
- **演奏与普通同音连线同一口径**：两音**音高相同**时**并成一个长音**（只起奏一次、时值相加）——
  `(5/ |["1." 5/)` 的起音 + 房子 1 首音 = 一个 1 拍的 `5`；房子 2 / 结束句的首音虽然与起音
  隔着整段旋律（**跨小节、跨行**），但演奏顺序里它紧接在起音之后（第 2 遍跳过房子 1 之后），
  因此**照样合并**（`adj651c`）。写法不变、不需要额外记号。
- 没有"跨跳房子连音线"可延续时，孤立的 `)` 不产生任何连线（老谱面不受影响）。

**演奏（同音连线 = 延长）**：一条连音线内**音高相同**的相邻两音**并成一个长音**（只起奏一次、
时值相加，**可跨小节**）——例：`(6- | 6)-` 奏一个 `6` 共 4 拍；音高不同则照常各奏各的。
与**倚音**的关系（`adj629r`）：

- 第二个音带**后倚音**（`6[h1'/]`）→ **仍然合并**：后倚音正好落在这个长音的**末尾**，长音让出最后一小段
  （例：`(6- | 6[h1'/])-` = 一个 `6` 奏 4 拍，末尾一个 `1'`）；
- 第二个音带**前倚音**（`6[1'/]`）→ **不合并**：前倚音要占这个音**开头**的一份时值，并进去就没有独立起奏点；
- 带**波音**的音自己不被并入（它要重新起奏并波动）。

等时值连音组四条规则（记不住就先照抄示例）：

1. **组总时值 = 小节名义拍数 − 组外音符实际时值**。例：2/4 的 `3./ 6,// (y3/ 2/ 1/) |`——组外已占 1 拍，组占剩下的 1 拍，三个音各 1/3 拍（演奏时值同样 1/3 拍）。
2. **占宽同样按"剩余时值"分摊**：组内每个音符的宽度 = 组总占宽 ÷ 音符数（不按各自写的 `/`）。
3. **减时线连成一条**（跨拍也不断开），同时仍与**同一拍内的组外音符**相连。
4. 组内音符少于 2 个时不生效（退化成普通连音线）。

## 2.8 小节线与反复

| 写法 | 含义 |
|---|---|
| `\|` | 单小节线 |
| `\|\|` | 双小节线（终止） |
| `\|:` `:\|` `:\|:` | 反复开始 / 结束 / 包围 |
| `\|/` | 隐藏小节线 1（不显示**也不占空间**，行首跳房子用） |
| `\|*` | 隐藏小节线 2（不显示**但占空间**，单声部转多声部补位用） |
| `"文字"` | 小节线备注（如 `\|"p:2/4"` 临时拍号） |
| `&fine` `&dc` `&ds` `&hs` `&ty` | 小节线修饰符：曲终 / 从头反复 / 大反复 / 花 S / 大跳跃 |

**跳房子**（`[` 起点 + `|]` 终点，必须写在小节线后）：

| 写法 | 含义 |
|---|---|
| `\|["1." 1 2 3 4 :\|` | 标签里的数字 = **该房子所属的遍次**（第 1 遍走到才奏） |
| `\|["2.3." 1 2 3 4 :\|` | **多个数字** = 该房子属于**第 2、3 两遍**（计数 2，两遍各奏一次） |
| `\|["1." … \|]["1." … :\|]` | **同一注释 = 同一个房子**：共用一份计数，在它所属那一遍里**走到哪处奏哪处** |
| `\|["结束句" 3 - - - \|]` | 标签**无数字** = 不指定遍次，按**出现顺序**取一个还没被占用的遍次（用于"末遍房子"） |
| `[+` / `[-` | 抬高 / 降低房子横线（每级 2px，可多个） |
| `\|]/` | 房子终点**不封闭**（线画到此处，但**末尾延伸到后面的反复/跳跃线**，见下） |
| `\|]` | 房子终点**明确封闭**——范围就到这根线 |
| `\|]["2."` | 同一根线上 `]` 在 `[` 前：**上一个房子结束 + 下一个房子开始**（画法上共用一根竖线） |

> **跳房子的判定口径（`adj723aa`，2026-10 用户定案）**——三条合起来才完整：
>
> 1. **注释里 `.` 分隔出的编号就是该房子所属的遍次**：`["1."` ⇒ 第 1 遍；`["2.3."` ⇒ 第 2、3 遍；
>    `["4."` ⇒ 第 4 遍。**注释里的数字只用于"判断是否同一个房子"与"得到计数"**，
>    真正的执行依据是**计数 + 谱面自然顺序 + 反复/跳跃**。
> 2. **计数 = 注释里 `.` 分隔的段数**（`["2.3."` ⇒ 2，`["1."`/无注释 ⇒ 1）。
>    走到房子入口时：**还有计数 ⇒ 进入并演奏**；**计数为 0 ⇒ 跳过该房子范围、继续往下演奏**。
>    3. **进入下一遍次时，本遍进入过的那些房子的计数各减 1**——不管这个房子有没有都走完
>    （这样"属于这一遍的任务"就完结了，不会留到下一遍又被走进来）。
>
> 同注释的房子**在同一遍里"每一处都奏"**（前提是演奏顺序能走到那处）；
> **不同注释属于不同遍次**。房子**不会嵌套**：分界在小节线上，小节内的音符才是演奏的主体。
> 例（用户逐字确认）：
> ```
> Q: |: 1 2 |["1." 3 4 |]["2." 5 6 |] 7 1 :|      ⇒ 12 34 71 · 12 56 71
> Q: 1 1 |["1." 1 2 |]["2." 1 3 |]["1." 1 4 :|] 1 5 ||  ⇒ 11 12 14 · 11 13 15
> ```

> 小节线后的**备注引号**、**`&` 修饰符**、**跳房子标记**三者**顺序无关**（`\|"p:2/4"&hs`、`\|&ds]/&hs` 都行）。
> 音符后的**注释引号**与 `&` 编码同理（`1&tr"注释"` / `1"注释"&tr`），但注释**紧跟的 `+`/`-`** 算注释的升降级数。
>
> **同一根线上既 `:|` 又 `&ds`/`&dc`（如 `:|&ds]`）时：反复优先**（`adj653`）——
> 该段还有遍次没走完就先按 `:|` 回跳；**遍次走完**再到这根线，才执行 `&ds`/`&dc`。
> 例：`Q: 1- |:&hs 2- 3- :|&ds 4- ||]` ⇒ 奏 `1 2 3 2 3 2 3 4`（2 遍反复 + 花 S 之后那一遍）。
>
> ### 全局跳转的配对与已知缺口（`adj723w`，2026-10）
>
> 按通行惯例，全局跳转有四组配对：**`&dc` 配 `&fine`**、**`&ds` 配花 S（`&hs`）**、
> 以及 **"跳至花"（To Coda）配花段（Coda ⊕）**。本引擎目前的支持面：
>
> | 记号 | 本引擎 | 说明 |
> |---|---|---|
> | `&hs` | ✅ | 花 S，`&ds` 的跳转目标（跳到它之后） |
> | `&ds` | ✅ | 跳花 S；全曲只跳一次 |
> | `&dc` | ✅ | 从头反复；全曲只跳一次 |
> | `&fine` | ✅ | 曲终；**只在有大反复且大反复已发生后**才生效（第一次经过不停） |
> | `&ty` | ⚠ 部分 | 渲染为**花记号 `⊕`**；走查语义是"跳到**下一根 `&ty` 之后**"（两 `&ty` 之间不演奏） |
> | **`To Coda`（跳至花）** | ❌ **无对应修饰符** | 目前**写不出来**——用户 2026-10 明确：「`To Coda` 目前没有相应的修饰符，暂时先不做规范」 |
>
> **因此下列规则目前无法完整落地**（缺 `To Coda` 记号）：标准写法
> `𝄆A𝄇 𝄋B ToCoda C D.S. ⊕D` 应为 `A A B C → B → D`，
> 而本引擎只能用 `&ty` 近似（两根 `&ty` 分别充当指令点与花段起点），
> 结果会多奏 `To Coda` 到跳转线之间的那一小节（实测 `1 1 2 3 2 5`，期望 `1 1 2 3 4 2 5`）。
> **待 To Coda 记法定下后再收敛。**
>
> 已实现且与规则一致的部分（实测通过）：`&dc`+`&fine` 例（`𝄆A𝄇 B Fine C D.C.` ⇒ `A A B C → A A B`）
> 与 `&ds`+`&fine` 例（`A 𝄋 𝄆B𝄇 C Fine D.S.` ⇒ `A B B C → B B C`）。
> 另记：**`&ty` 的"跳越"每根最多只扫一次**（`adj723w`）——即使 `&dc`/`&ds` 回跳后又走到同一根 `&ty`，
> 也**不再重复跳越**（**跳跃只执行一次**：`&dc`/`&ds` 全曲各一次、`&ty` 的跳越也只发生一次）。

**房子终点写 `|]/`（不封闭）时的范围**：`]/` 的含义是"**房子线画到此处，但房子的末尾要延伸到后面的反复或跳跃处**"。
即该房子的末尾线是**其后最近的**满足任一条的小节线（`adj723aa` 定案）：

- 反复线 `:|` / `:|:`（**首选**）
- 带 `&ds`（跳花 S）、`&dc`（从头反复）、`&fine`（曲终）修饰的小节线

> **注意**：与早期版本不同，**`||` / `||/` 不再是未封闭房子的末尾线**——
> `||]` 这种"双线 + `]`"是**明确封闭**，房子到它为止。
> 若 `]/` 后面找不到上面那些线，才退回到它自己那根线。

落到那根线时，**它自己的"跳跃 / 结束"照常生效**（例如落到 `|&fine` 就曲终、落到 `|&ds` 就跳花 S）。
线**之后**的音乐照常演奏。已封闭的房子 `|]` 不受此影响（范围就是自己那根线之间）。

**持续到曲末的未封闭房子**（行首房子常见的收尾写法）：最后一段房子的终点写 `||]`——
双小节线 + `]`，是**明确封闭**，范围从它的 `[` 到曲末。

**全局跳转的生效条件（`adj723aa`）**：

- **`&ds`（跳花 S）必须有对应的 `&hs` 才生效**——用户口径：「`&ds` 前面没有对应的 `&hs`，
  因此 `&ds` 应该要不起作用」。没有花 S 就**不跳**（**不会退回"跳到曲首"**，那是 `&dc` 的语义）。
- **`&fine`（曲终）只在"生效的大反复确实发生过"之后才终止**——第一次经过 `&fine` 不停；
  `&dc`/`&ds` 跳回来之后**第二次**经过才停。没有大反复时单独写 `&fine` 通常不作为结束。
- **转调遇到反复、跳跃等不恢复调号**，除非有明确的再转调 `"d:X"` 或恢复调号 `"d:"`。

### 小节时值校验与临时拍号（adj594）

每个小节里**带时值元素**的时值之和应与当前拍号一致（`P: 4/4` → 每小节 4 拍；`P: 6/8` → 每小节 6 拍）。不一致时给**告警**（不阻断预览/导出）；**每个音轨的第 1 小节只查"整数拍"**（弱起可以不满拍号）：

```
P: 4/4
Q: 1 2 3 4 | 1 2 3 |
                ↑ 告警：第 2 小节共 3 拍，与拍号 4/4（每小节 4 拍）不符
```

- **临时拍号**：把 `|"p:2/4"` 写在小节线后，**从这一小节线之后的小节**（即下一小节）起按 2 拍计，一直延续到同一音轨的下一个临时拍号；不同音轨（`Q1:`/`Q2:`）**各算各的**。
  ```
  Q: 1 2 3 4 | 5 6 7 1' |"p:2/4" 1 2 | 3 - |      ← 后两小节按 2/4 校验，全部对齐
  ```
- **小节号按音轨累加**：同一旋律折成多行 `Q:` 时，第二行的小节接着数（不会又从"第 1 小节"开始）。
- **首小节（弱起）例外**：每个音轨的**第 1 小节只要求"整数拍"**——弱起可以短于拍号（`1 |` = 1 拍、`1 2 |` = 2 拍都合法），但 2.5 拍这种"半拍"仍告警。第 2 小节起必须等于拍号。

  4/4 的曲子、开头只有 2 拍的弱起，这样写就是对的（不会有告警）：

  ```jps
  V: 1.0
  B: 弱起示例
  D: C
  P: 4/4
  Q: 5 5 | 1 2 3 4 | 5 6 5 3 | 2 - - - ||
  ```

  反过来说：**不想弱起**就把首小节补满 4 拍（加增时线 `-` 或减时线 `/`），例如 `5 5 - -`。
  多声部各条 `Q:` 轨**各自**判首小节，互不影响。

- **谁不参与合计**：记号/括号/渐强渐弱（`&hx`、`&zkh…&ykh`、`1<`）、乐器切换、临时段 `{bz … }`——倚音占用主音符的时值，也不额外计入。
- **空小节跳过**：一个小节里一个带时值元素都没有（多声部填充用）不报。
- 末尾**没写收尾 `|`** 的那一截也算一个小节（与排版口径一致）；没写 `P:` 时按 `4/4` 兜底检查。

## 2.8b 临时转调 `d:`

改调号有两种写法，二者**同槽位**（都写在小节线后的引号里）：

| 写法 | 位置 | 含义 |
|---|---|---|
| `D: C`（描述头） | 描述头 | **全曲**默认调号（`1 = C`） |
| `\|"d:1=D"` | 小节线后 | **从这一小节线之后的小节起**改为 D 调（`1 = D`） |
| `\|"d:"` | 小节线后 | **恢复描述头 `D:` 的调号**（转回原调） |

- **调名写法与描述头 `D:` 完全同一套规则**：`d:C` / `d:D` / `d:Eb` / `d:F#` / `d:$B` / `d:#F` 都行
  （升降号可在字母前或后，`$` 与 `b` 都表示降号；**音名要大写**——与 `D:` 一致）；简谱习惯的级数写法 `d:1=D` 也接受（`1=` 只是书写习惯）。
- **生效范围（adj665 定稿口径）**：从该小节线之后一直延续，**只有再写 `d:<调>`（换调）或 `d:`（恢复）
  才会变**——**反复（`:|`）与跳跃记号（`&dc` / `&ds` / `&ty` / `&fine`）都不回原调**。
  - 也就是说：转调后即使反复或跳跃，仍然**继续用转调后的调号**；想回原调就显式写 `d:`。
  - 反复段**跨过**转调线时，第二遍的同一小节会落在**转调后的调**上（这是本口径的预期行为）；
    谱面上标注的调号始终是**书写位置**上的调号（`转1=D` 标在转调线右上角），两者含义不同。
  - 被**跳房子 / 跳越跳过**的段落里的 `d:` 不生效（没走到就不换调）。
- **预览**：在**该小节线右上方**显示一个小记号 `转1=D`（`d:` 恢复时显示恢复后的调名，如 `转1=C`）。
  - 调名**按你写的原文显示**：写 `d:Ab` 就显示 `转1=Ab`（不会显示成等音的 `转1=#G`）；`d:` 恢复时显示描述头调号的原文。
  - 调名的升降号**与描述头 `D:` 同一套笔法**：画成字母左上角的 ♯ / ♭ 角标（和左上角 `1 = A♭` 长得一样），
    所以 `d:Ab`、`d:$B`、`d:bE` 的降号都显示成 ♭，`d:#F`、`d:F#` 显示成 ♯。
  - 记号后紧跟 `+` / `-` 可**逐级抬升 / 降低记号**（与音符注释 `1"注"+` 同一套记法、同一位置——写在**引号之后**）：
    `|"d:1=Ab"+`、`|"d:D"++`、`|"d:Eb"-`；写在引号里（`|"d:D+"`）也认，两种写法效果相同。
- **演奏**：记号之后的音按新调计算音高（`1` 的音高整体平移），MIDI / WAV / MP3 导出同样生效。
- `d:` 后面可以继续写普通备注文字（`"d:1=D强音"` → 转 D 调，并显示 "强音"）。
- 与其它小节线附加内容**顺序无关**：`|"d:1=D"&hs` 与 `|&hs"d:1=D"` 等价（同 `"p:2/4"`）。

```
Q: 1 2 3 4 |"d:1=D" 1 2 3 4 |"d:" 1 2 3 4 |      ← 中段转 D 调，末段显式写 d: 转回描述头调号
Q: 1 2 3 4 |"d:1=D" 1 2 3 4 :| 1 2 3 4 |        ← 反复线之后**仍是 D 调**（不回原调）
Q: 1 2 |"d:Ab"+ 1 2 |&fine 1 2 |                ← 显示 `转1=Ab` 并抬升一级；`&fine` 之后**仍是 Ab 调**
Q: 1 2 |"d:1=D" 2 3 |&ds 4 5 |                  ← `&ds` 跳回后仍按 D 调演奏（除非再写 d:）
```

> 多声部（`Q1:`/`Q2:`）时，转调记号写在**任一声部**的那根小节线上都会对**整个块**生效——
> 规范写法是各声部在**同一根线**上都写（写法一致），与 `"p:2/4"` 的口径对齐。

## 2.11 多声部

- `Q1:` `Q2:` 编号 + `C1:` `C2:` 歌词；`Q1"女声":` 可加声部名。
- 短声部用 `8`（隐藏休止符）补音符、`|*`（隐藏小节线 2）补小节，做到各声部小节对齐。
- 声部数多于 `Y:` 行数时，多出的声部用默认乐器。

### 单声部行与多声部组混排（演奏顺序，adj595）

**连续写在一起**的曲行才算一组：同一组内**声部号不重复** ⇒ 同时演奏；一旦出现重复声部号就**另起一组**，
一组接一组**依次**往下演奏。单声部行（`Q:` = 声部 1）自成一组，单独用**第一音色**（`Y:` 第 1 条）演奏。

```
Q:  1 2 3 4 |      ← 单声部：单独奏（第一音色）
Q1: 5 5 5 5 |      ┐ 第一组多声部：两行**同时**奏（Q1 用第 1 条 Y、Q2 用第 2 条 Y）
Q2: 3 3 3 3 |      ┘
Q1: 6 6 6 6 |      ┐ 第二组多声部：接在第一组**之后**，不与它重叠
Q2: 2 2 2 2 |      ┘
Q:  7 7 7 7 |      ← 又回到单声部：接在第二组之后，仍用第一音色
```

即顺序为「单声部 → 第一组 → 第二组 → 单声部……」，与排版上下分块的外观一致（排版同样是"声部号重复即另起一块"）。

## 2.12 临时伴奏与临时多声部（`{bz … }` / `{dsb … }`）

一段旋律里，某几拍想**临时加一层伴奏**、或**临时分成两个声部**，用 `{bz … }` / `{dsb … }` 直接写在
曲行中间即可——不必把整首曲子都改成多声部（见 2.11）。

- **`{bz … }` 临时伴奏**：段内是伴奏声部，画在主旋律**上方**，与主旋律**同一拍位垂直对齐**。
- **`{dsb … }` 临时多声部**：段内是**上声部**；该段覆盖范围内的主旋律自动成为**下声部**，
  两层上下叠放、同一拍位对齐，并用一对大花括号 `{ }` 把两层括在一起。

**写法**：`{bz` / `{dsb` 之后留一个空格，段末用 `}` 收尾。段内可以正常写音符、时值、小节线：

```jps
V: 1.0
B: 临时伴奏示例
D: C
P: 4/4
Q: 3 4 | {bz 1 2 3 4 | 5 6 7 1'} 5 6 7 1' | 1' 7 6 5 | 5 - - -
```

```jps
V: 1.0
B: 临时多声部示例
D: C
P: 4/4
Q: 3 4 | {dsb 1 2 3 4 | 5 6 7 1'} 5 6 7 1' | 1' 7 6 5 | 5 - - -
```

括号有两种写法，**任选一种**（不要同时用，否则会出现两层括号）：

- **自动括号**（**只有 `{tp … }` 替谱段**）：段内不写括号，程序自动给整段加一对圆括号 `( … )`。
  `{bz … }` / `{dsb … }` **不再自动加**（adj629l / adj666i，用户要求）——它们本身已有"伴奏层 / 大括号上下两层"的记号。
- **显式括号**：在段内自己写 `&zkh` / `&ykh`（左/右括号），程序就按你写的位置画、并为其**预留占宽**：

```jps
V: 1.0
B: 显式括号的临时伴奏
D: C
P: 4/4
Q: 3 4 | {bz &zkh 1 2 3 4 | 5 6 7 1' &ykh } 5 6 7 1' | 1' 7 6 5 | 5 - - -
```

**对齐与宽度规则**（这是它"能对上"的关键）：

| 项 | 规则 |
|---|---|
| 段占不占拍？ | **不占**。段是叠加层：`{ … }` 前后主旋律的拍位连续不变 |
| 段有多宽？ | **包络** = `[段所在拍位, 段所在拍位 + 段自身总拍数)`，与主旋律同一拍位区间对应 |
| 段内音符怎么排？ | 按**拍位比例**映射到包络内（`1-` 占 2 拍，宽度就是 `1` 的两倍） |
| **段层与主旋律的占宽？** | **重叠区按"多声部规则"算**（adj629m，三种段层一视同仁）：同一拍取**两层里更密的那一层**的需求（最小时值单元决定的最小宽）——主旋律该拍会被一并撑宽、段内 16 分音符也拿得到足够槽宽；撑宽只从"行内富余"里让出 ⇒ **行总宽不变、不溢出**。所以加了段层后，覆盖区那些拍的主旋律位置可能略微变宽（这是有意的对齐），行外内容与行的总宽不受影响 |
| **每拍占宽？** | 段内外的**每拍占宽一致**（富余按拍数等比分配，段不会把相邻小节挤窄）。大括号/圆括号所需的间隙记在**边界小节线**上并计入非时值占位预算，只让所有拍**同比例**略窄，不破坏均匀性 |
| 段内小节线？ | 按**段内自身拍位**推进，再映射到**主旋律小节线**的位置——上下两条 `\|` 精确对齐 |
| 段右边界？ | 收在**主旋律小节线**处（不越过它），右括号落在该小节线**之前** |
| 段左边界？ | 段首音与主旋律同拍位音符对齐；左括号落在段首音**左侧**预留出的空位里 |
| 括号占宽？ | 段内 `&zkh`/`&ykh` 的占宽**计入行宽预算**（上下两层一起考虑占宽），不会被音符压住 |
| 括号位置/间距？ | 与全谱其它括号**同一套**：文本括号字形、**与数字同高**（字形中心 = 数字中心），左右各留 `0.5×字号` 间距 |
| **`{bz}`/`{dsb}` 两侧的括号？** | **不自动加**（`adj629l` 用户要求 `{bz}`；`adj666i` 同口径扩展到 `{dsb}`）：它们本身就是"这些音属于伴奏层 / 上下两层"的记号，再套一对圆括号是多余的（用户拿印刷谱对比："我希望的效果"里没有这对圆括号）；**只有你自己写了** `&zkh`/`&ykh` 才按你写的位置画。**`{tp}` 替谱段仍自动加**（画在歌词区、离主旋律远，需要括号圈出"这一遍弹这些"） |
| 段内音会丢吗？ | **不会**：段内容按拍位映射排布，个别音被挤到近乎 0 宽时会给一个**最小占宽**画出来（旧版会把这音静默丢掉，用户报「伴奏最后面的 `5/` 没有显示出来」） |
| 段层画在哪？ | bz：画在主旋律**上方**一层；dsb：上（段内容）+ 下（包络内主旋律）**两层整块下移**，使整块中线与主旋律其余部分**居中对齐** |
| **大括号在哪？** | dsb 的大括号是**无时值占宽元素**（同 `&zkh/&ykh` 只占宽、不占拍）：左 `{` 在起始小节线**右侧**、右 `}` 在结束小节线**左侧**——好比把下一行两侧的小节线**向上延伸**，段内容全在这两条线**内部**排布（且与小节线留出净距，不贴线）。纵向**包住上下两层**——上端高过上一行音符的上沿、下端低过下一行音符的下沿；形状取自图形 `大括号.svg`（左 `{` 用原图、右 `}` 用**水平翻转**；纵向铺满段高、横向收成 `0.12×段高` 的细括号，只向**外侧**伸展，不依赖具体字体） |
| dsb 的下声部？ | 取包络范围内的主旋律音，与上声部同一拍位垂直对齐 |
| 上下层**间距可调**？ | 可以：在「谱面设置 → 布局 → 临时段」里分别设 `bz 段上下间距` / `dsb 段上下间距`（单位 px，10–80，默认 22 ≈ 1.7×字号）。bz 调间距只让段层上下移动、主旋律不动；dsb 调间距让两层**对称外扩**、整块中线仍对齐主旋律基线。这是**谱面级**设置，会写进 `# jps-config` |

**注意**：

- 段必须**成对闭合**（`{bz … }`）；缺少 `}` 会报「未找到结束 "}"」。
- 段**不支持嵌套**——段内再写 `{bz` / `{dsb` 会报「不能嵌套在已有段内」。
- 单独出现的 `}` 会报「多余的 "}"」。

**试听效果（声部与音色）**：

重叠区按**两个声部**演奏，各用不同音色、不同颜色的色块：

| 段型 | 上层（段内容） | 下层（包络内主旋律） |
|---|---|---|
| **`{bz … }`** | **伴奏声部**：用**第 2 可用音色**（脚本第 2 条 `Y:` 行；没有则「手风琴」），力度 **0.75** | **主声部**：沿用该曲行音色、力度不变 |
| **`{dsb … }`** | **第二声部**：用**第 2 可用音色**（同上），力度 **0.75** | **主声部**：用该曲行音色、力度不变 |

- 段层与主旋律**同一拍位同刻发声**（时间由排版坐标决定，反复/跳房子下也同步）。
- 重叠区按**多声部**呈现：**上下两层各有一个色块、同步移动**（上层 = 段内容，下层 = 包络内主旋律）。
- 段落在 `|: … :|` 里时，**每一遍都会演奏**。
- 色块**按音色着色**——不同音色不同颜色；播放中用 `@乐器名` 切换音色时，色块颜色随之变化。
- 伴奏 / 第二声部的音色**由本谱决定**（`Y:` 第 2 行，缺省「手风琴」）——**「音色」选「自动」时**不会被别处压成同一种音色；
  但**选定某个具体音色时全篇统一**，重叠区两个声部也会一起换成它（adj455，见 2.9 的音色优先级）。
- 第 1 可用音色即主声部音色（默认「大钢琴」，也就是「全局设置 → 音色库」启用列表的首位）。

**色块动态定界**（adj429）：多声部 Q1/Q2 的色块按声部中线**自动分块**（互不重叠）；临时叠加段的上下两层也按中线分块，且每块高度不小于 4 px（不到则隐藏）。色块不会侵入歌词区（默认 `+0.6×字号` 的下沿远小于歌词行 `quci=15`）。**adj429b（dsb 上下严格等高）**：dsb 上下两层色块**严格等高**（用户建议）——把"对称中线"从 row.y 上移 0.25×字号 = 3.25 px，让 upper 用 TOP_EXT(1.1ns) 覆盖减时线、lower 用 BOT_EXT(0.6ns) 不压歌词，两者通过中线偏移消化上下延伸量的天然不对称；整组随之轻微上移，但上行曲部底 − quci=15 ≫ 3.25，无侵入风险。

**色块颜色（adj432；adj722 口径翻转后角色对调）**：段内声部角色决定色块颜色——`{bz … }` 上层（伴奏）= **蓝**、`{dsb … }` 上层（**第二声部**）= **绿**、`{dsb … }` 下层（**主声部**）= **红**；普通主旋律仍按音色着色（第 1 音色红、其它音色依次取调色板）。

**段层间距可拖动（adj432）**：预览区「排版辅助虚线」下，段层行虚线为**紫色**（与曲行绿、描述头橙、边距青区分），拖它调整：
- `{bz … }` 上层虚线 → `segmentRowGap.bz`（伴奏层与主旋律的间距；向上拖 = 增大）
- `{dsb … }` 上层虚线 → `segmentRowGap.dsb`（向上拖 = 增大间距，两层对称外扩）
- `{dsb … }` 下层虚线 → `segmentRowGap.dsb`（向下拖 = 增大间距，同一变量）
- `{tp … }` 替谱行虚线 → `segmentRowGap.tp`（替谱行与其下方歌词行的间距，往上拖 = 层上移，见 2.12b）

拖动即改设置面板「谱面设置 → 布局 → 临时段」的两个数值，并写进谱面 `# jps-config`（差量写入）——换机器/换人打开同一份 `.jps` 版面一致。

## 2.12b 替谱段 `{tp … }`（同一小节两遍不同奏法）

一段旋律反复时，**某一小节在某几遍里奏法不同**（记谱上常写成下方括号里的一小段"ossia"），
用**替谱段** `{tp … }` 表示——它写在**歌词行**里，**第 k 段歌词 = 第 k 遍**：

```jps
V: 1.0
B: 如愿（片段）
D: C
P: 4/4
Q:  |: 1 2 3 5 | 6 1 2 3 | 4 3 6 6 | 2 3 4 5 :|
C:  有 人 放 烟 花 有 人 追 晚 风 借 一 缕 时 光 捧 一 片 星 空
C2: 有 人 唱 情 歌 有 人 听 晚 钟 {tp 4/ 3/ 6,/ 6,/ 1/ 1/ 1} 借 一 丝 懵 懂 惊 一 片 翻 涌
```

（第 3 段歌词若又要换一种奏法，就在它自己的 `C3:` 行里同样写一个 `{tp … }`。）

| 规则 | 说明 |
|---|---|
| 写在哪 | **只能在歌词行**（`C:` / `C2:` / `C3:` …）里；写在 `Q:` 曲行里会报错并提示 |
| 第几遍 | **歌词行序号**：`C:`（=`C1:`）= 第 1 遍、`C2:` = 第 2 遍、`C3:` = 第 3 遍……加一段歌词就多一套替谱 |
| 锚点 | 替谱从**紧跟 `{tp … }` 之后那个歌词字**所对应的音符起生效（所以写在"被替换区间第一个字"的前面） |
| 长度 | **段内总拍数**（段本身**不占**主旋律的拍）：`4/ 3/ 6,/ 6,/ 1/ 1/ 1` = 4 拍 ⇒ 正好盖住那一小节 |
| 段内写法 | 与曲行同一套：音符/时值/连音/倚音/装饰都行，可跨小节；**不必写小节线**。段内**不支持嵌套** |
| 预览 | 画在**它所属那条歌词行的上方**（自动加一对圆括号，括号与段内首末音各留 `0.75×` 字号 = `TP_BRACKET_GAP`，**不紧贴**；段从**小节线**起时左括号允许略微越到小节线左侧，免得被"小节线内侧"钳制回去压住数字），与主旋律**逐拍同位**（`x` 与同一拍的主旋律音完全一致，**不做横向压缩**） |
| 层高 | **`{bz … }`（临时伴奏）与 `{tp … }`（替谱）** 字号不变、整层高度**压扁到 2/3**——看起来"扁"一些，一眼能区分"这是另一层 / 另一遍的内容"；**`{dsb … }`（临时多声部）的第一声部按正常高度**（`adj693`，用户要求：「临时多声部的第一声部高度不再压缩，显示为正常高度」）——它是"**两个声部上下叠**"，压扁会让第一声部比下面的声部矮一头、也看不出声部分层 |
| 间距 | **三条虚线各管一段**：歌词行 1 的虚线 → 歌词区与上方曲部的间距（`height_quci`）；歌词行 2 及以后的虚线 → 歌词行之间的间距（`height_cici`，A）；**替谱行虚线 → 替谱行与其下方那条歌词行的间距**（`segmentRowGap.tp`）——拖它上下移动的是**替谱层本身**（下方歌词行不动） |
| 占位 | 替谱层按**自己的高度 B** 把该歌词行整行推下去 ⇒ **有替谱时歌词行间距 = A + B**，没替谱时 = A |
| 占宽 | 替谱层与主旋律**共用同一套拍格**：每拍取"两层里更密的那一层"的需求（`adj629m`）。拍**内部**的细分按**替谱自己的时值**分布在"**覆盖该拍位那个主旋律音的槽**"里（槽右端 = 下一个音的 x，末音 = `x + width`；一拍里有多个音时**必须分段**——用"墨迹宽"或整拍线性插值都会把替谱 16 分挤到重叠甚至倒退，`adj659b`）；拍起点正好有主旋律音时**严格同拍同位**（`adj629k`）。⚠️ 试过"按拍需求重排整行占宽 + 提前断行 + 强制撑满"，实测**整行明显变差**、已回退（`adj659` → `adj660`） |
| 同一行多个 `{tp}` | **不重叠的排在同一条水平线上**（并排画、整行只多留**一个** B）——同一行写两处替谱（如 `… {tp 4/ 3/ 6,/} … {tp 1/ 1/ 1} …`）不会各占一条线（`adj655`）。只有**水平区间真的重叠**（例如连写两个 `{tp}`、锚点落在同一拍）才往上叠一层 |
| 段内记号 | 段内可以正常写**连音线** `( … )`、倚音、装饰等（连音线按段层自己的音符配对绘制） |
| 段内演奏 | 与曲行**同一套口径**：**倚音**（前/后、长/短）、**演奏型装饰**（波音/打音/叠音）、**滑音**都在段内照常发声（adj637 起补齐；时值同样只从本音符里匀，不改段内总时长） |
| 段内连音的演奏 | 与主旋律**同一套规则**：连音线内**音高相同**的相邻两音 = **一个长音**（时值相加、只起奏一次，如 `(6// 6/)` 奏 0.75 拍）；**音高不同**就照常各奏各的（`(6// 7/)` 两个音）。带倚音/波音的音不参与合并 |
| 歌词对齐 | **按槽位对齐**：替谱锚点音之后的歌词字，按**它在歌词行里的槽位**（计时 token 序号；`@` 跳空照占一槽）对到替谱的**同序号音**上——不是"字序逐个配"（会把 `@` 的跳空吃掉），也不是按拍位区间找（替谱是另一段旋律，音符个数与包络内主旋律音个数**可以不同**，`adj654`/`adj657`）。**该行的字比主旋律该行的音多**时，末尾超出槽位的字由**替谱音补上**（不再丢字，`adj658`）；字比替谱音多时，多出来的字保持原位 |
| 两端括号 | 替谱层两端 `&zkh`/`&ykh` 与音符的间距按**墨迹**算：左括号 `0.375 × 段层字号`（**半个间距**——它的基准是"音符块左缘"，数字墨迹还往右缩一段，取满间距视觉上偏松，`adj664`）、右括号 `0.75 × 段层字号`。两侧都可以**越过小节线**（替谱层独占一行，不压别的内容），但**右括号不得越出页面边距线**（内容区右边界）。**替谱包络排到行末时**该行会预留"括号 + 间距"的宽度（整行按略窄的可用宽摊，≈1.5%），保证行末 `)` 仍有完整间距（`adj629k`/`adj657`/`adj661`/`adj662`/`adj663`/`adj664`） |
| 演奏 | **第 k 遍**用替谱替代主旋律那一段（音色/力度与主旋律一致）；其它遍仍奏主旋律。MIDI/WAV 导出同源 |
| 演奏边界 | 判据是**时值区间有重叠**：与替谱覆盖区相交的主旋律音那一遍不发声（避免与替谱"打架"）；**替谱奏完立刻回主曲部**——起点正好落在替谱终点上的主旋律音照常发声（例如替谱盖住前两拍时，第 3 拍那个音必须奏出来） |
| 排版 | 加了替谱**不会改动主旋律的音符与间距**，只在那一行为它**留出高度**；没写 `{tp}` 的谱面零影响 |
| 点选联动 | 替谱层的音符和主旋律一样**可以点**：单击跳编辑器到 `{tp … }` 里对应那个音；试听中单击/双击从该音开始演奏 |
| 格式化/着色 | 段内就是**曲部内容**：编辑器按**曲部颜色**着色（音符橙、小节线灰蓝，`{tp`/`}` 用行头色），"格式化"也按曲行规则给段内补空格（歌词文字保持原样） |
| 间距 | 「谱面设置 → 布局 → 临时段」里的 **`tp` 段上下间距**（默认 14 px）= 替谱行与其下方歌词行的间距；预览虚线可拖（拖它移动的是替谱层本身） |

**告警（不阻断）**：某条歌词行的替谱在本段反复遍数下**永远播不到**（例如写了 `C3:` 但本段只反复 2 遍）时，
说明该段替谱不会生效——把反复记号改成能奏到第 3 遍的写法（`:||:` 或 `&ds`），或删掉那条替谱。

> **与 `{bz … }` / `{dsb … }` 的区别**：那两个是"**同时**加一层"（伴奏/多声部，每遍都奏）；
> `{tp … }` 是"**这一遍换成另一段**"（替代主旋律，只在自己那一遍生效），且写在歌词行上而不是曲行上。

## 2.13 块间空格规则

**块与块之间恰好一个空格**：音符块、小节线块、连音线 `(` `)`、装饰 `&…`、跳房子 `[` `]`、乐器 `@…@` 各自是独立块。
音符**块内部**不写空格（`1'#`、`1/.`、`3[2/]` 都连写）。多写空格或漏写空格会被解析器提示。

## 2.14 页面设置行 `# jps-config`

- 程序把"这份谱的版面设置"写在这一行：`# jps-config:{"note_size":14,"margin_left":55}`。
- **差量写入**：只记录与默认值不同的项；**全都是默认时这一行会清空成 `# jps-config:{}`**（adj629t：保留该行位置，
  不再整行删除——新文件模板本来也是 `{}`）。
- **「恢复默认」= 回到代码默认的完整状态**（adj629s）：点它会把**所有**谱面级设置都还原——
  包括"拖过描述头元素位置"这类**可选项**（`metaPos` / `heights` / `segmentRowGap` / `lyricShrink` / `showInstrument`）；
  再点「保存设置」，若确实全都等于默认，这一行就是 `# jps-config:{}`（不会残留 `{"metaPos":{…}}` 这种尾巴）。
  其中 `metaPos` 记的是**描述头各元素的自定义位置**（`title`/`subtitle_i`/`author_i`/`keyline`/`tempo`/`notes_i`，
  相对各自锚点的 px 偏移）——**在预览区拖动那些文字**时才会产生，没拖过就不会有这个字段。
- **水印层与背景层（adj965）**：谱面设置里多了两个组，键见 `docs/SETTINGS-AUDIT.md` 第 38–52 行
  （水印 `wmType/wmText/wmImage/wmSize/wmScale/wmRotate/wmOpacity/wmOffsetX/wmOffsetY`、
  背景 `bgImage/bgScale/bgRotate/bgOpacity/bgOffsetX/bgOffsetY`）。
  **默认全部等于默认值 ⇒ `# jps-config` 里一个键都不会多**（等于没这个功能）。
  图形文件的取值是**相对这份 `.jps` 的路径**；插件里也可以写 Obsidian **双链** `[[图片.png]]`；也接受 `data:` 内嵌。
  > ⚠ **它把"谱面自包含"打了个洞**（adj480 的另一面）：把 `.jps` 发给别人时，**相对路径的图片不会跟着走**。
  > 要发给别人，要么把图一起给，要么用面板里的「内嵌进谱面」把它变成 `data:` URI（自包含、但源码会变大）。
  层的顺序（从上到下）：**曲谱 → 水印 → 背景**；两层都**只显示在页面内**的部分。
  「排版辅助」打开时，可用 `Ctrl+滚轮` 缩放背景图、`Ctrl+Alt+滚轮` 旋转、`Ctrl+左键拖动` 移动位置。
- **描述头默认排布（adj629u）：三块各自"贴角"，顺序排列**——左侧（`D:` 调式+拍号 一行、`J:` 节拍 一行）
  贴**描述头区域的左下角**（末行在下、上方一行往上排；只有其中一行时，它自己就贴下沿）；
  右侧（`Z:` 作者，可多行）贴**右下角**（首行在上，末行贴下沿）；
  居中（`B:` 标题 / 副标题 / `Y:` 乐器）贴**区域上沿**，一行一行往下接。
  行距随「描述头字号 / 标题字号」自动缩放（大字号不会挤在一起）。**空设置（`# jps-config:{}`）就是这个排布**；
  只有你拖过某个元素，那个元素才按 `metaPos` 走。
- **描述头两行的 `=` 号对齐（adj629v）**：`D: Bb` 预览成 `1 = ♭B`、`J: 62` 预览成 `♩= 62` 时，
  两个 `=` 号**左右对齐在同一列**（含升降号的情形，升降号只把字母与拍号往右推，不动 `=`）。
- **只写"你改过的项" + 谱面自包含**（adj480）：在「谱面设置」里点「保存设置」时，只有**这一次你真正改动**的字段会写进谱面。
  程序**不再在本机保存一份"页面设置"**（旧版本会，且会套用到未自带设置的谱面）——因此
  "你看到的"只由「**代码默认值 + 谱面这一行**」决定：复制源码给别人（或在别的机器/浏览器上打开），
  显示效果一致（唯一不确定的是字体：字体**族**随谱走，但对方机器上未必装了这个字体，会按字体栈回退）。
- 这一行请**不要手改**——要改去「谱面设置」，改完自动写回。
- 生效优先级：**源码（本行）> 代码默认值**。
  （宿主侧可能还有"宿主默认层"：例如 Obsidian 插件的插件设置与笔记 frontmatter——它们只对**本行没写**的项生效，
  且不随谱走；要把它们也带进谱面用插件里的「随谱固化」。）
- **写法要求**（不满足会给告警，不再是静默失效）：必须**顶格**（行首不能有空格/制表符）；
  值必须是 **JSON 对象**；键必须是可识别的设置项（拼错会告警）；值类型要对
  （数值项写数值、布尔项写 `true`/`false`、`page` 取 `A4`/`A5`/`A4_horizontal`/`A5_horizontal`、
  布局模式取 `space`/`duration`、连音线样式取 `0`/`1`/`2`）。不合法的那一项会被**忽略并告警**（问题条 + 状态栏橙点，带行号），
  JSON 整行坏掉则整行忽略、回退默认值，谱面照常渲染。

相关版面规则（在「谱面设置 → 布局」里调）：

| 项 | 说明 |
|---|---|
| 纸张 / 边距 | A4/A5/横版；四边距（默认上下 40、左右 50 px） |
| 两端对齐最小小节数 | 默认 4：**只对末行生效** —— 非末行一律两端对齐（撑满整行），**只有末行**才按它判：末行小节数 ≥ 该值撑满、< 该值自然对齐（行尾留白）。想让末行也贴右，就把它设成"不小于末行小节数"的值 |
| **单行曲部的小节槽** | 一段曲部**只有一行**且小节数少于上面那个值时（如新建文件只有 1 小节），整行按该值**预分小节槽**：每小节占一个槽、槽内音符自动摊开，行尾留白；某小节内容放不下就按自身自然宽度排开。⚠ 单行曲部**本身就是末行**（所以上面那条"只对末行生效"对它照旧生效） |
| 布局模式 | 空间优先（默认，按本体宽+富余摊开）/ 时值优先（按时值比例） |
| **显示小节计数**（默认**开**；adj630c 按用户要求由"关"改为勾选） | 打开后在小节**左侧小节线下方**画带方框的小节序号；**方框上沿距小节线下端 1px**（adj906 定稿）；**数字与方框都按倚音音符字号的 3/4** 显示。序号画在**曲部行自己的空间里**（落在小节线底缘下方那片空隙内），所以**开关它不改变排版**（行高、歌词位置、分页都不动）。**行首第一个小节**通常不画小节线（隐藏小节线）⇒ 序号画在它的位置下（通常是边距线位置）；**多声部**块的块首序号画在**大括号与音符之间**、与小节线底下同高（高度取**主声部**那条线，即 `voice 1` 那行）；**临时多声部**（`{dsb}` 等）让旋律与别层不在同一水平线时，序号同样挂在**主声部**的小节线下（跟着那一层的高低走）；行中间的小节线仍画在线的正下方 |
| **序号间隔**（默认 4） | 每隔几个小节显示一个序号：默认 4 ⇒ 第 4、8、12、16… 小节（**全曲连续编号**，多声部块内每小节只算一次）。取 1 则每小节都标；范围 1–99 |

## 2.15 音符的"自动格式化"

编辑时不用手抠空格：光标离开某条 `Q:` 行时，编辑器会自动整理块间空格（数字前补空格等）。
格式化的对象是**块间空格**，块内写法（`1'#`、`3[2/]`）不会被拆开。

# 第四部分 报错与排查

编辑器在**行号栏**标色（红=错误、黄=告警），点问题提示条可跳到出错位置；每条报错都带「**正确写法**」。

| 报错 / 现象 | 常见原因 | 正确写法 |
|---|---|---|
| 块之间空了两个空格 | 块间**恰好一个空格** | `1 2 3`（不要 `1  2`） |
| 无法识别的符号 | 用了本语法没有的字符（如 `%`、全角空格） | 换成合法符号；不确定就看 2.4 的表 |
| 引号未闭合 | `1"注释` 少了右引号 | `1"注释"` |
| 多空格 / 缺空格导致 `@`、`&` 解析错 | 独立块没有单独占一格 | `1 &tr 2`、`1 @弦乐@ 2` |
| 跳房子位置不对 | `[` 没写在**小节线后** | 行首写 `\|/ ["1." …`，行中写 `\|["1." …` |
| `C:` 行"孤零零"（前面没有曲行） | 词行必须跟在**同声部的 Q 行**后面 | 先写 `Q:` 再写 `C:` |
| `@乐器名` 出现告警 | 旧写法 | 改用 `@乐器名@` |
| 连音线没画出来 / 画到了别处 | `(` 与音符之间少了空格，或把连接点 `(1)` 当成了普通音符 | 连音线写 `( 1 2 )`（括号与音符**留空格**）；**连接点**才写紧贴的 `(2)`（见 2.7） |
| 渐强/渐弱不显示 | 没写结束 `!`，或跨了行 | `<` 与 `!` 写在**同一行的音符后**；不写 `!` 则收到行末 |
| 增时线数量不对 / 音符被吃掉 | 把 `-` 当成"降低一级"写在了渐强/编码后面 | 渐强只有 `+`；`-` 一律是增时线 |
| 试听没声音 | 音色库未就绪 / 未勾选音色 | 桌面端首次打开会自动准备内置音源；Web 端首次需联网下载一次；勾选「全局设置 → 音色库」里的音色 |

# 附录 A 与「番茄简谱」的兼容性

## A.1 一句话

爱记谱**沿用**「番茄简谱」（原 `doc.lezhi99.com/zhipu` 在线编辑器）的 `.jps` 后缀与脚本语法，
目标是：**原网站导出的谱子，粘贴进来基本即可使用**。原站格式化后的写法（如把 `5-` 拆成 `5 -`）
本引擎都能解析，复制过来不用手工整理。

**沿用（按原站写法解析）**：描述头 `V:` `B:` `Z:` `D:` `P:` `J:` `Y:` `S:`；`Q:` / `C:` 行（含声部编号与名称）；
音符与休止、高低音点、变音记号、时值与附点、小节线与反复记号、跳房子、连音线、
`&` 装饰编码、歌词规则、`[fenye]` 分页。

下面列的是**与原站不同的地方**与**本应用新增的写法**。凡有出入，**以本说明为准**。

## A.2 与原站写法不同的地方

| 项 | 原站 | 爱记谱 | 依据 |
|---|---|---|---|
| **乐器切换** | `@乐器名` | 推荐 **`@乐器名@`**（两侧都加 `@`）——含特殊字符的乐器名只有这样才能安全解析。<br>旧的 `@乐器名` **仍然能解析**，但会给一条**告警**提示改用新写法。 | `docs/SOUNDBANKS-SPEC.md` §一 |
| **倚音时值** | 一组倚音按各自时值合计 | 一组倚音**平分它所占的时值**。例：`3[3/2/]` 的主音符从 1/2 拍 → **3/4 拍**，每个倚音从 1/4 拍 → **1/8 拍**。 | `adj505` / `adj507`（`docs/ERRORS-LOG.md`） |

> 第 2 条是**可观察的行为差异**：同一份带倚音的谱子，两边的播放时值会略有不同（**谱面排版一致**）。
> 记谱时按本说明的规则理解即可。

## A.3 本应用新增的写法

| 新增 | 说明 | 详见 |
|---|---|---|
| **等时值连音组** `(y …)` | 组内几个音**平分**该组的时值，弧线上标数字。注意：放在**小节末尾**时按"剩下的时值"算、放在中间时按写明的时值算。 | §2.7 |
| **呼吸记号** `&hx` | 标注换气位置。**不计拍**（不影响小节时值校验）。 | §2.6 |
| **扩音区**（颤音加长 `+`） | 让颤音持续更久。 | §2.6 |
| **页面设置行** `# jps-config:{…}` | 把版面 / 字体等设置**写进谱面源码**，于是"复制源码给别人，效果一致"。 | §2.14 |
| **临时段** `{bz … }` / `{dsb … }` / `{tp … }` | 段内临时加一层伴奏 / 临时分两个声部 / 同一小节写两遍不同奏法。 | §2.12、§2.12b |

## 附：代码块参数（`v=` 视图 / `z=` 缩放）

在 Obsidian 笔记里、或在本网页文档里，\`\`\`jps 代码块可以在语言名后面写**参数**（空格分隔）：

```jps v=s z=150 playground
V: 1.0
B: 茉莉花
Z: 中国民歌
D: Eb
P: 4/4
# jps-config:{"align_min_bars":2}
Q: 3 3/ 5/ (6/ 1'/) (1'/ 6/ | 5 (5/ 6/) 5- | 3 3/ 5/ (6/ 1'/) 1'/ 6/ |
C: 好一朵美@丽的茉莉@花，好一朵美@丽的
Q: 5 (5/ 6/) 5- | 5 5 5 (3/ 5/) | 6 6 5- |
C: 茉莉@花，芬芳美丽@满枝丫，
Q: 3 (2/ 3/) 5 (3/ 2/) | 1 (1/ 2/) 1- | (3/ 2/) (1/ 3/) (2. 3/) |
C: 又香@又白@人人@夸。让@我@来将
Q: 5 (6/ 1'/) 5- | 2 (3/ 5/) (2/ 3/) (1/ 6,/) | 5,- 6, 1 |
C: 你摘@下，送给@别@人@家，茉莉
Q: (2. 3/) (1/ 2/) (1/ 6,/) | 5,-- 0 ||
C: 花@茉@莉@花。
```

（上面这块写的是 `v=s z=150` —— 它顶上有一排控件，**改一下下面的谱面立刻重排**：
三档视图（谱面 / 满宽 / 整页）与缩放分别长什么样，调一下就看出来了。
示例是整首《茉莉花》（14 小节、5 行）—— **谱面够长**，两种差别才看得出来。）

| 参数 | 取值 | 说明 |
|---|---|---|
| `v=` | `s` / `w` / `p` | **视图**：`s` 谱面（裁到墨迹，**默认**）/ `w` 满宽 / `p` 整页 |
| `z=` | 数字 1–1000 / `*` | **缩放**：百分比；`z=*` = 自适应容器宽；不写 = 100（自然尺寸） |

几个约定（与 Obsidian 插件**完全一致**）：

- 分隔符**以空格为主**，`,` `;` `|` 也认（`v=w,z=150` 可以）；**顺序任意**、**大小写不敏感**（`V=W` 也认）。
- **认不出的键值一律忽略**：`v=x` ⇒ 当没写（用默认「谱面」）；`z=abc` ⇒ 当没写（100%）。
- **连写不算参数** ✗：`z=150v=p` 两个都不认（否则"粘在一起"会静默变成别的模式）。
- 视图参数的键名是 **`v=`**（不是 `m=` —— 那是短暂用过的旧名，已废弃）。
- **`playground` 关键字**（本网页文档 / 应用内帮助专有）：写成 \`\`\`jps v=s z=150 playground
  的块会渲染成「**控件 + 实时预览**」—— 顶上选视图、拉缩放、勾「自适应」（`z=*`）、点「重置」，
  下面的谱面跟着重排；**控件初值就是这一行写的 `v=` / `z=`**，点「重置」回到它。
  ⚠ Obsidian 插件对"认不出的参数"一律忽略 ⇒ 笔记里它仍然是一个普通代码块，写不写都不影响看谱。
