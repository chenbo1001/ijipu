# iJipu（爱记谱）抖音 + 小红书 应用推荐视频脚本

> **品牌速查**：iJipu / 爱记谱 / i记谱 · Slogan「码即成，谱自现」· 主色深空蓝 `#1E2A5E` + 霓虹青 `#00F0FF` · 用户昵称「谱师」· 文件后缀 `.jps`
>
> **视频核心策略**：15-30 秒短平快，直击「会写代码就能写谱」「不用懂乐理也能排版」「在线/PWA/桌面端三端可用」三大痛点。

---

## 一、通用拍摄/剪辑总纲（两平台通用）

### 1. 节奏与时长
| 版本 | 时长 | 适用 |
|---|---|---|
| 极速版 | 15s | 抖音信息流首发、完播率优先 |
| 完整版 | 30s | 抖音「详情」挂载、小红书正文 |
| 教程版 | 60s | B站/视频号长尾、留资转化 |

### 2. 画面风格
- **底色**：深空蓝渐变 `#0F1526 → #1E2A5E`
- **强调色**：霓虹青 `#00F0FF`（光标、关键代码、按钮）
- **乐谱预览区**：纯白 `#FFFFFF` + 墨色 `#1b1b1b`（与品牌视觉规范一致）
- **字体**：等宽（JetBrains Mono / 思源等宽）= 代码区；思源黑体 = 中文字幕
- **BGM**（建议）：
  - 抖音：节奏感强的电子/赛博风（如 synthwave、lo-fi 改造版《小星星》）
  - 小红书：温暖钢琴/木吉他铺底，副歌节点切入轻快节拍

### 3. 三幕叙事结构（黄金 3 秒 + 冲突 + 解决方案）
1. **0-3s 钩子**：抛痛点 / 反常识 / 视觉冲击
2. **3-25s 演示**：实操演示，边录边配音
3. **最后 3-5s CTA**：引导下载/搜索/评论

## 四、剪辑与投放 Checklist

### 拍摄/录屏
- [ ] 录屏分辨率 1080×1920（竖版），帧率 60fps，光标移动务必丝滑
- [ ] 代码字体选用 JetBrains Mono / Fira Code（连字效果加分）
- [ ] 录屏片段提前准备 3 份：`.jps` 源码演示 / 实时渲染 / 导出试听

### 字幕
- [ ] 关键句必须加大加粗（霓虹青 `#00F0FF`）
- [ ] 中文用思源黑体 Heavy/Black，字号 ≥ 屏幕宽度 1/20
- [ ] 抖音避免字体过小导致手机端不可读

### 音频
- [ ] 抖音版：开头打字音 `嘀嘀嘀` + BGM drop 点对齐小节切换
- [ ] 小红书版：保留环境音（键盘声、咖啡杯碰撞声）增加沉浸感

### 投放
- [ ] 抖音：发布时间 20:00-23:00；话题 `#代码 #简谱 #iJipu #程序员副业 #独立开发`
- [ ] 小红书：发布时间 21:00-23:30；首发带 3-5 个垂直标签更易进推荐流
- [ ] 评论区：1 小时内回复前 30 条评论，置顶引导语（私发源码、引导进群）

### 风险与合规
- [ ] BGM 使用抖音/小红书音乐库正版曲目，禁用未授权曲目
- [ ] 不出现其他品牌 Logo（避免竞品对比引战）
- [ ] 代码示例使用公有领域曲目（如《小星星》）规避版权
- [ ] 桌面端截图避免显示 Windows 激活水印 / 个人账号信息
